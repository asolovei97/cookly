# Глосарій

Терміни, які використовуються в усіх документах Cookly.

| Термін | Значення |
|---|---|
| **Акаунт** | Користувач, який може увійти в застосунок. Прив'язаний до однієї персони. |
| **Персона** | Людина, на яку готують: параметри тіла, ціль, активність. Може не мати акаунта (наприклад, дитина). |
| **Сім'я** (household) | Група персон зі спільними меню, запасами, обладнанням і бюджетом. Може бути й «командою». |
| **Код запрошення** | Реферальний код, за яким новий користувач приєднується до сім'ї і забирає вже створену для нього персону. |
| **Ціль** | Схуднення (дефіцит), підтримка, набір маси; разом з рівнем активності визначає норму. |
| **Норма** | Добова ціль калорій і БЖВ персони: формула або ручне значення. |
| **КБЖВ** | Калорії, білки, жири, вуглеводи. Зберігаються на 100 базових одиниць. |
| **Інгредієнт** | Типовий продукт («куряче філе», «молоко 2,5%») з усередненими КБЖВ. На нього посилаються рецепти. |
| **Товар** | Конкретний продукт у продажу (SKU): бренд, упаковка, штрихкод, власні КБЖВ. Належить інгредієнту. |
| **Базова одиниця** | `g` або `ml`. У ній зберігаються КБЖВ і кількості. |
| **Альтернативна одиниця** | `шт`, `порція`, `ст. л.`, `упаковка` тощо з коефіцієнтом перерахунку в базову. |
| **Обладнання** | Довідник кухонного обладнання (духовка, блендер, каструля з вагою тари…). |
| **Запаси** | Що є вдома: кількості інгредієнтів і товарів, а також прапорці «завжди є». |
| **Рецепт** | Склад з інгредієнтів, кроки, порції, вимоги до обладнання, термін зберігання. |
| **Напівфабрикат** | Рецепт, який може бути інгредієнтом іншого рецепта (майонез, бульйон, тісто). |
| **Публічний рецепт** | Версіонований знімок приватного рецепта, схвалений модерацією. |
| **План меню** | Календар на довільний діапазон днів: готування й прийоми їжі. |
| **Прийом їжі** | Слот у дні (сніданок, обід, вечеря, перекус); набір налаштовує сім'я. |
| **Готування** (cooking session) | Факт приготування рецепта з реальними товарами й грамовками. Дає унікальну **страву**. |
| **Страва** | Результат готування: фактична вага й КБЖВ. Її з'їдають порціями в одному чи кількох прийомах їжі. |
| **Закупка** | Сесія покупок за списком, з позиціями, згрупованими за джерелом. |
| **Джерело** | Звідки береться позиція закупки: мережа, `ринок` або `приготую сам`. |
| **Мережа** | Торгова мережа (АТБ, Сільпо…). Ціни прив'язуються до мережі й міста. |
| **Спостереження ціни** | Одна зафіксована ціна товару: хто, де, коли, скільки. |
| **Публічна ціна** | Медіана свіжих спостережень для товару, мережі й міста. |
| **Запис з'їденого** | Скільки персона з'їла: порція страви, товар чи інгредієнт поза меню. |
| **Модерація** | Перевірка адміном контенту від користувачів перед показом усім. |
