# Рецепти

Що таке рецепт у Cookly, хто його створює, як він стає публічним і як виглядає.

- [Рецепти](recipes.md) — склад, кроки, порції, напівфабрикати, обладнання, термін зберігання.
- [Публікація](publishing.md) — приватні рецепти сім'ї, публікація через модерацію, версії.
- [Фото](media.md) — обкладинки, фото приготувань, сховище.
- [Піксельні картинки](pixel-art.md) — детермінована обкладинка з даних рецепта без ШІ.
