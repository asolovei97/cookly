# Джерела даних

Звідки беремо КБЖВ і ціни: що вже вирішено для MVP і що треба дослідити.

## КБЖВ

| Джерело | Що дає | Статус |
|---|---|---|
| USDA FoodData Central | Типові продукти з детальними нутрієнтами | **MVP**: стартовий набір інгредієнтів, переклад і вичитка |
| Користувачі + модерація | Українські товари, яких немає в базі | **MVP** |
| Open Food Facts | Товари за штрихкодом, зокрема українські | **Пізніше**, після юридичної перевірки |

**Open Food Facts**: ліцензія ODbL (база) і Database Contents License (вміст), фото — CC BY-SA. Умови: вказувати джерело і поширювати похідну базу на тих самих умовах (share-alike). API вимагає власний User-Agent і має ліміти. Якщо змішати ці дані з нашою базою, базу, можливо, доведеться відкрити. Тому поки розглядаємо OFF лише як підказку під час створення товару.

## Ціни

| Джерело | Статус |
|---|---|
| Ціни від користувачів, див. [спостереження цін](observations.md) | **MVP** |
| Парсери сайтів мереж (Сільпо, АТБ, Varus, мережі на zakaz.ua) | **Окрема фаза**: адаптер на кожну мережу за спільним інтерфейсом; мережа вмикається лише після перевірки її умов використання |
| Фіскальні чеки (QR-код) | ~~**Дослідити**~~ → **MVP**, див. [чеки](../receipts.md) |

- Публічних API цін у Сільпо, АТБ, Varus не знайдено. Zakaz.ua — платформа доставки для кількох мереж (Novus, Auchan, METRO та інших), а не відкрите джерело даних.
- **QR-код фіскального чека** містить посилання на перевірку чека в Електронному кабінеті ДПС (`cabinet.tax.gov.ua/cashregs/check?...`) з датою, часом, сумою і фіскальним номером. Чи можна отримати звідти **позиції** чека — не підтверджено, потрібен spike. Чеки Сільпо (`receipt.silpo.elkasa.com.ua`) віддають позиції в серверному HTML — з них починаємо, див. [чеки](../receipts.md#адаптери).
