# B8 · Ціни

Спостереження цін від користувачів, медіани за містом і по Україні, викиди, орієнтовна ціна інгредієнта і API цін. Продуктовий опис — у [цінах](../../prices/index.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Спостереження: ручне введення і внутрішній інтерфейс для закупок.
- Місто спостереження з підказкою геолокації.
- Публічна ціна з ланцюжком запасних варіантів.
- Викиди через модуль модерації [B7](../07-moderation/workflow.md#реєстр-типів).
- Орієнтовна ціна інгредієнта.
- Таблиця агрегатів `price_stats`, задачі воркера.
- `GET /v1/prices`.

**Не входить**: запис цін із закупок і порівняння кошика між мережами ([B15](../../roadmap.md#бекенд)), парсери цін і позначка акції ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Місто — у спостереження, необов'язкове; місто сім'ї — лише значення за замовчуванням | Місто сім'ї для всіх спостережень | Людина може готувати в іншому місті кілька днів |
| Геолокація лише як підказка, координати не зберігаються | Обов'язкова геолокація; зовнішній геокодер | Приватність; найближче місто шукаємо у власному довіднику |
| Ринок — ціна на інгредієнт | Обов'язковий товар | На ринку немає SKU |
| Ланцюжок: місто → Україна, 14 → 60 днів | Лише місто за 14 днів | Ціна є навіть за малої кількості даних, з чесною позначкою рівня |
| Перевірка викидів від 3 сімей | Завжди | Медіана з 1–2 спостережень ненадійна |
| Агрегати в `price_stats`, оновлює воркер | Обчислення на кожен запит | Списки закупок запитують сотні цін за раз |
| Копійки цілим числом | Дробові числа | Без помилок округлення |
