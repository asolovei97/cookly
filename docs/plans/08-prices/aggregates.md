# Агрегати

Як зі спостережень виходять публічні ціни, орієнтовні ціни інгредієнтів і відповідь API.

## Публічна ціна товару

Медіана спостережень для пари «товар + джерело» з **ланцюжком запасних варіантів**:

| Рівень | Вибірка | Позначка |
|---|---|---|
| 1 | Місто, 14 днів | — |
| 2 | Україна, 14 днів | — |
| 3 | Місто, 60 днів | `stale` |
| 4 | Україна, 60 днів | `stale` |
| — | Немає даних | ціна невідома |

- «Місто» — місто сім'ї; без нього ланцюжок починається з рівня 2.
- Відповідь містить рівень, свіжість («востаннє бачили N днів тому») і кількість спостережень.
- Вікна задаються в конфігу.
- Для ринку — те саме для пари «інгредієнт + `ринок`».

## Викиди

- Перевірка вмикається, коли у вікні є **щонайменше 3 спостереження від різних сімей**. До того приймається все.
- Спостереження, що відхиляється від медіани **понад ±50%**, отримує статус `pending`, **не враховується** в медіані й потрапляє в модуль модерації [B7](../07-moderation/workflow.md) як тип `price_observation`.
- **Схвалити** → `approved`, враховується в медіані.
- **Відхилити** → `rejected`, назавжди виключається з медіани.
- Сім'я автора бачить свою ціну незалежно від статусу.

## Орієнтовна ціна інгредієнта

- Медіана ціни за кг / л серед **усіх товарів інгредієнта** і **спостережень ринку на цей інгредієнт**.
- Місто за 30 днів → Україна за 30 днів → невідомо.
- Потрібна, поки товар не обрано (меню, оцінка бюджету).

## Таблиця price_stats

- Ключі: «товар + джерело + місто», «товар + джерело + Україна», «інгредієнт + місто», «інгредієнт + Україна».
- Значення: медіана, кількість, дата останнього спостереження для кожного вікна.
- **Унікальна задача воркера** на ключ після кожного нового чи зміненого спостереження (повторні задачі для того самого ключа не дублюються).
- **Нічна задача** перераховує все, бо вікна зсуваються і старі спостереження випадають.

## API

`GET /v1/prices?productIds=…&ingredientIds=…` для кожної позиції повертає:

- ціну в кожній мережі: медіану, рівень, `stale`, свіжість;
- ціну на ринку (для інгредієнтів);
- орієнтовну ціну за кг / л (для інгредієнтів);
- **останню ціну своєї сім'ї** з датою і джерелом.

Порівняння кошика між мережами будується на цьому API в [B15](../../roadmap.md#бекенд).
