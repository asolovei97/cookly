# Спостереження

Одна зафіксована ціна: хто, де, коли, скільки. Концепція — у [спостереженнях цін](../../prices/observations.md).

## Модель

| Поле | Примітка |
|---|---|
| Товар **або** інгредієнт | Інгредієнт — лише для джерела `ринок` |
| Джерело | Мережа з [довідника](../06-catalog/directories.md#мережі) (активна) або `ринок` |
| Місто | **Необов'язкове**, див. нижче |
| Ціна | У копійках, ціле число: за упаковку (`soldBy: package`) або за кг / л (`soldBy: weight`, ринок) |
| Дата | День спостереження |
| Автор | Акаунт і сім'я; назовні не розкривається |
| Походження | `manual` (B8), `purchase` ([B15](../../roadmap.md#бекенд)), згодом `parser` |
| Статус викиду | `none` \| `pending` \| `approved` \| `rejected`, див. [агрегати](aggregates.md#викиди) |

- Валюта — сім'ї (`UAH`).
- Ціна за кг / л рахується під час читання з розміру упаковки й округлюється до копійки.

## Ручне введення

- «Записати ціну» з картки товару: «побачив у магазині».
- `POST /v1/prices/observations`.
- B15 записує ціни з закупок через той самий доменний сервіс (`origin: purchase`).

## Місто й геолокація

- **Місто — у спостереження**, а не в сім'ю. Місто сім'ї ([B5](../05-household/household.md#місто)) — лише значення за замовчуванням.
- **Геолокація — підказка.** Якщо користувач дав дозвіл «під час використання», клієнт під час запису ціни визначає найближче місто і, якщо воно відрізняється від міста сім'ї, пропонує: «Ви у Львові? Записати ціну для Львова».
- Дозвіл на геолокацію просимо **за контекстом**, під час першого запису ціни; він необов'язковий.
- `GET /v1/cities/nearest?lat=&lon=` шукає найближче місто у довіднику `cities`, до якого додаються координати. Зовнішнього геокодера немає.
- **Координати не зберігаються і не логуються**: вони потрібні лише для цього запиту.
- **Без міста** спостереження записується і рахується лише в медіані по Україні.

## Ринок

- Спостереження з джерелом `ринок` може посилатися **прямо на інгредієнт** («куряче філе»), без товару.
- Ціна — за кг / л.

## Обмеження

- **Одне спостереження** на «акаунт + товар/інгредієнт + джерело + день»: повторне замінює попереднє.
- Ручне введення — **не більше 100 на день** від акаунта → `429 prices.rate_limited`.
- Неактивна мережа → `422` з `errors[]` для `/chainId`.

## Приватність

- Назовні видно **лише агрегати** і **останню ціну своєї сім'ї**.
- Автори спостережень в API не розкриваються.

## Приватні й об'єднані продукти

- Спостереження на **приватний продукт без публічної версії** враховуються лише для сім'ї.
- Спостереження на **оригінал з публічною версією** йдуть у медіану публічної версії ([B7](../07-moderation/workflow.md#публічна-копія)).
- Спостереження на **об'єднаний продукт** йдуть в агрегати кінцевого запису (`mergedInto`, [B7](../07-moderation/merge.md)).
