# Імпорт

Від вставленого тексту до збереженого рецепта. Правила — у [B23](../23-llm-assistant/import.md).

## Розбір

`POST /v1/llm/import` з текстом:

| Відповідь | Що бачить людина |
|---|---|
| `422 llm.no_payload` | «У відповіді немає рецепта»: **«Відкрити ще раз»** |
| `422 llm.unsupported_schema` | Пояснення і **оновити застосунок чи повторити запит** |
| `200` з помилками | Те, що розібрано, і **банер** із пропозицією повторити запит |

## Прев'ю рецептів

- **Список рецептів** з відповіді, **чекбокси**, що зберегти.
- На рецепті — рядки зі статусами зіставлення; **незіставлені нагорі**.
- **Тап на рядку** → кандидати, [`CatalogPicker`](../m03-catalog-and-search/picker-and-search.md#catalogpicker), **«Створити продукт»**, **«Прибрати»** ([B23](../23-llm-assistant/import.md#зіставлення)).

## Збереження

`POST /v1/llm/import/{previewId}/save`:

- кнопка активна **завжди**;
- незіставлені рядки **не потрапляють** у рецепт; перед збереженням — **попередження** зі списком;
- після збереження — [редактор M4](../m04-recipes/editor.md#llm) з дією **«Готувати»**.

## Без мережі

- Збір промпту й розбір **потребують сервера**: кнопки неактивні з поясненням.
- Скопійована відповідь лишається в буфері; вставити її можна, коли мережа з'явиться.
