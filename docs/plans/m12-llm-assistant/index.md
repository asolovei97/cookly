# M12 · LLM-асистент

Клієнтська частина запиту у власну LLM: прев'ю даних, відкриття провайдера, повернення відповіді через кнопку чи share і збереження рецептів. Спирається на [B23](../23-llm-assistant/index.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Входи «Що приготувати?» й «Оцінити раціон».
- Прев'ю даних, вибір провайдера, параметри.
- Відкриття за `mode`, екран очікування.
- Share extension (нативна зміна).
- Прев'ю рецептів, зіставлення, збереження.

**Не входить**: меню на тиждень від LLM, Custom GPT, MCP ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Входи на своїх екранах | У панелі «+» | Панель лишається з трьома щоденними діями |
| Копіювання лише після тапа | Автоматично | Користувач контролює, що йде назовні |
| Екран очікування живе 24 години | Лише поки відкритий застосунок | LLM думає довго, людина може відволіктися |
| Збереження активне завжди | Блокувати незіставленим | Необов'язкове не блокує; людина бачить попередження |
| Share extension у нативній збірці | Лише кнопка вставки | На телефоні «Поділитися» зручніше за копіювання |
