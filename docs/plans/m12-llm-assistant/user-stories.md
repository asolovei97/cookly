# Юзер-сторі — LLM-асистент

Критерії приймання для [плану M12](index.md). AC перевіряються Maestro на варіанті `testing` з заздалегідь підготовленими відповідями або RNTL. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MLLM-1 — Входи
Як користувач, я хочу запитати свою LLM, що приготувати.

**AC-1.1 (Рецепти):**
- Given `llm` і `llm.cook_from_pantry` увімкнено,
- When відкривається вкладка «Рецепти»,
- Then кнопка «Що приготувати?».

**AC-1.2 (Статистика):**
- Given `llm.diet_analysis` увімкнено,
- When відкривається статистика,
- Then кнопка «Оцінити раціон».

**AC-1.3 (Вимкнено):**
- Given `llm` off,
- When відкриваються ці екрани,
- Then кнопок немає.

## US-MLLM-2 — Прев'ю даних
Як користувач, я хочу бачити, що піде в LLM.

**AC-2.1 (За замовчуванням):**
- Given сценарій `diet_analysis`,
- When відкривається прев'ю,
- Then вага, ціль, вік, зріст вимкнені.

**AC-2.2 (Алергії):**
- Given `cook_from_pantry` й алергія в сім'ї,
- When відкривається прев'ю,
- Then алергії увімкнені, є пояснення.

**AC-2.3 (Провайдер):**
- Given минулого разу обрано Claude,
- When відкривається прев'ю,
- Then обрано Claude, кнопка «Відкрити в Claude».

## US-MLLM-3 — Відкриття
Як користувач, я хочу відкрити LLM одним тапом.

**AC-3.1 (URL):**
- Given `mode: url`,
- When тап на кнопку,
- Then діплінк, буфер без змін.

**AC-3.2 (Буфер):**
- Given Gemini,
- When тап на кнопку,
- Then промпт у буфері, тост, провайдер відкрито.

**AC-3.3 (Аналіз):**
- Given `diet_analysis`,
- When LLM відкрито,
- Then екран лише з «Відкрити ще раз» і «Готово».

## US-MLLM-4 — Повернення
Як користувач, я хочу легко повернути відповідь.

**AC-4.1 (Буфер не читається сам):**
- Given повернення в застосунок,
- When екран очікування відкрито,
- Then буфер не прочитано; читання лише після «Вставити відповідь».

**AC-4.2 (Повернутися пізніше):**
- Given екран закрито 3 години тому,
- When відкривається «Рецепти»,
- Then чип повертає на екран очікування; після 24 годин чипа немає.

**AC-4.3 (Share):**
- Given текст відповіді в LLM-застосунку,
- When «Поділитися» → Cookly,
- Then текст на екрані розбору.

**AC-4.4 (Без блоку):**
- Given текст без JSON,
- When вставлено,
- Then «У відповіді немає рецепта» і «Відкрити ще раз».

## US-MLLM-5 — Прев'ю рецептів
Як користувач, я хочу перевірити рецепт перед збереженням.

**AC-5.1 (Вибір):**
- Given 3 рецепти,
- When обрано 1 і збережено,
- Then створено один приватний рецепт.

**AC-5.2 (Незіставлені нагорі):**
- Given 2 незіставлені рядки,
- When відкривається рецепт,
- Then вони нагорі.

**AC-5.3 (Часткова помилка):**
- Given другий рецепт невалідний,
- When показується прев'ю,
- Then перший доступний, банер пропонує повторити запит.

## US-MLLM-6 — Збереження й офлайн
Як користувач, я не хочу, щоб дрібниці блокували мене.

**AC-6.1 (З незіставленим):**
- Given незіставлений рядок,
- When «Зберегти»,
- Then попередження зі списком; після згоди рецепт без цього рядка.

**AC-6.2 (Далі):**
- Given збережено,
- When відкривається екран,
- Then редактор M4 і дія «Готувати».

**AC-6.3 (Без мережі):**
- Given немає мережі,
- When відкривається прев'ю даних чи екран очікування,
- Then кнопки неактивні з поясненням.
