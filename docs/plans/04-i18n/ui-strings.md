# Рядки інтерфейсу

Тексти мобільного застосунку, які можна редагувати з адмінки без релізу. Адмінка лише українською: її тексти лежать у коді адмінки й через цей сервіс не проходять.

## Модель

- Таблиця `ui_strings (key, lang, value, edited_by_admin, deprecated)`.
- Ключі — `<розділ>.<елемент>`, наприклад `auth.login.title`.
- Тексти помилок — ключі `error.<code>`, наприклад `error.auth.invalid_token`. Якщо ключа немає, клієнт показує `error.generic`.

## Формат

- **ICU MessageFormat** з підстановками і формами множини:
  `{count, plural, one {# порція} few {# порції} many {# порцій} other {# порції}}`.
- Під час збереження в адмінці бекенд перевіряє синтаксис і наявність форм множини, потрібних мові. Помилка → `422 i18n.invalid_message`.
- Клієнт використовує FormatJS або i18next-icu — вибір у [M1](../../roadmap.md#мобільний-застосунок).

## Цикл ключів

1. **Розробник** додає ключ і тексти у вихідні файли репозиторію: `i18n/mobile/uk.json`, `i18n/mobile/en.json`.
2. **`api i18n sync`** запускається під час деплою, як міграції:
   - додає нові ключі в БД;
   - **не перезаписує** значення, які відредагував адмін (`edited_by_admin`);
   - оновлює значення, яких адмін не чіпав;
   - ключі, яких більше немає у файлах, позначає `deprecated`. Вони не потрапляють у пакет, але лишаються в БД.
3. **Адмін** редагує тексти в адмінці (право «переклади»).
4. **`api i18n export`** перед релізом мобільного застосунку вивантажує актуальні тексти з БД у файли, які вбудовуються в збірку як запасний варіант.

## Пакети

- `GET /v1/i18n/{lang}` — **публічний** (`security: []`), бо рядки потрібні ще до входу.
- Повертає весь пакет мови: `{ "version": 42, "strings": { … } }` з заголовком `ETag`.
- `If-None-Match` з поточним `ETag` → `304`.
- **Версія** пакета зростає з кожною зміною рядків цієї мови (правка адміна чи `sync`).
- Невідома чи вимкнена мова → `404 i18n.language_not_found`.

## Клієнт

- Завантажує пакет мови користувача, кешує його і перевіряє оновлення через `ETag`.
- Якщо бекенд недоступний — використовує кеш, а без кешу — вбудований у збірку пакет.
