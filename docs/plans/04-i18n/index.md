# B4 · Переклади

Багатомовний контент і рядки інтерфейсу мобільного застосунку. Продуктовий опис — у [перекладах](../../i18n.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Бібліотека для контенту: тип `i18n.Text`, вибір мови з запасними варіантами, позначка застарілих перекладів, нормалізація для пошуку, реєстр сутностей для черги перекладів.
- Таблиця `languages`.
- Сервіс рядків інтерфейсу мобільного застосунку: `ui_strings`, ICU, пакети, `sync` / `export`.
- Адмін-API перекладів: контент і рядки.

**Не входить**: самі перекладні сутності (інгредієнти, обладнання…) — вони з'являються з [B6](../../roadmap.md#бекенд). Контентні AC у B4 перевіряються на тестовій таблиці, що існує лише в тестах. Домени реєструють свої сутності в черзі й повторно використовують ті самі перевірки.

## Документи

- [Контент](content.md) — `i18n.Text`, мова запиту, форма API, мови, застарілі переклади, черга, пошук.
- [Рядки інтерфейсу](ui-strings.md) — ICU MessageFormat, цикл `sync` / `export`, пакети, тексти помилок.
- [Юзер-сторі](user-stories.md) — US-I18N-1…10.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| JSONB `{lang: value}` + `source_lang` | Окрема таблиця перекладів | Простіше читати й писати; весь контент в одному записі |
| API застосунку віддає вибраний рядок, адмін-API — мапу | Мапа всюди | Клієнт не знає про запасні мови; адміну потрібні всі мови |
| Таблиця `languages` | Список у конфігу | Мову можна наповнити, поки вона вимкнена, й увімкнути без деплою |
| `i18n_outdated text[]` | Не відстежувати застарілі | Дешево, а неактуальний переклад інакше лишається непоміченим |
| ICU MessageFormat | Прості шаблони | В українській кілька форм множини |
| Вихідні файли в репо + `sync` у БД + `export` у збірку | Лише БД чи лише файли | Розробник додає ключі в коді, адмін править тексти без релізу, а збірка має актуальний запасний варіант |
| Адмінка лише українською | Адмінка через `ui_strings` | Адмінкою користуються кілька людей, усі україномовні |
