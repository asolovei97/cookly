# B7 · Модерація

Як контент від користувачів стає доступним усім: подання, черга, схвалення з публічною копією, пропозиції оновлення, відхилення й об'єднання дублікатів. Продуктовий опис — у [модерації](../../catalog/moderation.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Загальний модуль модерації: реєстр типів, черга, дії, причини, м'яке блокування, аудит.
- Застосування до інгредієнтів і товарів.
- Публічна копія і пропозиції оновлення від автора.
- Об'єднання дублікатів, кандидати в дублікати.
- Принцип знімків в історії.

**Не входить**: ціни-викиди ([B8](../../roadmap.md#бекенд)), фото ([B10](../../roadmap.md#бекенд)), публічні рецепти ([B11](../../roadmap.md#бекенд)) — вони реєструються в модулі у своїх пунктах. Пропозиції від будь-якої сім'ї — [майбутнє](../../future.md).

## Документи

- [Об'єднання](merge.md) — кандидати в дублікати, `mergedInto`, переписування посилань, знімки в історії.
- [Юзер-сторі](user-stories.md) — US-MOD-1…8.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Загальний модуль з реєстром типів | Окрема модерація для кожної сутності | Однакові черга, дії й аудит для продуктів, цін, фото й рецептів |
| Прапорець «Поділитися з усіма» | Автоматичне подання всього | Не все приватне потрібне всім («Мамин домашній сир») |
| Схвалення створює публічну копію | Передача власності публічному запису | Автор далі редагує свій оригінал, а зміни для всіх ідуть через модерацію; як у [рецептах](../../recipes/publishing.md) |
| Пропозиції оновлення лише від автора | Від будь-якої сім'ї | Простіше для MVP; модель пропозицій уже це підтримує |
| `mergedInto` + переписування активних посилань воркером | Миттєве переписування всього | Об'єднання швидке, історія не змінюється |
| Знімки КБЖВ в історії | Живі посилання на каталог | Правка модератора не має переписувати статистику дефіциту заднім числом |
