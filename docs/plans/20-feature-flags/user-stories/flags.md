# Юзер-сторі — прапорці

US-FLAG-1…5. Загальні правила — в [індексі юзер-сторі](index.md).

## US-FLAG-1 — Обчислення
Як адмін, я хочу передбачувано вмикати фічу частині людей.

**AC-1.1 (Глобально вимкнено):**
- Given прапорець `receipts` з `enabled = false` і сім'я в групі дозволу,
- When сім'я запитує `GET /v1/features`,
- Then `receipts.enabled = false`.

**AC-1.2 (Заборона сильніша за групу):**
- Given сім'я одночасно в `denyHouseholds` і в групі дозволу,
- When обчислюється прапорець,
- Then off.

**AC-1.3 (Платформа):**
- Given прапорець лише для `ios`,
- When запит з `X-App-Platform: android`,
- Then off.

## US-FLAG-2 — Rollout за сім'єю
Як учасник сім'ї, я хочу мати той самий набір фіч, що й інші учасники.

**AC-2.1 (Однаково в сім'ї):**
- Given `rolloutPercent = 30` і сім'я з двома акаунтами,
- When обидва запитують `GET /v1/features`,
- Then обидва отримують однакове значення.

**AC-2.2 (Стабільність):**
- Given сім'я отримала фічу при 30%,
- When відсоток піднімають до 50%,
- Then фіча лишається увімкненою.

**AC-2.3 (Без сім'ї):**
- Given акаунт без сім'ї,
- When обчислюється відсоток,
- Then хеш береться від `accountId`.

## US-FLAG-3 — Групи
Як адмін, я хочу відкрити бета-фічу групі тестувальників.

**AC-3.1 (Група сімей):**
- Given група сімей `beta` у `allowGroups` і `rolloutPercent = 0`,
- When сім'я з групи запитує набір,
- Then фіча on, а для сім'ї поза групою — off.

**AC-3.2 (Прев'ю):**
- Given сім'я X у групі `beta`,
- When `GET /admin/v1/features/preview?householdId=X`,
- Then відповідь показує значення кожного прапорця і правило, що спрацювало.

## US-FLAG-4 — Кор-фічі й небезпечні зміни
Як адмін, я хочу аварійно вимкнути фічу, але не зробити цього випадково.

**AC-4.1 (Правила для кор-фічі):**
- Given кор-фіча `shopping`,
- When `PATCH` додає їй `rolloutPercent`,
- Then `422 feature.core_rules`.

**AC-4.2 (Без причини):**
- Given кор-фіча `shopping`,
- When `PATCH` з `enabled = false` без причини,
- Then `422 feature.reason_required`.

**AC-4.3 (Подвійне підтвердження):**
- Given причина вказана, але `confirm` немає,
- When надходить `PATCH`,
- Then зміна не застосовується, а відповідь містить кількість зачеплених сімей; з `confirm: true` — застосовується і пишеться в аудит.

**AC-4.4 (Права):**
- Given адмін лише з роллю `moderator`,
- When він змінює прапорець,
- Then `403 admin.forbidden`.

## US-FLAG-5 — Публічні прапорці
Як користувач до входу, я хочу бачити актуальний екран входу.

**AC-5.1 (Без токена):**
- Given публічний прапорець `auth.google` і непублічний `receipts`,
- When `GET /v1/features` без токена,
- Then у відповіді лише `auth.google`.

**AC-5.2 (Ключ, якого немає в коді):**
- Given прапорець позначено `retired`,
- When будь-хто запитує набір,
- Then його немає у відповіді.
