# Юзер-сторі — фіча-прапорці

Критерії приймання для [плану фіча-прапорців](../index.md). AC перевіряються на рівні API, зокрема через `POST /v1/sync/ops` і адмін-ендпоінти. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Прапорці](flags.md) — US-FLAG-1…5: обчислення, rollout за сім'єю, групи, кор-фічі й небезпечні зміни, публічні прапорці.
- [Застосування](enforcement.md) — US-FLAG-6…9: `x-feature`, версія фічі, синхронізація й воркер, версія прапорців і глобальна мінімальна версія.
