# Юзер-сторі — застосування

US-FLAG-6…9. Загальні правила — в [індексі юзер-сторі](index.md).

## US-FLAG-6 — x-feature
Як розробник, я хочу, щоб вимкнена фіча була недоступна й через API.

**AC-6.1 (Вимкнена фіча):**
- Given операція з `x-feature: receipts` і прапорець off для сім'ї,
- When сім'я викликає операцію,
- Then `403 feature.disabled` з `feature: "receipts"`.

**AC-6.2 (Ядро):**
- Given операція без `x-feature`,
- When прапорці будь-які,
- Then операція виконується.

**AC-6.3 (Контракт і реєстр):**
- Given у контракті `x-feature: unknown_key`, якого немає в реєстрі,
- When запускається перевірка CI,
- Then вона падає.

## US-FLAG-7 — Версія фічі
Як користувач старої версії, я хочу користуватися застосунком, навіть якщо одна фіча змінилася.

**AC-7.1 (Лише ця фіча):**
- Given `minFeatureVersion` закупки для `ios` — `2.0.0` і застосунок `1.9.0`,
- When викликається операція закупки,
- Then `426 feature.upgrade_required` з `minVersion: "2.0.0"`, а операції плану меню виконуються.

**AC-7.2 (Без версії):**
- Given запит адмінки без `X-App-Version`,
- When викликається операція фічі з `minFeatureVersion`,
- Then версія фічі не перевіряється.

## US-FLAG-8 — Синхронізація й воркер
Як користувач, я не хочу втратити офлайн-дані, якщо фічу вимкнули.

**AC-8.1 (Операція вимкненої фічі):**
- Given тип `shopping.item.check@1` з `feature: shopping` і фіча off,
- When операція надходить у `POST /v1/sync/ops`,
- Then `rejected` з `feature.disabled`, а наступна залежна операція — `sync.dependency_failed`.

**AC-8.2 (Повтор після ввімкнення):**
- Given та сама операція з тим самим `opId`,
- When фічу ввімкнули і пакет надійшов знову,
- Then `applied`.

**AC-8.3 (Воркер):**
- Given задача імпорту чека для сім'ї з вимкненою фічею `receipts`,
- When воркер бере задачу,
- Then вона `skipped` без повторів.

## US-FLAG-9 — Версія прапорців і глобальна мінімальна версія
Як користувач, я хочу отримувати зміни прапорців без перезапуску застосунку.

**AC-9.1 (Заголовок версії):**
- Given клієнт закешував набір версії 41,
- When адмін змінює прапорець,
- Then наступна відповідь API будь-якого інстансу протягом 30 секунд має `X-Features-Version: 42`.

**AC-9.2 (Глобальна версія з адмінки):**
- Given у таблиці налаштувань мінімальна версія `android` — `1.5.0`, а в env — `1.0.0`,
- When запит з `X-App-Version: 1.2.0`,
- Then `426 app.upgrade_required` з `minVersion: "1.5.0"`.

**AC-9.3 (Порожня таблиця):**
- Given налаштувань немає,
- When запит з будь-якою версією,
- Then діє значення з env.
