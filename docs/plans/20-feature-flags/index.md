# B20 · Фіча-прапорці й версії

Прапорці з таргетингом, групи, мінімальна версія фічі й глобальна мінімальна версія застосунку в адмінці. Так не-кор фічі відкриваються частині людей, а кардинальна зміна однієї фічі не вимагає перевстановлювати весь застосунок. Продуктовий опис — у [фіча-прапорцях](../../feature-flags.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Реєстр фіч у коді, прапорці, правила, групи сімей і користувачів.
- Кор-фічі й публічні прапорці.
- `GET /v1/features`, `X-Features-Version`, кеш у пам'яті з pub/sub у Redis.
- `x-feature` у контракті, `403 feature.disabled`, `426 feature.upgrade_required`.
- Операції синхронізації й задачі воркера за прапорцями.
- Глобальна мінімальна версія в таблиці налаштувань.
- Адмін-ендпоінти: правила, групи, прев'ю, аудит, застарілі прапорці.

**Не входить**: EAS Update і клієнтський кеш ([M10](../../roadmap.md#мобільний-застосунок)), екрани адмінки ([A7](../../roadmap.md#адмінка)), A/B-аналітика й варіанти.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Власна реалізація | Unleash, GrowthBook, Flagsmith | Керування в нашій адмінці з ролями й аудитом, без зайвої інфраструктури |
| Булевий прапорець, `variant` завжди `null` | Варіанти для A/B зараз | Аналітики A/B немає; поле додане заздалегідь, контракт не зламається |
| Rollout за сім'єю | За користувачем | Закупка й план спільні — у сім'ї має бути однаковий набір фіч |
| Ключі в коді, адмін редагує лише правила | Ключі створює адмін | Ключ без коду нічого не вмикає; CI звіряє контракт із реєстром |
| Мінімальна версія фічі → `426` лише для цієї фічі | Лише глобальна мінімальна версія | Зміна однієї фічі не відрізає весь застосунок |
| Публічний набір до входу, решта після | Усе після входу; усе до входу | Вхід і онбординг теж треба перемикати, а список внутрішніх фіч не видно назовні |
| Обчислення в пам'яті з pub/sub | Похід у БД на кожен запит | Прапорці перевіряються майже на кожному запиті |
| Кор-фічу вимкнути можна лише з причиною й подвійним підтвердженням | Заборонити; без підтверджень | Аварійний рубильник потрібен, але помилка вимикає застосунок для всіх |
