# Промпти

Як сервер збирає промпт з даними користувача і повертає діплінки.

## Запит

`POST /v1/llm/prompts/{scenario}`:

- **вхід**: блоки даних, які користувач залишив увімкненими в прев'ю, параметри сценарію (персона, період, порції), провайдер;
- **вихід**: текст промпту, `mode` (`url` | `clipboard`) і діплінк для кожного провайдера шаблону.

Спершу клієнт отримує **прев'ю**: `GET /v1/llm/prompts/{scenario}/preview?personId=` — перелік блоків з даними й позначкою, які увімкнено за замовчуванням.

## Блоки даних

### cook_from_pantry

| Блок | За замовчуванням |
|---|---|
| Запаси: назва + кількість або «є» | Увімкнено |
| Обладнання сім'ї | Увімкнено |
| Кількість порцій | Увімкнено (персони сім'ї) |
| Неулюблене персон | Увімкнено |
| **Алергії** персон | **Увімкнено** — рецепт з алергеном небезпечний |

### diet_analysis

| Блок | За замовчуванням |
|---|---|
| Підсумки днів проти норми за 7 або 30 днів ([B17](../17-nutrition-log/days.md#підсумки-днів)) | Увімкнено |
| Топ продуктів за період | Увімкнено |
| Вага й тренд ([B18](../18-budget-and-stats/stats.md#вага)) | Вимкнено |
| Ціль | Вимкнено |
| Вік і зріст | Вимкнено |

- Персону обирають за правилами видимості [B5](../05-household/household.md#видимість): вагу персони з акаунтом може додати лише вона сама; інакше блок недоступний.

## Стиснення

- Дані пишуться компактними рядками: `молоко 900 мл; яйця 6 шт; рис є`.
- Порядок і формат блоків задає шаблон; сервер лише підставляє текст.

## Діплінки

| Провайдер | `mode: url` | `mode: clipboard` |
|---|---|---|
| ChatGPT | `chatgpt.com/?q=<промпт>` | `chatgpt.com/` + промпт у буфер |
| Claude | `claude.ai/new?q=<промпт>` | `claude.ai/new` + промпт у буфер |
| Gemini | — | `gemini.google.com/app` + промпт у буфер |

- Для кожного провайдера в конфігу — `maxUrlLength`; закодований промпт довший → `mode: clipboard`.
- Gemini завжди `clipboard`: параметра для готового промпту немає.
- Клієнт відкриває діплінк у застосунку провайдера, якщо той встановлений, інакше в браузері.

## Відповідь, що очікується

- `cook_from_pantry` — шаблон просить відповісти JSON-блоком за схемою `cookly/v1/recipe` ([імпорт](import.md#схема)).
- `diet_analysis` — лише текст; повернення в застосунок немає.
- Кожне збирання промпту збільшує лічильник «відкриття» ([шаблони](templates.md#лічильники)).
