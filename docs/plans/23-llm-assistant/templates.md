# Шаблони

Версіоновані шаблони промптів, якими керує адмін.

## Модель

| Поле | Примітка |
|---|---|
| Сценарій | `cook_from_pantry`, `diet_analysis`; задається в коді |
| Версія | Ціле число, зростає з кожною новою версією |
| Статус | `draft` · `active` · `archived` |
| Текст | JSONB за мовами інтерфейсу (`uk`, `en`), з плейсхолдерами блоків даних ([промпти](prompts.md#блоки-даних)) |
| Схема відповіді | `cookly/v1/recipe` або `none` (лише текст) |
| Провайдери | Підмножина `chatgpt`, `claude`, `gemini` |
| Прапорець | Ключ сценарію, див. нижче |

- **Активна лише одна версія** на сценарій; активація нової архівує попередню.
- **Відкат** — повторна активація архівної версії.
- Мови немає в тексті → береться `source_lang` шаблону, як у [B4](../04-i18n/content.md#вибір-рядка).
- Невідомий плейсхолдер у тексті → `422 llm.unknown_placeholder` під час збереження.
- Сценарії й схеми задаються в коді; адмін не створює нових сценаріїв.

## Схема відповіді

- Сервер підтримує **поточну й попередню** версії схеми сценарію, поки активний шаблон не перейде на нову ([імпорт](import.md#схема)).
- Нова версія схеми — нова назва (`cookly/v2/recipe`), стара працює далі.

## Адмінка

Право `llm.templates.manage` — лише `admin` ([B3](../03-admin-auth/access.md#ролі-й-права)).

| Метод і шлях | Що робить |
|---|---|
| `GET /admin/v1/llm/templates` | Шаблони за сценаріями з версіями й лічильниками |
| `POST /admin/v1/llm/templates` | Нова версія `draft` |
| `PATCH /admin/v1/llm/templates/{id}` | Змінити `draft` |
| `POST /admin/v1/llm/templates/{id}/preview` | Зібрати промпт на тестових даних, з довжиною і `mode` для кожного провайдера |
| `POST /admin/v1/llm/templates/{id}/activate` | Активувати (зокрема відкат на архівну) |

- Активна чи архівна версія не редагується → `409 llm.template_locked`; зміни — лише новою версією.
- Активація пишеться в [аудит](../03-admin-auth/audit-and-users.md).

## Лічильники

- На шаблон, версію й провайдера: **відкриття** промпту, **імпорти** відповіді, **збереження** рецептів.
- Лише числа, без даних користувачів ([імпорт](import.md#приватність)).

## Прапорці

| Ключ | Тип | Що вимикає |
|---|---|---|
| `llm` | `optional` | Усю фічу |
| `llm.cook_from_pantry` | `optional` | Сценарій «що приготувати» |
| `llm.diet_analysis` | `optional` | Сценарій «аналіз раціону» |

Ендпоінти оголошують `x-feature` ([B20](../20-feature-flags/enforcement.md#x-feature)); вимкнений сценарій → `403 feature.disabled`.
