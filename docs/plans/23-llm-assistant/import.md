# Імпорт

Як відповідь LLM повертається в застосунок і стає приватним рецептом.

## Схема

```json
{
  "schema": "cookly/v1/recipe",
  "recipes": [
    {
      "name": "Омлет з сиром",
      "servings": 2,
      "ingredients": [{ "name": "яйця", "quantity": 4, "unit": "шт" }],
      "steps": ["Збити яйця…"],
      "equipment": ["сковорідка"],
      "timeMinutes": 15
    }
  ]
}
```

- Обов'язкові: `schema`, `recipes[].name`, `servings`, `ingredients`.
- Невідомі поля ігноруються, як у [терплячого читача](../01-backend-bootstrap/http-and-errors.md#еволюція-api).
- Підтримуються **поточна й попередня** версії схеми ([шаблони](templates.md#схема-відповіді)).

## Вставка

- Екран очікування має кнопку **«Вставити відповідь»** — клієнт читає буфер лише після натискання.
- **Share extension**: «Поділитися» з LLM-застосунку в Cookly відкриває той самий екран з текстом.
- Повернення в застосунок відкриває екран очікування, але буфер **не читає** сам.

## Розбір

`POST /v1/llm/import` з сирим текстом:

1. Знаходить JSON-блок з полем `schema` (зокрема всередині markdown-блоку коду).
2. Валідує за схемою.
3. Зіставляє рецепти з каталогом (нижче) і повертає **прев'ю**.

| Ситуація | Відповідь |
|---|---|
| JSON-блоку немає | `422 llm.no_payload` |
| Невідома схема | `422 llm.unsupported_schema` |
| Блок частково невалідний | `200` з тим, що вдалося розібрати, і переліком помилок; клієнт пропонує повторити запит |

## Зіставлення

| Що | З чим | Нижче порогу впевненості |
|---|---|---|
| Інгредієнт | Найкращий збіг [пошуку каталогу](../06-catalog/search.md#пошук-за-текстом) з оцінкою | «Оберіть» |
| Одиниця | [Одиниці каталогу](../06-catalog/units.md) | Базова одиниця з позначкою |
| Обладнання | Довідник [обладнання](../06-catalog/directories.md#обладнання) | Пропускається з позначкою |

- Незіставлений інгредієнт користувач **замінює**, **створює** як продукт ([B6](../06-catalog/ingredients-and-products.md)) або **прибирає**.
- Поріг впевненості — параметр конфігу.
- Збереження не блокується: незіставлені рядки **не потрапляють** у рецепт, клієнт попереджає про це ([M12](../m12-llm-assistant/import.md#збереження)).

## Збереження

- Користувач обирає, **які рецепти** з відповіді зберегти.
- Кожен стає **приватним рецептом** сім'ї ([B9](../09-recipes/structure.md#поля-рецепта)) з `source: llm` і провайдером.
- Кроки — текстом; коефіцієнт виходу — `1,0` за замовчуванням ([B9](../09-recipes/composition.md#типовий-вихід)); КБЖВ рахуються як завжди (`recipe_nutrition`).
- Після збереження можна одразу почати [готування](../16-cooking/session.md#старт).
- `POST /v1/llm/import/{previewId}/save` зі списком рецептів і рішеннями по рядках.

## Приватність

- Зібрані промпти **не зберігаються**.
- Сирий текст імпорту й прев'ю **видаляються** після збереження чи скасування, а незавершені — через 24 години.
- Лишаються лише [лічильники](templates.md#лічильники).
