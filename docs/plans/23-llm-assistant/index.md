# B23 · LLM-асистент

Запит у власну LLM користувача (ChatGPT, Claude, Gemini) за готовим промптом з його даними і повернення структурованої відповіді в застосунок. Сервер збирає промпт за версіонованим шаблоном, віддає діплінки й розбирає вставлену відповідь у прев'ю приватного рецепта. Продуктовий опис — у [LLM-асистенті](../../llm-assistant.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Шаблони промптів: версії, мови, схеми відповіді, провайдери, активація й відкат, лічильники.
- Збирання промпту: блоки даних, значення за замовчуванням, стиснення, діплінки, `mode: clipboard`.
- Сценарії `cook_from_pantry` (з поверненням) і `diet_analysis` (лише текст).
- Імпорт відповіді: схема `cookly/v1/recipe`, розбір, зіставлення з каталогом, збереження приватного рецепта.
- Прапорці `llm`, `llm.cook_from_pantry`, `llm.diet_analysis`.

**Не входить**: екрани й share extension ([M12](../../roadmap.md#мобільний-застосунок)), редактор шаблонів в адмінці ([A10](../../roadmap.md#адмінка)), меню на тиждень від LLM, Custom GPT і MCP ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Промпт збирає сервер | Рендер на клієнті | Шаблон і дані на сервері; шаблон міняється без релізу; офлайн однаково не потрібен |
| Текст промпту окремо для кожної мови | Один англійський | Відповідь має бути мовою користувача |
| Алергії в промпті за замовчуванням | Як інше чутливе — вимкнено | Рецепт з алергеном небезпечний; користувач бачить це в прев'ю |
| `mode: clipboard`, якщо промпт задовгий | Обрізати дані | Нічого не губиться; Gemini й так працює через буфер |
| Розбір і зіставлення на сервері | На клієнті | Зіставлення потребує каталогу |
| Кнопка «Вставити відповідь» | Автоперевірка буфера | iOS показує банер на кожне читання буфера |
| Промпти не зберігаються | Журнал промптів | Вони містять персональні дані; адмінці досить лічильників |
| Одна активна версія на сценарій, відкат | Кілька активних | Передбачувано; помилку в промпті виправляє відкат |
