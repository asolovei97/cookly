# Юзер-сторі — LLM-асистент

Критерії приймання для [плану LLM-асистента](index.md). AC перевіряються на рівні API і адмін-ендпоінтів. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

## US-LLM-1 — Шаблони
Як адмін, я хочу виправити промпт без релізу застосунку.

**AC-1.1 (Активація):**
- Given активна версія 3 шаблону `cook_from_pantry` і `draft` версії 4,
- When активують версію 4,
- Then версія 3 `archived`, наступні промпти збираються за версією 4, активацію записано в аудит.

**AC-1.2 (Відкат):**
- Given активна версія 4,
- When активують архівну версію 3,
- Then промпти збираються за версією 3.

**AC-1.3 (Незмінність):**
- Given активна версія,
- When її намагаються змінити,
- Then `409 llm.template_locked`.

**AC-1.4 (Невідомий плейсхолдер):**
- Given текст з `{{unknown}}`,
- When `draft` зберігають,
- Then `422 llm.unknown_placeholder`.

## US-LLM-2 — Прев'ю даних
Як користувач, я хочу бачити, що піде в LLM.

**AC-2.1 (Що приготувати):**
- Given сім'я з запасами, обладнанням і алергією на арахіс,
- When `GET /v1/llm/prompts/cook_from_pantry/preview`,
- Then усі блоки, зокрема алергії, увімкнено за замовчуванням.

**AC-2.2 (Аналіз раціону):**
- Given персона з акаунтом,
- When вона запитує прев'ю `diet_analysis`,
- Then вага, ціль, вік і зріст вимкнено за замовчуванням.

**AC-2.3 (Чужа вага):**
- Given мама обирає тата з акаунтом для аналізу,
- When читається прев'ю,
- Then блок ваги недоступний.

## US-LLM-3 — Промпт і діплінки
Як користувач, я хочу відкрити свою LLM з готовим запитом одним тапом.

**AC-3.1 (Блоки за вибором):**
- Given блок алергій вимкнено,
- When `POST /v1/llm/prompts/cook_from_pantry`,
- Then у тексті промпту немає алергій.

**AC-3.2 (URL):**
- Given промпт коротший за `maxUrlLength` ChatGPT,
- When обрано ChatGPT,
- Then `mode: url` і діплінк `chatgpt.com/?q=…`.

**AC-3.3 (Задовгий):**
- Given промпт довший за `maxUrlLength`,
- When обрано Claude,
- Then `mode: clipboard`, діплінк `claude.ai/new` і текст промпту.

**AC-3.4 (Gemini):**
- Given будь-який промпт,
- When обрано Gemini,
- Then `mode: clipboard`.

**AC-3.5 (Мова):**
- Given мова інтерфейсу `en` і текст шаблону `uk` та `en`,
- When збирається промпт,
- Then використано англійський текст.

## US-LLM-4 — Розбір
Як користувач, я хочу вставити відповідь і побачити рецепт.

**AC-4.1 (Блок у markdown):**
- Given текст відповіді з поясненням і JSON у блоці коду зі `schema: cookly/v1/recipe`,
- When `POST /v1/llm/import`,
- Then прев'ю з рецептами.

**AC-4.2 (Немає блоку):**
- Given текст без JSON,
- When `POST /v1/llm/import`,
- Then `422 llm.no_payload`.

**AC-4.3 (Частково невалідний):**
- Given два рецепти, другий без `ingredients`,
- When `POST /v1/llm/import`,
- Then `200` з першим рецептом і помилкою для другого.

## US-LLM-5 — Зіставлення
Як користувач, я хочу, щоб інгредієнти з відповіді стали продуктами каталогу.

**AC-5.1 (Збіг):**
- Given інгредієнт «яйця 4 шт» і в каталозі «Яйця курячі»,
- When будується прев'ю,
- Then рядок зіставлено з «Яйця курячі», 4 шт.

**AC-5.2 (Нижче порогу):**
- Given інгредієнт «соус тартар», для якого немає впевненого збігу,
- When будується прев'ю,
- Then рядок позначено «оберіть».

## US-LLM-6 — Збереження
Як користувач, я хочу зберегти рецепт і одразу готувати.

**AC-6.1 (Приватний рецепт):**
- Given прев'ю з двома рецептами,
- When зберігають лише перший,
- Then створено один приватний рецепт з `source: llm` і провайдером, коефіцієнтом виходу 1,0 і розрахованими КБЖВ.

## US-LLM-7 — Приватність і прапорці
Як користувач, я не хочу, щоб мої дані зберігалися без потреби.

**AC-7.1 (Без промптів):**
- Given зібрано промпт,
- When читаються дані сервера,
- Then тексту промпту немає, лічильник «відкриття» зріс.

**AC-7.2 (Видалення імпорту):**
- Given незавершене прев'ю 25 годин тому,
- When виконується задача очищення,
- Then сирий текст і прев'ю видалено.

**AC-7.3 (Вимкнений сценарій):**
- Given прапорець `llm.diet_analysis` off,
- When `POST /v1/llm/prompts/diet_analysis`,
- Then `403 feature.disabled`.
