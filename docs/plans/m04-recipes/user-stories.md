# Юзер-сторі — рецепти

Критерії приймання для [плану M4](index.md). AC перевіряються Maestro на варіанті `testing` або RNTL. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MREC-1 — Пошук
Як користувач, я хочу знайти, що приготувати на своїй кухні.

**AC-1.1 (Обладнання за замовчуванням):**
- Given у сім'ї немає духовки, є рецепт з вимогою духовки,
- When відкривається вкладка «Рецепти»,
- Then рецепта немає; вимкнення чипа «З мого обладнання» його показує.

**AC-1.2 (З того, що є):**
- Given рецепт покрито на 80%,
- When увімкнено «З того, що є»,
- Then картка показує 80% і чого бракує.

**AC-1.3 (За інгредієнтом):**
- Given фільтр «Куряче філе» через пікер,
- When показуються результати,
- Then лише рецепти з куркою, зокрема через напівфабрикати.

**AC-1.4 (Пусто):**
- Given жодного результату,
- When показується список,
- Then пояснення і дії: скинути фільтри, створити рецепт.

## US-MREC-2 — Сторінка рецепта
Як кухар, я хочу побачити рецепт на потрібну кількість порцій.

**AC-2.1 (Масштабування):**
- Given рецепт на 4 порції з 3 яйцями,
- When обрано 6 порцій,
- Then «4,5 шт» і точні грами поруч, КБЖВ на порцію без змін.

**AC-2.2 (Обладнання):**
- Given рецепт вимагає блендер, якого немає,
- When відкривається сторінка,
- Then вимога виділена.

**AC-2.3 (Алергія):**
- Given у доньки алергія на горіхи, рецепт з горіхами,
- When відкривається сторінка,
- Then помітне попередження з ім'ям персони.

**AC-2.4 (Офлайн):**
- Given рецепт відкривали онлайн,
- When відкривається без мережі,
- Then сторінка з кешу, масштабування працює.

## US-MREC-3 — Редактор
Як користувач, я хочу зберегти свій рецепт за хвилину.

**AC-3.1 (Мінімум):**
- Given заповнено назву, порції й один інгредієнт,
- When натиснуто «Зберегти»,
- Then рецепт створено з коефіцієнтом 1,0.

**AC-3.2 (Без інгредієнтів):**
- Given немає жодного рядка,
- When натиснуто «Зберегти»,
- Then помилка в розділі «Інгредієнти».

**AC-3.3 (Кілька виборів):**
- Given пікер у режимі кількох виборів,
- When обрано три продукти,
- Then три рядки в редакторі.

**AC-3.4 (Свайп):**
- Given рядок «Сіль, 5 г»,
- When свайп `toTaste`,
- Then рядок без кількості, не впливає на КБЖВ.

**AC-3.5 (Підказка):**
- Given у складі «Томат», є ребро до «Базилік»,
- When тап на підказку «Базилік»,
- Then новий рядок з базиліком; при вимкненому `pairings` підказок немає.

## US-MREC-4 — Кроки
Як автор, я хочу, щоб кроки вели кухаря.

**AC-4.1 (Таймер і інгредієнти):**
- Given крок «Варити» з таймером 20 хв і чипом «Рис»,
- When рецепт збережено й відкрито,
- Then крок показує таймер і рис.

## US-MREC-5 — Чернетка
Як користувач, я не хочу втратити написане.

**AC-5.1 (Відновлення):**
- Given незбережена зміна, застосунок закрито,
- When редактор відкривають знову,
- Then зміна на місці.

**AC-5.2 (Без мережі):**
- Given немає мережі,
- When натиснуто «Зберегти»,
- Then чернетка лишається, кнопка «Надіслати, коли є мережа», автовідправки немає.

## US-MREC-6 — Обкладинка
Як автор, я хочу гарну картинку без зусиль.

**AC-6.1 (Піксельна):**
- Given рецепт без фото,
- When відкривається сторінка,
- Then піксельна обкладинка.

**AC-6.2 (Перегенерація):**
- Given змінено склад,
- When нова обкладинка ще не готова,
- Then видно стару, а готова підміняє її без перезавантаження екрана.

**AC-6.3 (Фото):**
- Given обрано фото HEIC,
- When воно завантажується,
- Then файл стиснутий у JPEG до 2048 px і прив'язаний до рецепта.

## US-MREC-7 — Публікація
Як автор, я хочу поділитися рецептом і контролювати це.

**AC-7.1 (Складові):**
- Given рецепт з приватним товаром,
- When відкривається «Опублікувати»,
- Then екран показує рецепт, товар і перемикач імені.

**AC-7.2 (Відхилено):**
- Given рецепт `rejected`,
- When відкривається сторінка,
- Then причина і «Подати знову».

**AC-7.3 (Зняття):**
- Given опублікований рецепт,
- When «Зняти з публікації»,
- Then дія одразу, тост зі «Скасувати», у пошуку рецепта немає.

**AC-7.4 (Офлайн):**
- Given немає мережі,
- When відкривається сторінка приватного рецепта,
- Then «Опублікувати» неактивна з поясненням.
