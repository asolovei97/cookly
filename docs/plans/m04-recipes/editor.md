# Редактор

Створення й зміна приватного рецепта. Один екран із розділами, що згортаються.

## Розділи

| Розділ | Поля |
|---|---|
| **Основне** | Назва\*, категорія, порції\*, опис |
| **Інгредієнти** | Рядки\* (хоча б один), секції |
| **Кроки** | Текст, таймер, інгредієнти кроку |
| **Обладнання** | Групи-альтернативи |
| **Додатково** | Строк зберігання, коефіцієнт виходу, «виробляє інгредієнт» |

\* — обов'язково. Помилки сервера (`errors[]`) показуються під своїм рядком ([M1](../m01-mobile-bootstrap/stack.md#форми)).

## Інгредієнти

- Додавання через [`CatalogPicker`](../m03-catalog-and-search/picker-and-search.md#catalogpicker) у режимі **кількох виборів**.
- **Напівфабрикат** — окрема вкладка пікера.
- **Кількість і одиниця** в одному рядку; лише застосовні одиниці ([B6](../06-catalog/units.md#застосовність)).
- **Перетягування** для порядку.
- **Свайпи**: `toTaste`, `optional`, видалити.
- **Секції** необов'язкові («Для тіста»).
- Під списком — **підказки «до X пасує»** ([B24](../24-pairings/hints.md#до-x-пасує)): тап додає продукт. Прапорець `pairings` вимкнено → підказок немає.

## Кроки

- Текст і порядок (перетягування).
- Необов'язковий **таймер**.
- **Інгредієнти кроку** — тап по чипах зі складу.
- Фото кроків — [майбутнє](../../future.md).

## Обладнання

- Групи: «(духовка АБО аерогриль) І блендер» — простими рядками «потрібно одне з…» ([B9](../09-recipes/structure.md#вимоги-до-обладнання)).

## Коефіцієнт виходу

- У **«Додатково»**, значення **1,0** і пояснення звичайними словами ([B9](../09-recipes/composition.md#типовий-вихід)).
- Реальне значення згодом підкаже [B16](../16-cooking/dish.md#підказка-коефіцієнта-виходу).

## Обкладинка

- За замовчуванням — **піксельна** ([B10](../10-media/pixel-art.md)), поки немає фото.
- **Фото**: зняти чи обрати з галереї, `uploadMedia` зі стисненням на клієнті ([B10](../10-media/uploads.md#формати)).
- Під час перегенерації показується стара обкладинка, а потім **непомітно оновлюється**.

## Чернетка

- **Автозбереження локально** (MMKV) після кожної зміни; повернення в редактор відновлює чернетку.
- Збереження на сервер — `POST` / `PATCH /v1/recipes`.
- Немає мережі → чернетка лишається, кнопка **«Надіслати, коли є мережа»** ручна; автоматичної відправки немає, бо рецепти поза журналом [B14](../14-offline-sync/index.md).
- Рядки з продуктами, створеними офлайн, чекають синхронізації цих продуктів.

## LLM

Рецепт, збережений з LLM-асистента ([M12](../../roadmap.md#мобільний-застосунок)), відкривається в цьому ж редакторі. Позначка «з LLM» — лише на картці ([B9](../09-recipes/structure.md#поля-рецепта)).
