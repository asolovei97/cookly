# M4 · Рецепти

Вкладка «Рецепти»: пошук і фільтри, сторінка рецепта з масштабуванням, редактор, обкладинки, публікація. Спирається на [B9](../09-recipes/index.md), [B10](../10-media/index.md), [B11](../11-recipe-publishing/index.md), [B13](../13-pantry/usage.md#з-того-що-є), [B24](../24-pairings/hints.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Список: пошук, чипи, фільтр за інгредієнтом, стартовий вміст.
- Сторінка рецепта: масштабування, секції, кроки, обладнання, попередження, дії.
- Редактор: розділи, інгредієнти, кроки, чернетка, обкладинка, фото.
- Публікація: подання зі складовими, статус, зняття.
- Перегляд раніше відкритих рецептів офлайн.

**Не входить**: запуск готування ([M7](../../roadmap.md#мобільний-застосунок)), додавання в план ([M5](../../roadmap.md#мобільний-застосунок)) — тут лише кнопки, LLM-імпорт ([M12](../../roadmap.md#мобільний-застосунок)), фото кроків ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Редактор — один екран із розділами | Покроковий майстер | Майстер уповільнює правки; розділи не перевантажують телефон |
| Обов'язкові лише назва, порції, один інгредієнт | Уся форма | Рецепт можна зберегти за хвилину, доповнити пізніше |
| Автозбереження чернетки локально | Ручне збереження | Нічого не губиться при виході чи без мережі |
| «З мого обладнання» увімкнено за замовчуванням | Вимкнено | Не показувати те, що не приготувати; перемикається одним тапом |
| Коефіцієнт виходу в «Додатково» | На видному місці | Більшості людей незрозумілий; значення 1,0 працює, а B16 підкаже точніше |
| Редагування офлайн лише чернеткою | Повний офлайн | Рецепти поза офлайн-доменами B14 |
