# Редагування

Як наповнювати план з мінімумом рішень. Правила — у [B12](../12-meal-plan/model.md).

## Додавання

Тап на слот → спільний пікер ([M3](../m03-catalog-and-search/picker-and-search.md#catalogpicker)) на [`food-search`](../21-establishments/search.md#єдиний-пошук-їжі) з вкладками:

| Вкладка | Що створює |
|---|---|
| **Нещодавнє** | Те, що обрано |
| **Рецепти** | Заплановане готування на цей день + порції |
| **Продукти** | Позиція-продукт з кількістю |
| **Заклади** | Позиція закладу ([B12](../12-meal-plan/calculations.md#кбжв)) |
| **Вже заплановане** | Порції наявного готування |

- Обрано рецепт → порції рахуються **за тими, хто їсть**.
- Дія одразу, з «Скасувати» ([UX](../../mobile-ux.md#принципи)).

## Звідки ще

- **«У план»** зі сторінки рецепта ([M4](../m04-recipes/browse.md#дії)) → вибір дня й слота, за замовчуванням **найближчий порожній**.
- **«Скласти меню»** ([M3](../m03-catalog-and-search/navigation.md#панель-)) → вкладка «План» на першому дні з порожніми слотами.

## Вільні порції

- На плашці страви з нерозподіленими порціями — чип **«Ще 3 порції»** ([B12](../12-meal-plan/calculations.md#попередження)).
- Тап пропонує наступні прийоми їжі в межах строку зберігання; призначення **одним тапом**.
- **Довге натискання** перетягує позицію між слотами.

## Хто їсть і частки

- За замовчуванням застосунок **нічого не питає**: уся сім'я, порції = кількість персон, частки за нормами ([B12](../12-meal-plan/model.md#порції-й-склад)).
- Тап на прийом їжі → шит:
  - **чекбокси персон**: вимкнути того, хто не їсть (у гостях, у таборі);
  - **«+ порції»** для гостей: кнопки **−1, +1, +10**, поле вводу;
  - **повзунки часток**; решта автоматично перерозподіляється, сума завжди 100%;
  - **«Скинути до норм»**;
  - **«До кінця тижня»** застосовує цей склад до таких самих прийомів їжі.
- Зміна складу перераховує порції: тост **«Порції: 3 → 2 · Скасувати»**. Страву приготовано → звільнена порція стає вільною («Ще 1 порція»).
- Межа — **100 порцій**; +10 біля межі дає 100.

## Попередження

- **Іконки** на плашці, деталі по тапу ([B12](../12-meal-plan/calculations.md#попередження)); нічого не блокує.
- **`allergen`** — єдине підтвердження: діалог із переліком збігів, `confirmAllergen: true`, потім помітна позначка ([B12](../12-meal-plan/preferences.md#алергії)).

## Гарнір

У прийомі їжі з одним готуванням — картка **«Додати гарнір»** ([B24](../24-pairings/hints.md#гарнір-чи-салат-у-плані)):

- топ-5 кандидатів;
- позначки «перевищить норму на N ккал» і «перевищить бюджет на N грн» ([B24](../24-pairings/fit.md));
- кнопка **«Зменшити порцію»**, якщо є `reducedServings`;
- **«Додати»** — одразу в план, зі «Скасувати»;
- 👍 / 👎 на підказці;
- прапорець `pairings` вимкнено → картки немає.

## Шаблони

У меню **«…»** шапки тижня ([B12](../12-meal-plan/model.md#шаблони-тижня)):

- зберегти тиждень як шаблон;
- застосувати шаблон, копіювати тиждень: режими `add` і `replace`;
- `replace` — одразу, зі **«Скасувати»**.

## Офлайн

План працює лише онлайн ([B12](../12-meal-plan/model.md#права-й-конфлікти)). Без мережі — **останній кеш лише для читання**, дії неактивні з поясненням.

## Конфлікти

`409 plan.stale` → застосунок сам перечитує план і **повторює зміну**, якщо вона не суперечить новим даним. Суперечить → тост **«План змінили, оновлено»** без повтору.
