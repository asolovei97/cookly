# M5 · План меню

Вкладка «План»: тижневий графік страв по прийомах їжі, зі строком зберігання, днем готування й запланованою закупкою, редагування порцій і часток, підказки гарніру. Спирається на [B12](../12-meal-plan/index.md), [B15](../15-shopping/generation.md#запланована-закупка), [B18](../18-budget-and-stats/budget.md), [B21](../21-establishments/search.md), [B24](../24-pairings/fit.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Графік тижня, екран дня, огляд місяця, фільтр персони.
- Смуги страв, лінія строку зберігання, іконка готування, маркер закупки.
- Додавання в слот, вільні порції, перетягування, частки.
- Попередження, картка гарніру, шаблони, копіювання тижня.
- Кеш лише для читання, обробка `409 plan.stale`.

**Не входить**: сама закупка ([M6](../../roadmap.md#мобільний-застосунок)), готування ([M7](../../roadmap.md#мобільний-застосунок)), підтвердження з'їденого ([M8](../../roadmap.md#мобільний-застосунок)) — тут лише переходи.

## Документи

- [Редагування](editing.md) — додавання, порції, частки, попередження, гарнір, шаблони, офлайн, конфлікти.
- [Юзер-сторі](user-stories.md) — US-MPLAN-1…7.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Графік: рядки — слоти, колонки — дні | Список днів | Видно, що суп їдять 3 дні, а котлети — один |
| 3–4 дні зі скролом і прилипаючими слотами | 7 вузьких колонок | На телефоні розбірливо |
| Один колір на готування, лінія строку зберігання | Лише назви в клітинках | Серія і межа зберігання читаються одним поглядом |
| Екран дня списком | Лише графік | Деталі й читачі екрана |
| Запланована закупка — маркер на графіку | Закупка без дати | Видно, коли йти в магазин відносно готування |
| Підказка `shopping_needed` | Нічого не підказувати | Легко забути докупити до дня готування |
| Перетягування іконки готування | Дата лише у формі | Готувати в неділю, їсти з понеділка — звичайний сценарій |
