# Юзер-сторі — план меню

Критерії приймання для [плану M5](index.md). AC перевіряються Maestro на варіанті `testing` або RNTL. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MPLAN-1 — Графік
Як укладач меню, я хочу бачити, що ми їмо протягом тижня.

**AC-1.1 (Сітка):**
- Given план на тиждень,
- When відкривається вкладка,
- Then рядки — прийоми їжі, колонки — дні, сьогодні перше, слоти прилипають при скролі.

**AC-1.2 (Серія):**
- Given суп на 3 дні обідами,
- When показується графік,
- Then три плашки одного кольору, назва на першій.

**AC-1.3 (Строк зберігання):**
- Given суп зберігається 3 дні, готування в понеділок,
- When показується графік,
- Then лінія до середи, навіть якщо призначено лише понеділок.

**AC-1.4 (Шапка):**
- Given норма мами 2000 ккал, заплановано 1800,
- When показується день,
- Then мінікола відображає 90%, поруч вартість дня.

**AC-1.5 (Екран дня і читач екрана):**
- Given увімкнено VoiceOver,
- When відкривається вкладка,
- Then дні списком, усі елементи читаються.

## US-MPLAN-2 — Готування на графіку
Як укладач меню, я хочу знати, коли готувати.

**AC-2.1 (Іконка раніше):**
- Given готування в неділю, перший прийом у понеділок,
- When показується графік,
- Then іконка-сковорідка в неділю.

**AC-2.2 (Перетягування):**
- Given іконка в неділю,
- When її перетягнуто на суботу,
- Then заплановане готування в суботу, прийоми їжі на місці, строк зберігання перераховано.

**AC-2.3 (Приготовано):**
- Given готування завершено у вівторок,
- When показується графік,
- Then іконка «приготовано» у вівторок.

## US-MPLAN-3 — Закупка на графіку
Як укладач меню, я хочу не забути купити продукти.

**AC-3.1 (Маркер):**
- Given запланована закупка на суботу на діапазон сб–пт,
- When тап на маркер,
- Then чернетка закупки на цей діапазон.

**AC-3.2 (Виконано):**
- Given закупку завершено,
- When показується графік,
- Then маркер «виконано».

**AC-3.3 (Підказка):**
- Given готування в неділю, бракує молока, закупки до неділі немає,
- When показується графік,
- Then м'який маркер «Закупитись до неділі» з дією «Запланувати».

## US-MPLAN-4 — Додавання
Як укладач меню, я хочу додати страву за кілька тапів.

**AC-4.1 (Рецепт):**
- Given порожній слот обіду в сім'ї з 3 персон,
- When обрано рецепт,
- Then заплановане готування цього дня на порції тих, хто їсть, тост «Скасувати».

**AC-4.2 (Вільні порції):**
- Given чип «Ще 3 порції»,
- When тап і вибір наступного прийому,
- Then порції призначено одним тапом.

**AC-4.3 (Заклад):**
- Given вкладка «Заклади»,
- When обрано «Біг Мак»,
- Then плашка рахується в КБЖВ і вартості, а в закупці її немає.

**AC-4.4 (Перетягування):**
- Given позиція в обід понеділка,
- When довге натискання й перетягування на вечерю,
- Then позиція у вечері.

## US-MPLAN-5 — Частки
Як укладач меню, я хочу задавати частки лише тоді, коли треба.

**AC-5.1 (За замовчуванням):**
- Given норми 2600 / 1800 / 1600,
- When додано страву,
- Then застосунок нічого не питає, частки 43 / 30 / 27%.

**AC-5.3 (Вимкнути персону):**
- Given обід на трьох, не приготовано,
- When чекбокс дитини вимкнено,
- Then тост «Порції: 3 → 2 · Скасувати», частки решти перераховано.

**AC-5.4 (Гості):**
- Given обід на трьох,
- When «+ порції» +1,
- Then 4 порції, кільця й мінікола персон без змін, вартість за 4.

**AC-5.5 (До кінця тижня):**
- Given дитину вимкнено у вівторок,
- When «До кінця тижня»,
- Then вона вимкнена в наступних обідах цього тижня.

**AC-5.6 (Межа):**
- Given 95 порцій,
- When +10,
- Then 100.

**AC-5.2 (Повзунок):**
- Given частки 40 / 30 / 30%,
- When першу змінено на 50%,
- Then решта перерозподілено, сума 100%.

## US-MPLAN-6 — Попередження й гарнір
Як укладач меню, я хочу бачити проблеми, не зупиняючись.

**AC-6.1 (Алергія):**
- Given страва з горіхами і донька з алергією,
- When страву додають,
- Then діалог зі збігами; після підтвердження — помітна позначка.

**AC-6.2 (Гарнір зі зменшенням):**
- Given кандидат виводить маму за норму,
- When показується картка,
- Then позначка й «Зменшити порцію»; вибір додає зменшені порції.

**AC-6.3 (Вимкнена фіча):**
- Given `pairings` off,
- When показується прийом їжі,
- Then картки немає.

## US-MPLAN-7 — Шаблони, офлайн і конфлікти
Як укладач меню, я хочу повторювати вдалий тиждень і не втрачати зміни.

**AC-7.1 (replace):**
- Given шаблон у режимі `replace`,
- When застосовано,
- Then тиждень замінено одразу, тост «Скасувати» повертає попередній.

**AC-7.2 (Офлайн):**
- Given немає мережі,
- When відкривається вкладка,
- Then кеш, дії редагування неактивні з поясненням.

**AC-7.3 (Stale):**
- Given `409 plan.stale` і зміна не суперечить новим даним,
- When застосунок повторює,
- Then зміна застосована без дій користувача.

**AC-7.4 (Конфлікт):**
- Given позицію видалили на іншому пристрої,
- When її змінюють,
- Then тост «План змінили, оновлено».
