# Юзер-сторі — закупка

Критерії приймання для [плану закупки](../index.md). AC перевіряються на рівні API, зокрема через `POST /v1/sync/ops` для офлайн-операцій. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Список](list.md) — US-SHOP-1…5: створення, потреба, «приготую сам», вибір товару, упаковки й порівняння.
- [У магазині](trip.md) — US-SHOP-6…10: позначки, ціни, ділення, конфлікти, завершення.
