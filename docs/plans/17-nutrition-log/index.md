# B17 · Облік з'їденого

Записи того, що з'їла кожна персона: порції страв за частками з плану, продукти поза меню, заклади, ручні записи й швидке готування — з таймзонами, прийомами їжі й підсумками днів. Продуктовий опис — в [обліку з'їденого](../../nutrition-log.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Записи: п'ять видів, знімок КБЖВ, права, редагування без обмеження в часі.
- Підтвердження прийому їжі з плану: частки → грами, залишок страви.
- Перемикач «із запасів», списання й компенсація; ціна поза запасами → факт бюджету.
- Швидке готування з рецепта.
- Таймзони акаунта, сім'ї й запису; обов'язковий прийом їжі з автопідстановкою.
- Підсумки днів проти норми, нещодавні позиції, повтор прийому їжі.
- Операції синхронізації в реєстрі [B14](../14-offline-sync/protocol.md#реєстр-типів).

**Не входить**: тижневі метрики, графіки й головний екран ([B18](../../roadmap.md#бекенд)), запис у Apple Health / Health Connect ([здоров'я](../../health-integrations.md)), push-нагадування ([майбутнє](../../future.md)), клієнтські екрани ([M8](../../roadmap.md#мобільний-застосунок)).

## Документи

- [Записи](entries.md) — види, знімок, права, редагування, операції, ендпоінти.
- [З плану](from-plan.md) — підтвердження, частки → грами, залишок, запаси, швидке готування, бюджет.
- [Дні](days.md) — таймзони, прийоми їжі, підсумки днів, нещодавні, повтор.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Записи з плану лише після підтвердження | Автоматичні записи після готування | Хтось міг не їсти; статистика має бути правдивою |
| Будь-який учасник записує будь-кому | Лише сам собі | За столом одна людина підтверджує за всіх |
| Порція страви — посилання + грами | Знімок КБЖВ у записі | Виправлення страви протягом 48 год оновлює записи |
| Решта видів — знімок у момент запису | Посилання на каталог | Зміни каталогу не переписують історію |
| Офлайн через журнал операцій | Лише онлайн | Їдять там, де немає мережі; записи додаються без конфліктів |
| Локальна дата й таймзона в записі | День за UTC | Пізня вечеря не перескакує на завтра; поїздки не ламають історію |
| Прийом їжі обов'язковий, з автопідстановкою | Необов'язковий з групою «інше» | Підсумки за прийомами завжди повні, а вибір — без тапів |
| Перевищення залишку — обнулення з підказкою | Блокувати запис | Запис з'їденого ніколи не блокується |
