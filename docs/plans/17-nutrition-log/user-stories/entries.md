# Юзер-сторі — записи

US-NUTR-1…5. Загальні правила — в [індексі юзер-сторі](index.md).

## US-NUTR-1 — Поза меню
Як користувач, я хочу записати перекус, каву в кафе чи бургер.

**AC-1.1 (Товар у штуках):**
- Given товар «Йогурт 300 г» з одиницею `шт`,
- When надходить `nutrition.entry.add@1` з 1 шт,
- Then запис `product` має КБЖВ 300 г цього йогурту.

**AC-1.2 (Заклад):**
- Given позиція закладу «Біг Мак» з 503 ккал на порцію,
- When записано 1 порцію,
- Then запис `establishment` має 503 ккал, а запаси не змінилися.

**AC-1.3 (Ручний запис):**
- Given користувач знає лише калорії,
- When надходить запис `manual` з 350 ккал без БЖВ,
- Then запис зберігається з 350 ккал і БЖВ `null`.

## US-NUTR-2 — Знімок
Як користувач, я хочу, щоб історія не змінювалася сама.

**AC-2.1 (Каталог змінився):**
- Given запис 100 г товару з 250 ккал на 100 г,
- When модератор змінює КБЖВ товару на 270 ккал,
- Then запис лишається з 250 ккал.

**AC-2.2 (Виправлення страви):**
- Given запис 300 г страви і виправлення страви протягом 48 годин, що змінює її КБЖВ на 100 г,
- When читаються записи,
- Then КБЖВ запису перераховані за новим знімком.

## US-NUTR-3 — Права
Як учасник сім'ї, я хочу записувати за всіх, але не псувати чужі записи.

**AC-3.1 (Запис за іншого):**
- Given мама й тато з акаунтами,
- When мама додає запис для тата,
- Then запис створено з автором «мама».

**AC-3.2 (Чужий запис):**
- Given запис тата, створений ним самим,
- When мама намагається його змінити,
- Then `403 nutrition.forbidden`.

**AC-3.3 (Персона без акаунта):**
- Given запис доньки без акаунта, створений мамою,
- When тато його змінює,
- Then зміна застосовується.

## US-NUTR-4 — Редагування
Як користувач, я хочу виправити запис і щоб залишки теж виправилися.

**AC-4.1 (Залишок страви):**
- Given страва із залишком 1000 г і запис 300 г (залишок 700 г),
- When запис змінюють на 200 г,
- Then залишок 800 г.

**AC-4.2 (Видалення із запасів):**
- Given запис йогурту 1 шт «із запасів»,
- When запис видаляють,
- Then запаси отримують компенсуючу дельту +1 шт.

**AC-4.3 (Старий запис):**
- Given запис місячної давнини,
- When його змінюють,
- Then зміна застосовується, і підсумок того дня перераховано.

## US-NUTR-5 — Офлайн
Як користувач, я хочу записати їжу без мережі.

**AC-5.1 (Пакет офлайн):**
- Given три записи, створені офлайн,
- When пакет надходить у `POST /v1/sync/ops`,
- Then усі три `applied`, а повтор пакета повертає `duplicate`.

**AC-5.2 (Видалений запис):**
- Given запис видалено з іншого пристрою,
- When надходить `nutrition.entry.update@1` для нього,
- Then `rejected` з `nutrition.entry_not_found`.
