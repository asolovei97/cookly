# Юзер-сторі — облік з'їденого

Критерії приймання для [плану обліку з'їденого](../index.md). AC перевіряються на рівні API, зокрема через `POST /v1/sync/ops`. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Записи](entries.md) — US-NUTR-1…5: види, знімок, права, редагування, офлайн.
- [План і дні](plan-and-days.md) — US-NUTR-6…10: підтвердження, запаси й бюджет, швидке готування, таймзони й прийоми їжі, підсумки й нещодавні.
