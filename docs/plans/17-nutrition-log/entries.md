# Записи

Види записів з'їденого, їхні КБЖВ, права й редагування.

## Види

| Вид | Що містить | КБЖВ | Запаси |
|---|---|---|---|
| `dish` — порція страви | Страва ([B16](../16-cooking/dish.md)), грами | Посилання на страву: її знімок на 100 г × грами | Зменшує залишок страви |
| `product` — товар чи інгредієнт | Товар або інгредієнт, кількість у будь-якій застосовній [одиниці](../06-catalog/units.md#застосовність) | Знімок у момент запису | Перемикач «із запасів», див. [з плану](from-plan.md#запаси) |
| `establishment` — позиція закладу | Позиція меню [закладу](../../catalog/establishments.md), порції | Знімок у момент запису | Ніколи |
| `manual` — ручний запис | Назва (необов'язково), ккал, БЖВ (необов'язково) | Як введено | Ніколи |
| `quick_cooking` — швидке готування | Рецепт-джерело, змінений склад → нова страва | Як `dish` | Як готування, див. [з плану](from-plan.md#швидке-готування) |

- Страва без рецепта ([B16](../16-cooking/dish.md#страва-без-рецепта)) записується як `dish`.
- Спільні поля: персона, локальна дата, прийом їжі, `clientTime`, таймзона ([дні](days.md)), автор, необов'язкова ціна ([з плану](from-plan.md#бюджет)).

## Знімок КБЖВ

- `product`, `establishment`, `manual` — КБЖВ фіксуються в момент запису: зміни каталогу чи позиції закладу їх не змінюють ([B7](../07-moderation/merge.md#знімки-в-історії)).
- `dish` — КБЖВ = знімок страви на 100 г × грами. Виправлення страви протягом 48 годин ([B16](../16-cooking/dish.md#виправлення)) оновлює записи автоматично; після цього знімок страви фіксований.

## Права

- **Створювати** записи може будь-який учасник сім'ї для будь-якої персони сім'ї.
- **Змінювати й видаляти**:
  - запис персони без акаунта — будь-який учасник;
  - запис персони з акаунтом — сама персона або автор запису; інакше `403 nutrition.forbidden`.
- **Видимість**: записи й підсумки всіх персон бачить уся сім'я ([B5](../05-household/household.md#видимість)).
- Персона іншої сім'ї → `404`.
- Архівована персона: старі записи лишаються, нові → `422 nutrition.person_archived`.

## Редагування

- Запис можна змінити чи видалити **будь-коли**.
- Зміна грамів чи видалення `dish` коригує **залишок страви** на різницю.
- Зміна чи видалення запису «із запасів» створює **компенсуючу дельту** запасів ([B13](../13-pantry/model.md#зміни)).
- Підсумки днів перераховуються під час читання.

## Операції синхронізації

| Тип | Що робить |
|---|---|
| `nutrition.entry.add@1` | Новий запис будь-якого виду |
| `nutrition.entry.update@1` | Кількість, грами, прийом їжі, дата, персона |
| `nutrition.entry.delete@1` | Видалення з компенсацією |
| `nutrition.meal.confirm@1` | Підтвердження прийому їжі з плану, див. [з плану](from-plan.md#підтвердження) |

- Конфлікти полів запису — «перемагає останній запис на рівні поля» ([B14](../14-offline-sync/conflicts.md#правила-за-типами)).
- Операція над видаленим записом → `rejected` з `nutrition.entry_not_found`.
- Записи потрапляють у стрічку змін сім'ї ([B14](../14-offline-sync/protocol.md#зміни-з-інших-пристроїв)).

## Ендпоінти (онлайн)

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/nutrition/entries?personId=&from=&to=` | Записи персони за діапазоном дат |
| `GET /v1/nutrition/days?personId=&from=&to=` | Підсумки днів, див. [дні](days.md#підсумки-днів) |
| `GET /v1/nutrition/recent?personId=` | Нещодавні й часті позиції, див. [дні](days.md#нещодавні) |
| `POST /v1/nutrition/repeat-meal` | Повторити прийом їжі з іншого дня, див. [дні](days.md#повтор-прийому-їжі) |
| `GET /v1/plan/meals/{id}/confirmation` | Пропозиція записів для підтвердження |

Створення, зміна й видалення — через `POST /v1/sync/ops` і онлайн, і офлайн.
