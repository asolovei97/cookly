# B22 · Чеки

Імпорт фіскального чека за URL з QR-коду: розбір адаптером у воркері, прев'ю із зіставленням рядків з каталогом, підтвердження, після якого чек стає цінами, запасами й фактом бюджету або закриває позиції активної закупки. Продуктовий опис — у [чеках](../../receipts.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Імпорт: статуси, операції синхронізації, прев'ю, дедуплікація, давність, ліміти, прапорці.
- Адаптери: інтерфейс, `elkasa` (Сільпо), вирізання платіжних даних, мережа й місто; ДПС — після spike.
- Зіставлення: штрихкод, аліаси мереж, кількість і одиниці, «не їжа», конфлікти аліасів, знижка.
- Наслідки: спостереження цін ([B8](../08-prices/index.md)), дельти запасів ([B13](../13-pantry/index.md)), факт бюджету ([B18](../18-budget-and-stats/budget.md)), прикріплення до закупки ([B15](../15-shopping/trip.md#чек)).

**Не входить**: скан QR і екрани ([M11](../../roadmap.md#мобільний-застосунок)), черга аліасів в адмінці ([A9](../../roadmap.md#адмінка)), OCR паперових чеків ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Парсинг на сервері адаптером | На пристрої | Адаптери оновлюються без релізу; дедуплікація й ліміти в одному місці |
| Прев'ю на сервері, підтвердження — операція синхронізації | Підтвердження лише онлайн | Розбір потребує мережі, а підтвердити можна будь-де |
| Дедуплікація глобально | У межах сім'ї | Одна покупка — один чек; ціни не задвоюються |
| «Не їжа» з аліасом `ignore` | Усі рядки в запаси й бюджет | Бюджет — на їжу; пакет і хімія не мають потрапляти в запаси |
| Бюджет — сума рядків з їжею | ~~Сума чека~~ | Узгоджено з «не їжа» |
| Аліас: одразу для сім'ї, для всіх — після 3 однакових або модерації | Лише модерація | Каталог наповнюється сам; розбіжності бачить модератор |
| Платіжний блок вирізає адаптер до будь-якого запису | Вирізати після розбору | Навіть сирий HTML не містить картки |
| Прапорець на кожен адаптер | Один на всю фічу | Зламана верстка однієї мережі не вимикає решту |
| Адаптер ДПС лише після spike | Планувати наосліп | Невідомо, чи віддає ДПС позиції без капчі |
