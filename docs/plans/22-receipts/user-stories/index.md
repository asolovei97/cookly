# Юзер-сторі — чеки

Критерії приймання для [плану чеків](../index.md). AC перевіряються на рівні API, зокрема через `POST /v1/sync/ops`, і задач воркера на сторінках-фікстурах. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Імпорт](import.md) — US-RCPT-1…4: скан і розбір, дедуплікація й давність, приватність, ліміти й прапорці.
- [Зіставлення](matching.md) — US-RCPT-5…9: штрихкод і аліаси, кількість, «не їжа», наслідки, закупка.
