# Юзер-сторі — імпорт

US-RCPT-1…4. Загальні правила — в [індексі юзер-сторі](index.md).

## US-RCPT-1 — Скан і розбір
Як користувач, я хочу відсканувати чек і не вводити покупки вручну.

**AC-1.1 (Розбір):**
- Given URL чека `receipt.silpo.elkasa.com.ua/<id>` і сторінка-фікстура з 6 рядками,
- When надходить `receipt.submit@1` і воркер виконує задачу,
- Then імпорт `parsed`, прев'ю має магазин, дату, 6 рядків і підсумки.

**AC-1.2 (Офлайн):**
- Given `receipt.submit@1` створено офлайн,
- When пакет надходить після появи мережі,
- Then імпорт `queued`, а повтор пакета — `duplicate` за `opId`.

**AC-1.3 (Невідомий домен):**
- Given URL з невідомого домену,
- When надходить `receipt.submit@1`,
- Then імпорт `unsupported`, URL збережено.

**AC-1.4 (Сторінка недоступна):**
- Given сторінка повертає помилку 5 разів поспіль,
- When вичерпано повтори,
- Then імпорт `failed`.

## US-RCPT-2 — Дедуплікація й давність
Як користувач, я не хочу задвоєних цін і запасів.

**AC-2.1 (Інша сім'я):**
- Given чек підтвердила сім'я A,
- When сім'я B надсилає той самий URL,
- Then імпорт `duplicate` з `receipt.already_imported`.

**AC-2.2 (Після скасування):**
- Given імпорт чека скасовано,
- When його надсилають знову,
- Then імпорт `queued`.

**AC-2.3 (Старий чек):**
- Given дата чека 31 день тому,
- When воркер розбирає його,
- Then імпорт `failed` з кодом `receipt.too_old`.

## US-RCPT-3 — Приватність
Як користувач, я не хочу, щоб застосунок зберігав дані моєї картки.

**AC-3.1 (Вирізання):**
- Given сторінка-фікстура з маскованою карткою, RRN, кодом авторизації й рахунком лояльності,
- When чек розібрано,
- Then ні прев'ю, ні збережений сирий HTML їх не містять.

**AC-3.2 (Строк сирого HTML):**
- Given сирий HTML імпорту 31 день тому,
- When виконується задача очищення,
- Then сирий HTML видалено, а розібрані рядки лишились.

## US-RCPT-4 — Ліміти й прапорці
Як власник сервісу, я хочу захистити сторінки мереж і швидко вимкнути зламаний адаптер.

**AC-4.1 (Ліміт сім'ї):**
- Given сім'я надіслала 30 чеків за добу,
- When надходить 31-й,
- Then `429 receipt.rate_limited`.

**AC-4.2 (Вимкнений адаптер):**
- Given прапорець `receipts.elkasa` off,
- When надходить URL elkasa,
- Then імпорт `unsupported`.

**AC-4.3 (Вимкнена фіча):**
- Given прапорець `receipts` off для сім'ї,
- When надходить `receipt.submit@1`,
- Then `rejected` з `feature.disabled`, операція лишається в черзі клієнта.
