# Структура

З чого складається рецепт.

## Поля рецепта

| Поле | Примітка |
|---|---|
| Назва, опис | `i18n.Text`, [B4](../04-i18n/content.md) |
| Категорія | З довідника нижче |
| Порції | Кількість порцій, на яку записано склад |
| Рядки інгредієнтів | Див. нижче |
| Кроки | Див. нижче |
| Вимоги до обладнання | Групи, див. нижче |
| Строк зберігання | Днів, скільки можна їсти готову страву ([план меню](../../planning/meal-plan.md)) |
| Коефіцієнт виходу | Див. [склад і КБЖВ](composition.md#типовий-вихід) |
| Виробляє інгредієнт | `producesIngredientId`, необов'язкове: «Майонез домашній» → «Майонез»; дозволяє «приготую сам» у [закупці](../15-shopping/generation.md#приготую-сам) |
| Власник | `ownerHouseholdId`: `null` — адмінський, інакше — приватний сім'ї |
| Джерело | `source`: `manual` (за замовчуванням) або `llm` з провайдером — рецепт з [LLM-асистента B23](../23-llm-assistant/import.md#збереження) |

## Категорії

Пласкі, з перекладом, веде адмін (право «довідники»). Категорія задає посуд для [піксельної картинки](../../recipes/pixel-art.md).

| Категорія | Посуд |
|---|---|
| сніданок | тарілка |
| суп | миска |
| основна страва | тарілка |
| гарнір | тарілка |
| салат | миска |
| випічка | дошка |
| десерт | тарілка |
| напій | склянка |
| соус | баночка |
| заготовка | баночка |

Теги («вегетаріанське», «без глютену») — [майбутнє](../../future.md).

## Рядки інгредієнтів

- Посилання на **інгредієнт** або **рецепт-напівфабрикат**. Товар у рядку не допускається → `422` з `errors[]` для рядка.
- Кількість і одиниця — за [правилами застосовності B6](../06-catalog/units.md#застосовність); недоступна одиниця → `422 catalog.unit_not_applicable`.
- **`toTaste`** — рядок без кількості («сіль за смаком»): не впливає на КБЖВ і не потрапляє в закупку.
- **`optional`** — рядок з кількістю («зелень, 10 г, за бажанням»): враховується лише тоді, коли його обрали в плані чи під час готування.
- **Секція** — текстова мітка з перекладом («Для тіста», «Для начинки»); рядки групуються за нею.
- Порядок рядків зберігається.

## Кроки

- Текст (`i18n.Text`) і порядок.
- **Таймер** — необов'язкова тривалість. Працює локально на пристрої, бекенд лише зберігає значення.
- **Інгредієнти кроку** — посилання на рядки цього рецепта. Рядок не з цього рецепта → `422`.

## Вимоги до обладнання

- **Групи-альтернативи**: між групами — AND, усередині групи — OR. Приклад: «(духовка АБО аерогриль) І блендер».
- Елементи груп — типи з [довідника обладнання](../06-catalog/directories.md#обладнання).
- Рецепт доступний сім'ї, якщо для кожної групи в неї є хоча б один тип.

## Масштабування

- `GET /v1/recipes/{id}?servings=N` повертає склад для N порцій.
- Усі кількості масштабуються **лінійно**, зберігаються й повертаються **точні** значення (`3` яйця × 1,5 = `4,5`).
- Клієнт показує штучні одиниці, округлені до 0,5, і поруч точні грами.
