# Юзер-сторі — рецепти

Критерії приймання для [плану рецептів](../index.md). AC перевіряються на рівні API. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Створення](authoring.md) — US-REC-1…5: приватний рецепт, рядки, кроки, напівфабрикати, масштабування.
- [Використання](usage.md) — US-REC-6…10: КБЖВ, обладнання, пошук, адмінські рецепти й копія, архівування.
