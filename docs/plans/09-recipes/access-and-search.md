# Доступ і пошук

Хто бачить і змінює рецепти, як їх знайти, і ендпоінти.

## Права

| Рецепт | Бачать | Змінюють |
|---|---|---|
| Адмінський | Усі | Лише адміни з правом «довідники» ([матриця](../03-admin-auth/access.md#ролі-й-права)) |
| Приватний сім'ї | Лише сім'я | Будь-який учасник сім'ї |

- Спроба змінити адмінський рецепт у застосунку → `403 recipes.forbidden`.
- Чужий приватний рецепт → `404`.
- **«Зробити своїм»** (`POST /v1/recipes/{id}/copy`) створює приватну копію з посиланням на джерело; копію сім'я редагує як звичайний свій рецепт.
- Публікація приватних рецептів — [B11](../../roadmap.md#бекенд).

## Версії

Приватні рецепти **без історії змін**: готування зберігає фактичний склад як знімок. Версії публічних рецептів — у [B11](../../recipes/publishing.md).

## Архівування

- Рецепт, на який посилаються плани, готування чи інший рецепт, **архівується**: зникає з пошуку, але посилання працюють.
- Інакше — видаляється.

## Пошук

`GET /v1/recipes?q=&category=&ingredientId=&onlyMyEquipment=`

- `q` — за назвою, з нормалізацією і trigram ([B4](../04-i18n/content.md#пошук)).
- `category` — категорія рецепта.
- `ingredientId` — рецепти, що містять інгредієнт («що приготувати з курки»), зокрема через напівфабрикати.
- `onlyMyEquipment=true` — лише рецепти, вимоги яких задовольняє [обладнання сім'ї](../06-catalog/directories.md#обладнання).
- Повертаються адмінські рецепти, публічні рецепти спільноти ([B11](../11-recipe-publishing/author.md#пошук-і-копія), фільтр `source=default|community`) і приватні рецепти своєї сім'ї; архівні — ні.
- Кожен результат містить орієнтовні КБЖВ на порцію з `recipe_nutrition`.
- Пошук «з того, що є вдома» — [B13](../../roadmap.md#бекенд) або пізніше.

## Ендпоінти

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/recipes` | Пошук |
| `GET /v1/recipes/{id}?servings=` | Рецепт, за потреби масштабований |
| `POST /v1/recipes` | Створити приватний рецепт |
| `PATCH /v1/recipes/{id}` | Змінити приватний рецепт |
| `DELETE /v1/recipes/{id}` | Архівувати чи видалити |
| `POST /v1/recipes/{id}/copy` | «Зробити своїм» |
| `GET /v1/recipes/categories` | Категорії |
| `/admin/v1/recipes/...`, `/admin/v1/recipes/categories/...` | CRUD адмінських рецептів і категорій з аудитом |
