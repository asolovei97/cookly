# B9 · Рецепти

Структура рецепта, напівфабрикати, типовий вихід, орієнтовні КБЖВ, права, пошук. Продуктовий опис — у [рецептах](../../recipes/recipes.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Категорії рецептів.
- Рядки інгредієнтів, секції, `toTaste`, `optional`.
- Кроки з таймерами й інгредієнтами кроку.
- Вимоги до обладнання.
- Масштабування порцій.
- Напівфабрикати, перевірка циклів і глибини.
- Типовий вихід, базові рецепти.
- Орієнтовні КБЖВ (`recipe_nutrition`).
- Права, «Зробити своїм», архівування, пошук.
- Адмін-API рецептів.

**Не входить**: фото й піксельні картинки ([B10](../../roadmap.md#бекенд)), публікація ([B11](../../roadmap.md#бекенд)), пошук «з того, що є вдома» ([B13](../../roadmap.md#бекенд) або пізніше), підказка коефіцієнта виходу за зважуваннями ([B16](../../roadmap.md#бекенд)), теги ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Рядок — лише інгредієнт або напівфабрикат | Конкретний товар у рецепті | Рецепт не прив'язаний до магазину; товар обирають у закупці й готуванні |
| Окремий довідник категорій рецептів | Категорії інгредієнтів | Інша природа; категорія задає посуд для піксельної картинки |
| `toTaste` і `optional` | Усі рядки обов'язкові з кількістю | «Сіль за смаком» не має кількості; необов'язкове не має потрапляти в закупку |
| Точні значення при масштабуванні, округлення на клієнті | Округлення під час збереження | Точні КБЖВ і закупка; людям зручно бачити «4,5 яйця ≈ 4–5 шт + грами» |
| Глибина напівфабрикатів до 3 | Без обмеження | Перевірка циклів і розрахунок лишаються простими |
| `recipe_nutrition`, оновлює воркер | Обчислення на кожен запит | Списки й план меню показують КБЖВ багатьох рецептів одразу |
| «Зробити своїм» для адмінських рецептів | Редагування адмінських рецептів | Базові рецепти лишаються еталоном |
| Без версій приватних рецептів | Історія змін | Готування зберігає фактичний склад як знімок |
