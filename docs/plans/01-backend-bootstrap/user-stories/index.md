# Юзер-сторі — бутстрап бекенду

Критерії приймання для [плану бутстрапу](../index.md). Сторі технічні. AC перевіряються на рівні API, процесу або CI. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Платформа API](platform.md) — US-BOOT-1…7: ping, помилки, request_id, безпека за замовчуванням, panic, конфіг, health і метрики.
- [Дані, процеси й контракт](operations.md) — US-BOOT-8…13: міграції, воркер, коректна зупинка, логи без PII, контракт і генерація, мінімальна версія застосунку.
