# Модель

Сутності закладів: бренд, точки, розділи меню, категорії й позиції.

## Заклад

| Поле | Примітка |
|---|---|
| Назва | Адмінський — JSONB-переклад ([B4](../04-i18n/content.md#зберігання)); користувацький — рядок мовою автора |
| Тип | `fast_food` · `cafe` · `coffee` · `other` |
| Логотип | Медіа з [B10](../10-media/uploads.md#процес) |
| Аліаси | Для пошуку: «Мак», «Макдак» |
| Посилання | Сайт, сторінка меню, соцмережі |
| `source` | URL, звідки взято КБЖВ |

## Точка

| Поле | Примітка |
|---|---|
| Адреса | Рядок |
| Місто | З довідника `cities` ([B5](../05-household/household.md#місто)) |
| Координати | Для пошуку поруч |
| Посилання на мапу | Необов'язкове |

- У кав'ярні з однією адресою — одна точка.
- Заклад без точок дозволено (точку можна додати пізніше).

## Розділи меню

- Свої в кожному закладі: вільна назва, порядок («Шаурма», «Корпусні десерти», «Комбо»).
- Розділ можна прив'язати до **загальної категорії** — його позиції її успадковують.

## Загальні категорії

- Фіксований довідник, редагує `admin`: бургери, шаурма, піца, курка, гарніри, салати, десерти, напої, кава, сніданки…
- Назви — JSONB-переклад.
- Потрібні для фільтрів і пошуку між закладами («де поїсти шаурму»); окремі від [дерева категорій інгредієнтів](../06-catalog/categories.md).

## Позиція меню

| Поле | Примітка |
|---|---|
| Розділ | Обов'язковий |
| Загальна категорія | Успадковується від розділу; позиція може перевизначити |
| Назва | Як у закладу |
| ккал на порцію | **Обов'язково** |
| Б, Ж, В на порцію | Необов'язково |
| Вага порції | Необов'язково; якщо є — КБЖВ на 100 г рахуються автоматично |
| Одиниці | `порція`, `шт`; `g`, якщо вага відома ([B6](../06-catalog/units.md)) |

- **Кожен розмір — окрема позиція**: «Кола 0,4», «Кола 0,5».
- Позиція ніколи не потрапляє в запаси й список покупок.

## Версії й архів

- Зміна КБЖВ позиції створює **нову версію**; записи з'їденого вже мають знімок ([B17](../17-nutrition-log/entries.md#знімок-кбжв)), а план бере актуальну версію.
- Позиція, яку прибрали з меню, **архівується**: у пошуку її немає, старі записи й плани на неї посилаються.
- Архівований заклад архівує свої точки й позиції.

## Права

- Публічні заклади, точки й позиції бачать усі; змінюють `moderator` і `admin` ([B3](../03-admin-auth/access.md#ролі-й-права)).
- Приватні — лише сім'я-автор; змінює будь-який учасник.
- Чуже приватне → `404`.

## Ендпоінти

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/establishments/{id}` | Заклад з точками й розділами |
| `GET /v1/establishments/{id}/items?q=&section=` | Меню, див. [пошук](search.md) |
| `POST`/`PATCH`/`DELETE /v1/establishments/{id}` | Приватний заклад сім'ї |
| `POST`/`PATCH`/`DELETE /v1/establishments/{id}/locations/{locId}` | Точки |
| `POST`/`PATCH`/`DELETE /v1/establishments/{id}/sections/{secId}` | Розділи |
| `POST`/`PATCH`/`DELETE /v1/establishments/{id}/items/{itemId}` | Позиції |
| `GET /v1/establishment-categories` | Загальні категорії |
| `/admin/v1/establishments/...` | CRUD публічних закладів і довідника категорій |
