# Юзер-сторі — публікація й пошук

US-EST-5…8. Загальні правила — в [індексі юзер-сторі](index.md).

## US-EST-5 — Приватне й модерація
Як користувач, я хочу додати свою кав'ярню й поділитися нею, коли захочу.

**AC-5.1 (Одразу в сім'ї):**
- Given користувач створив заклад з двома позиціями,
- When інший учасник сім'ї шукає позицію,
- Then вона знаходиться, а для інших сімей — ні.

**AC-5.2 (Без автоматичної відправки):**
- Given приватний заклад,
- When минає будь-який час,
- Then у черзі модерації його немає.

**AC-5.3 (Разом зі складовими):**
- Given заклад з точкою і трьома позиціями,
- When користувач натискає «Запропонувати всім»,
- Then у черзі один запит із закладом, точкою і позиціями.

**AC-5.4 (Схвалення):**
- Given запит схвалено,
- When будь-яка сім'я шукає заклад,
- Then знаходить публічну копію, а приватний оригінал лишається в сім'ї автора.

## US-EST-6 — Дублікати
Як модератор, я хочу звести «Макдональдз» і «McDonald's» в один заклад.

**AC-6.1 (Об'єднання):**
- Given публічні заклади X і Y та записи з'їденого з позиціями X,
- When модератор об'єднує X → Y,
- Then точки й позиції X у Y, записи посилаються на Y, а їхні знімки КБЖВ не змінилися.

## US-EST-7 — Ціни
Як користувач, я хочу знати, скільки коштує бургер у моєму місті.

**AC-7.1 (Точка дає місто):**
- Given точка закладу у Львові,
- When записано позицію з ціною і цією точкою,
- Then спостереження ціни має місто Львів і точку.

**AC-7.2 (Медіана за містом):**
- Given свіжі спостереження ціни позиції з різних точок Києва,
- When читається публічна ціна,
- Then це медіана за Києвом.

## US-EST-8 — Пошук
Як користувач, я хочу знайти, що я з'їв, одним пошуком.

**AC-8.1 (Аліас):**
- Given заклад з аліасом «Макдак»,
- When `GET /v1/establishments?q=макдак`,
- Then заклад у результатах.

**AC-8.2 (Поруч):**
- Given дві точки за 300 м і 5 км,
- When `GET /v1/establishments/nearby` з координатами,
- Then ближча перша, а координати запиту не збережено.

**AC-8.3 (Єдиний пошук):**
- Given товар «Кола 0,5 л» і позиція «Кола 0,5» у McDonald's,
- When `GET /v1/food-search?q=кола`,
- Then обидва результати з різними `kind`, позиція — з назвою закладу.

**AC-8.4 (Нещодавні вище):**
- Given персона вчора записувала «Біг Мак»,
- When вона шукає «біг»,
- Then «Біг Мак» перший.

**AC-8.5 (Категорія між закладами):**
- Given два заклади з позиціями категорії «Шаурма»,
- When `GET /v1/establishments?category=<шаурма>`,
- Then обидва заклади в результатах.
