# B21 · Заклади

Каталог закладів (фастфуди, кафе, кав'ярні) з точками, меню за розділами й КБЖВ на порцію, публікація через модерацію, ціни за містом і пошук, зокрема єдиний пошук їжі для обліку й плану. Продуктовий опис — у [закладах](../../catalog/establishments.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Заклад, точки, розділи меню, загальні категорії, позиції з КБЖВ на порцію, версії й архів.
- Приватне для сім'ї → «Запропонувати всім» → модерація ([B7](../07-moderation/index.md)) → публічна копія; об'єднання дублікатів.
- Ціни позицій за порцію з точкою й містом ([B8](../08-prices/index.md)).
- Пошук закладів, меню, точок поруч; єдиний `food-search`.
- Стартові дані від модератора.

**Не входить**: використання в обліку ([B17](../17-nutrition-log/index.md)) і плані ([B12](../12-meal-plan/index.md)) — вони посилаються на позиції; екрани адмінки ([A8](../../roadmap.md#адмінка)); доступність позицій у точках, медіана за точкою, години роботи, парсинг меню й порівняння «вдома vs заклад» ([майбутнє](../../future.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Заклад-бренд з точками, меню на рівні закладу | Лише бренд; меню на точку | Адреси потрібні для пошуку поруч і цін, а меню мережі однакове |
| Кожен розмір — окрема позиція | Позиція з варіантами | Простіше для КБЖВ, цін і пошуку |
| КБЖВ на порцію | На 100 г, як у каталозі | Мережі публікують дані на порцію; вага відома не завжди |
| Розділи закладу + загальні категорії | Лише загальні; лише свої | Меню виглядає як у закладі, а фільтри працюють між закладами |
| Явна відправка на модерацію, як у рецептів | Автоматично після створення | Користувач сам вирішує, що ділити з усіма; приватне працює одразу |
| Позиції йдуть на модерацію разом із закладом | Окремо | Заклад без меню нікому не корисний |
| Медіана ціни за містом | За точкою | Даних на одну точку замало |
| Координати пристрою не зберігаються | Зберігати для статистики | Достатньо для пошуку поруч |
| `establishments` — `core` | `optional` | Без закладів облік у кафе неправдивий |
