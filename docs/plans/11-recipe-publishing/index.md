# B11 · Публікація рецептів

Як приватний рецепт сім'ї стає доступним усім і як оновлюється потім. Продуктовий опис — у [публікації](../../recipes/publishing.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Тип `recipe` у модулі модерації [B7](../07-moderation/workflow.md#реєстр-типів).
- Публічна копія, версії, пропозиції оновлення.
- Модерація складових: приватні інгредієнти, товари й напівфабрикати.
- Модерація й копіювання обкладинки ([B10](../10-media/uploads.md#модерація)).
- Ім'я автора і згода, зняття з публікації.
- Фільтр `source` у пошуку.

**Не входить**: лічильник популярності («приготували N разів») — [майбутнє](../../future.md).

## Документи

- [Публікація](publishing.md) — подання, складові, схвалення, версії, пропозиції оновлення, обкладинка, переклад.
- [Автор і доступ](author.md) — ім'я і згода, зняття з публікації, видалення оригіналу чи акаунта, пошук і копія.
- [Юзер-сторі](user-stories.md) — US-PUB-1…9.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Та сама модель, що для продуктів (B7) | Окремий процес для рецептів | Одна поведінка для автора й модератора |
| Нумеровані версії з історією | Лише остання версія | Можна побачити, що змінилося, і повернутися |
| Складові модеруються разом з рецептом | Блокувати публікацію, доки складові не стануть публічними | Автор подає один раз; модератор бачить контекст |
| Рецепт після видалення акаунта лишається анонімним | Видаляти | Інші сім'ї вже планують і готують за ним |
| Зняття з публікації без модерації, з архівуванням | Видалення | Посилання інших сімей не ламаються |
| `source=default\|community` | Без фільтра | Користувач може обрати лише базові рецепти |
