# Юзер-сторі — бутстрап мобільного застосунку

Критерії приймання для [плану бутстрапу](index.md). AC перевіряються Jest / RNTL або Maestro на варіанті `testing`. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MBOOT-1 — Зв'язок з бекендом
Як розробник, я хочу бачити, що застосунок говорить з правильним бекендом.

**AC-1.1 (Ping):**
- Given варіант `testing` і бекенд у Compose,
- When відкривається застосунок,
- Then екран ping показує `ok` і назву варіанту.

**AC-1.2 (Заголовки):**
- Given будь-який запит API,
- When він відправляється,
- Then містить `X-App-Platform`, `X-App-Version`, `X-Request-ID` і `Accept-Language`.

## US-MBOOT-2 — Помилки
Як користувач, я хочу зрозумілі повідомлення замість технічних кодів.

**AC-2.1 (Код з ui_strings):**
- Given відповідь `problem+json` з `code: auth.invalid_token` і ключ `error.auth.invalid_token` у пакеті,
- When помилка показується,
- Then видно текст з пакета.

**AC-2.2 (Невідомий код):**
- Given ключа для коду немає,
- When помилка показується,
- Then видно `error.generic`.

**AC-2.3 (Помилки полів):**
- Given `422` з `errors[{pointer: "/displayName"}]`,
- When форма отримує відповідь,
- Then помилка під полем імені.

## US-MBOOT-3 — Оновлення
Як користувач старої версії, я хочу знати, що треба оновитися.

**AC-3.1 (426):**
- Given бекенд повертає `426 app.upgrade_required` з `minVersion`,
- When виконується будь-який запит,
- Then показується екран оновлення з посиланням у стор.

## US-MBOOT-4 — Тексти
Як користувач, я хочу бачити актуальні тексти навіть без мережі.

**AC-4.1 (ETag):**
- Given закешований пакет з `ETag`,
- When бекенд відповідає `304`,
- Then застосунок використовує кеш.

**AC-4.2 (Без мережі й кешу):**
- Given перший запуск без мережі,
- When відкривається застосунок,
- Then тексти з вбудованого пакета.

**AC-4.3 (Мова):**
- Given мова пристрою `de`,
- When завантажуються тексти,
- Then використано `uk`.

## US-MBOOT-5 — Тема й примітиви
Як користувач, я хочу темну тему і великі зрозумілі елементи.

**AC-5.1 (Темна тема):**
- Given системна темна тема,
- When відкривається застосунок,
- Then усі примітиви в темній темі; ручний перемикач її змінює.

**AC-5.2 (Доступність):**
- Given найбільший системний розмір шрифту,
- When відкривається бібліотека примітивів,
- Then тексти збільшені, нічого не обрізано, кожна кнопка має підпис для читача екрана.

**AC-5.3 (Скасувати):**
- Given `Toast` з дією «Скасувати»,
- When її натиснуто,
- Then викликається обробник скасування.

## US-MBOOT-6 — Кеш без мережі
Як користувач, я хочу бачити останні дані, коли мережі немає.

**AC-6.1 (Persist):**
- Given екран ping завантажувався онлайн,
- When застосунок перезапускають без мережі,
- Then видно останню відповідь з позначкою «офлайн».

## US-MBOOT-7 — Варіанти й крашлітика
Як розробник, я хочу ставити кілька варіантів поруч і бачити падіння.

**AC-7.1 (Поруч):**
- Given встановлено `staging`,
- When встановлюють `development`,
- Then обидва застосунки на пристрої з різними назвами.

**AC-7.2 (Тестовий краш):**
- Given варіант `staging`,
- When у dev-меню натиснуто «тестовий краш»,
- Then подія в Sentry з символізованим стеком і без персональних даних.

**AC-7.3 (Без dev-меню):**
- Given варіант `production`,
- When виконується жест dev-меню,
- Then нічого не відкривається.
