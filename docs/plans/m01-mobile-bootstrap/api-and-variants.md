# API й варіанти

Як застосунок розмовляє з бекендом, звідки бере тексти і які збірки існують.

## API-шар

Обгортка над `openapi-fetch` з `packages/api-client`:

| Що | Як |
|---|---|
| Заголовки | `X-App-Platform`, `X-App-Version`, `X-Request-ID` (генерує клієнт), `Accept-Language` |
| Помилки | `application/problem+json` → текст з `ui_strings` за ключем `error.<code>`, інакше `error.generic` ([B4](../04-i18n/ui-strings.md#модель)) |
| Помилки полів | `errors[]` → поля форми ([стек](stack.md#форми)) |
| `426 app.upgrade_required` | Глобальний **екран оновлення** з посиланням у стор; `minVersion` з відповіді ([B1](../01-backend-bootstrap/http-and-errors.md#мінімальна-версія-застосунку)) |
| Немає мережі | Запит позначається офлайн, екран показує кеш ([стек](stack.md#серверний-стан)) |

- `401` і refresh — [M2](../../roadmap.md#мобільний-застосунок); `403 feature.disabled`, `426 feature.upgrade_required` і `X-Features-Version` — [M10](../../roadmap.md#мобільний-застосунок).

## Рядки інтерфейсу

- На старті — пакет `GET /v1/i18n/{lang}` з `If-None-Match` ([B4](../04-i18n/ui-strings.md#пакети)).
- Пакет кешується в MMKV; перевірка оновлення — на старті й при поверненні в застосунок.
- Бекенд недоступний → кеш; кешу немає → **вбудований у збірку** пакет з `api i18n export`.
- Мова — з налаштувань пристрою, якщо підтримується (`uk`, `en`), інакше `uk`; з M2 — з профілю акаунта.

## Варіанти застосунку

| | `development` | `testing` | `staging` | `production` |
|---|---|---|---|---|
| Призначення | Розробка | Автотести (Maestro) | Ручна перевірка людьми | Користувачі |
| API | Локальний | Docker Compose у CI | Staging | Production |
| Вхід | `fakeidp` + реальні | Лише `fakeidp` ([B2](../02-app-auth/protection.md)) | Реальні | Реальні |
| Sentry | Вимк. | Вимк. | Увімк. | Увімк. |
| Dev-меню | Так | Так | Так | Ні |
| OTA-канал ([M10](../../roadmap.md#мобільний-застосунок)) | — | — | `staging` | `production` |

- Кожен варіант — свій **bundle id / package name** і назва: усі ставляться на один пристрій поруч.
- Конфіг — `app.config.ts` за змінною варіанту і **EAS build profiles**.
- `testing` **детермінований**: анімації вимкнено, фіксовані таймзона, мова й дата, сид-дані бекенду; людям не роздається.

## Dev-меню

Доступне у `development`, `testing`, `staging` (жест або прихована кнопка):

- **бібліотека примітивів** — усі примітиви у світлій і темній темі;
- **тестовий краш** — перевірка Sentry;
- перемикач теми й мови, поточний варіант, версія, `X-Request-ID` останнього запиту.

## Мінімальні ОС

- **iOS 16+**, **Android 8 (API 26)+**.
- Точні значення фіксуються за обраним Expo SDK на старті.

## Екрани каркаса

- **Ping**: результат `GET /v1/ping` і варіант застосунку.
- **Оновлення**: глобальний екран на `426`.
- Решта — у dev-меню.
