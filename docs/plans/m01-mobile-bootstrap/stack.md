# Стек

Бібліотеки й правила, на яких будується мобільний застосунок.

## Основа

- **Expo** з **dev builds** — нативні модулі (SQLite, secure store, Sentry) без ejection.
- **TypeScript strict**.
- Тека `mobile/` у pnpm workspaces; залежить від `packages/api-client` ([B1](../01-backend-bootstrap/structure.md)).
- SDK — актуальний стабільний на момент старту; оновлення SDK — окремими PR.

## Навігація

- **Expo Router** — файлові маршрути в `mobile/app/`.
- Діплінки й **universal links** — для запрошень ([B5](../05-household/invites.md)), повернення з LLM ([B23](../23-llm-assistant/import.md#вставка)) і share extension.
- Глобальні екрани поверх навігації: оновлення застосунку, банер синхронізації (з M6).

## Серверний стан

- **TanStack Query** поверх `openapi-fetch` (як в адмінці).
- **Persist-кеш** у **MMKV**: після перезапуску без мережі екрани показують останні дані з позначкою «офлайн».
- Офлайн-сутності закупки, готування й обліку — **не тут**, а в SQLite за [B14](../14-offline-sync/client.md#сховище).

## Стан UI

- **Zustand** — невеликий глобальний стан: активна персона, вибраний день, тема.
- Стан, що має пережити перезапуск, — у MMKV.

## Тексти

- **FormatJS** (`react-intl`) — ICU MessageFormat, той самий формат, що в [`ui_strings`](../04-i18n/ui-strings.md#формат).
- Жодних рядків у коді: кожен текст — ключ `<розділ>.<елемент>`.
- Дати, числа, валюта — через `Intl` з мовою користувача.

## UI-примітиви й токени

- **Власні примітиви**: `Text`, `Button`, `IconButton`, `Card`, `Sheet`, `ListItem`, `TextField`, `Toast`, `Skeleton`, `EmptyState`.
- **Токени**: кольори (світла й **темна** тема), відступи, радіуси, типографіка, розміри цілей дотику.
- Тема — за системою, з ручним перемикачем.
- Примітиви одразу закладають [UX-принципи](../../mobile-ux.md#принципи): `Toast` з «Скасувати», `Skeleton`, `EmptyState` з дією, великі цілі (≥ 56 pt) у режимах закупки й готування, динамічний шрифт, підписи для читачів екрана.
- Коли з'явиться Figma, токени синхронізуються з нею.

## Форми

- **react-hook-form + zod**.
- Схеми zod **генеруються з OpenAPI** у `packages/api-client` — валідація на клієнті збігається з контрактом.
- Помилки полів з `errors[]` сервера (`pointer`) прив'язуються до полів форми ([B1](../01-backend-bootstrap/http-and-errors.md#формат-помилок)).

## Безпечне сховище

- **`expo-secure-store`** (Keychain / Keystore): токени й `deviceId` ([B2](../02-app-auth/flows.md)).
- Логіка входу й оновлення токенів — [M2](../../roadmap.md#мобільний-застосунок).

## Крашлітика

- **Sentry React Native SDK**; той самий SDK працює з GlitchTip, тож вибір у [P2](../../roadmap.md#платформа) не блокує.
- `request_id` з відповідей API додається до подій ([B1](../01-backend-bootstrap/observability.md)).
- Source maps завантажуються з CI для кожної збірки (і з M10 — для кожного OTA-оновлення).
- Персональні дані (вага, ім'я, email) не відправляються.
