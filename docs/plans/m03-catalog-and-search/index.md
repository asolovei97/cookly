# M3 · Каталог і пошук

Каркас навігації застосунку і все, що стосується продуктів на клієнті: спільний пікер, пошук, сканер штрихкоду, картка продукту, створення товару й інгредієнта, запис ціни, статус модерації. Спирається на [B6](../06-catalog/index.md), [B7](../07-moderation/index.md), [B8](../08-prices/index.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Таб-бар, панель «+», хедер із чипом активної сесії.
- `CatalogPicker` для всіх наступних M-пунктів.
- Пошук, офлайн-пошук, сканер штрихкоду.
- Перегляд каталогу: дерево категорій, картка продукту.
- Створення товару й інгредієнта, зокрема офлайн.
- Запис ціни вручну, місто й геолокація.
- Статус модерації для автора.

**Не входить**: вміст дешборду ([M9](../../roadmap.md#мобільний-застосунок)), плану ([M5](../../roadmap.md#мобільний-застосунок)), рецептів ([M4](../../roadmap.md#мобільний-застосунок)), сесій закупки й готування ([M6](../../roadmap.md#мобільний-застосунок), [M7](../../roadmap.md#мобільний-застосунок)), скан чека ([M11](../../roadmap.md#мобільний-застосунок)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| «+» посередині таб-бару з трьома діями | Велика панель із сімома діями | Лише те, що роблять щодня; решта — на своїх екранах |
| Вкладки Дешборд · План · «+» · Рецепти · Запаси | Окрема вкладка закупки | Закупка — сесія: вона починається з «+» і живе в чипі |
| Чип сесії в хедері | Смуга над таб-баром | Не з'їдає місце внизу, де працює великий палець |
| «Додати чек» у хедері закупки, «З чека» на старті закупки | Чек у панелі «+» | Чек належить закупці; три тапи до камери, в активній закупці — один |
| Спільний `CatalogPicker` | Свій пошук на кожному екрані | Одна поведінка, один набір UX-лімітів |
| Каталог усередині вкладки «Запаси» | Окрема вкладка | Каталог переглядають рідко, а обирають із нього постійно |
| Спершу мінімум полів товару | Уся форма одразу | Найчастіше досить назви, бренду й упаковки |
