# Юзер-сторі — навігація й пошук

US-MCAT-1…4. Загальні правила — в [індексі юзер-сторі](index.md).

## US-MCAT-1 — Вкладки й панель
Як користувач, я хочу записати їжу чи почати закупку одним рухом.

**AC-1.1 (Вкладки):**
- Given авторизований користувач,
- When відкривається застосунок,
- Then таб-бар: Дешборд, План, «+», Рецепти, Запаси.

**AC-1.2 (Панель):**
- Given будь-яка вкладка,
- When тап на «+»,
- Then панель з трьома діями: Записати їжу, Почати готування, Почати закупку.

**AC-1.3 (З чека):**
- Given будь-яка вкладка,
- When тап на «+», «Почати закупку» і «З чека»,
- Then камера відкрита після трьох тапів.

**AC-1.4 (Вимкнена фіча):**
- Given прапорець `receipts` off,
- When відкривається старт закупки,
- Then шляху «З чека» немає.

## US-MCAT-2 — Чип сесії
Як користувач, я хочу швидко повернутися до закупки.

**AC-2.1 (Чип):**
- Given активна закупка 5 з 12,
- When відкрита будь-яка вкладка,
- Then у хедері чип «Закупка: 5 з 12», тап відкриває закупку.

**AC-2.2 (Перезапуск):**
- Given активна сесія,
- When застосунок перезапускають,
- Then чип на місці.

## US-MCAT-3 — Пікер і пошук
Як користувач, я хочу знаходити продукт однаково всюди.

**AC-3.1 (Нещодавні за 1 тап):**
- Given порожній запит і нещодавній «Рис»,
- When тап на «Рис»,
- Then рис обрано одним тапом.

**AC-3.2 (Порядок сервера):**
- Given приватний товар сім'ї і публічний за запитом «молоко»,
- When показуються результати,
- Then приватний вище.

**AC-3.3 (Чипи):**
- Given результати з інгредієнтами й товарами,
- When обрано чип «Товар»,
- Then лише товари.

**AC-3.4 (Офлайн):**
- Given немає мережі, «Рис» є в запасах,
- When шукають «рис»,
- Then рис у результатах з позначкою «немає мережі».

**AC-3.5 (Немає результату):**
- Given порожні результати,
- When показується список,
- Then дія «Немає такого продукту» відкриває створення.

**AC-3.6 (Новий одразу обрано):**
- Given пікер відкрито з рецепта,
- When створено новий товар,
- Then він обраний у рецепті.

## US-MCAT-4 — Сканер
Як користувач, я хочу знайти товар за штрихкодом.

**AC-4.1 (Знайдено):**
- Given товар зі штрихкодом,
- When штрихкод скановано в режимі вибору,
- Then товар обрано.

**AC-4.2 (Не знайдено):**
- Given `404 catalog.barcode_not_found`,
- When штрихкод скановано,
- Then «Створити товар» зі штрихкодом у формі.

**AC-4.3 (Дозвіл):**
- Given дозвіл на камеру не надано,
- When відкривається сканер,
- Then пояснення і перехід у налаштування ОС.
