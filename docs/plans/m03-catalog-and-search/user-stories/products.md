# Юзер-сторі — продукти

US-MCAT-5…8. Загальні правила — в [індексі юзер-сторі](index.md).

## US-MCAT-5 — Картка
Як користувач, я хочу бачити КБЖВ і ціни товару.

**AC-5.1 (КБЖВ з інгредієнта):**
- Given товар без власних КБЖВ,
- When відкривається картка,
- Then КБЖВ інгредієнта з позначкою.

**AC-5.2 (Ціна):**
- Given ціни товару в АТБ і Сільпо у місті сім'ї,
- When відкривається картка,
- Then обидві ціни зі свіжістю; без цін — «ціна невідома».

## US-MCAT-6 — Створення
Як користувач, я хочу додати товар, якого немає, за кілька секунд.

**AC-6.1 (Мінімум полів):**
- Given обрано інгредієнт,
- When відкривається форма,
- Then видно назву, бренд, упаковку, а решта згорнуто; КБЖВ підставлені.

**AC-6.2 (kcalMismatch):**
- Given власні КБЖВ з розбіжністю понад 15%,
- When зберігається товар,
- Then м'яке попередження, товар збережено.

**AC-6.3 (Офлайн):**
- Given немає мережі,
- When створюється товар,
- Then він одразу доступний у пікері, операція в черзі.

**AC-6.4 (Зайнятий штрихкод):**
- Given `409 catalog.barcode_taken`,
- When зберігається товар,
- Then пропозиція відкрити наявний товар.

**AC-6.5 (Інгредієнт):**
- Given немає інгредієнта,
- When «Немає такого інгредієнта» і заповнено обов'язкове,
- Then приватний інгредієнт сім'ї створено.

## US-MCAT-7 — Ціна
Як користувач, я хочу записати ціну, яку побачив у магазині.

**AC-7.1 (Місто сім'ї):**
- Given місто сім'ї Київ,
- When відкривається запис ціни,
- Then підставлено Київ.

**AC-7.2 (Геолокація):**
- Given перший запис ціни, дозвіл надано, найближче місто Львів,
- When відкривається запис,
- Then підказка «Ви у Львові? Записати ціну для Львова».

**AC-7.3 (Місто вручну):**
- Given у сім'ї немає міста,
- When вручну обрано Львів і збережено,
- Then пропозиція зробити Львів містом сім'ї.

## US-MCAT-8 — Модерація
Як автор, я хочу знати, що сталося з моїм продуктом.

**AC-8.1 (Відхилено):**
- Given товар `rejected` з причиною,
- When відкривається картка,
- Then причина і «Подати знову»; без змін — `409 moderation.unchanged` зрозумілим текстом.

**AC-8.2 (Схвалено):**
- Given товар схвалено,
- When відкривається картка,
- Then відмітка «Схвалено — тепер бачать усі».
