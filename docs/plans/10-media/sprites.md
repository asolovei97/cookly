# Спрайти

Що треба намалювати для [генератора](pixel-art.md), у якому форматі і як це зробити в Pixelorama. Спрайти малює автор проєкту; перший набір генерує агент-дизайнер за [промптом](sprites-prompt.md).

## Набір

| Що | Розмір | Файли |
|---|---|---|
| **Посуд**: `plate`, `bowl`, `glass`, `board`, `jar` | 32×32 | `vessel-<key>.png` + `vessel-<key>-fill.png` |
| **Топінги категорій** — для 10 вузлів верхнього рівня [дерева](../06-catalog/categories.md#початкове-дерево) і важливих підвузлів: `dairy`, `eggs`, `poultry`, `fish`, `crustaceans`, `gluten-grains`, `gluten-free-grains`, `legumes`, `tree-nuts`, `sauces`, `alcohol`. Решта вузлів успадковує спрайт предка | 8×8 | `topping-cat-<key>.png` |
| **Конкретні топінги**: `egg`, `greens`, `tomato`, `cucumber`, `carrot`, `onion`, `potato`, `beet`, `meat`, `chicken`, `fish`, `cheese`, `mushroom`, `lemon`, `berries` | 8×8 | `topping-<sprite_key>.png` |
| **Фони** | 32×32 | `bg-1.png` … `bg-4.png` |

- **Маска наповнення** `vessel-<key>-fill.png`: білий піксель — сюди генератор наливає колір страви; прозорий — ні.
- Усі файли — PNG з **прозорим фоном** (крім фонів).
- Кожен піксель — лише з **палітри**.

## Палітра

- **24 кольори**, орієнтовані на їжу: кілька відтінків червоного й помаранчевого (буряк, томат, морква), жовтого (яйце, сир), зеленого (зелень, огірок), коричневого (м'ясо, хліб, гречка), білого й кремового (рис, сметана), сірого й темного (посуд, контур).
- Зберігається у двох форматах: `palette.hex` (для генератора) і `palette.gpl` (GIMP-палітра для імпорту в редактор).

## Маніфест

`backend/internal/pixelart/sprites/sprites.json`:

```json
{
  "version": 3,
  "vessels": { "bowl": { "file": "vessel-bowl.png", "fill": "vessel-bowl-fill.png" } },
  "toppings": { "egg": { "file": "topping-egg.png", "anchor": [4, 7] } },
  "categoryToppings": { "produce": "topping-cat-produce.png" },
  "backgrounds": ["bg-1.png", "bg-2.png", "bg-3.png", "bg-4.png"]
}
```

- `anchor` — точка топінга (x, y), яка ставиться в обрану генератором позицію.
- **`version`** збільшується з кожною зміною спрайтів: від неї залежить перегенерація картинок.
- Тест перевіряє: кожен файл маніфесту існує, має правильний розмір, усі пікселі — з палітри, маска посуду не порожня.

## Кроки в Pixelorama

1. **Палітра**: імпортуй `palette.gpl` через меню палітр і зроби її активною. Назви пунктів меню можуть відрізнятися між версіями.
2. **Новий файл**: розмір 32×32 для посуду й фонів або 8×8 для топінгів, прозорий фон.
3. **Сітка**: увімкни піксельну сітку і збільш масштаб, щоб бачити кожен піксель.
4. **Малювання**: олівець розміром 1 px, лише кольори з палітри. Для посуду — спершу контур, потім тіні.
5. **Маска посуду**: дубль файлу, де область наповнення залита білим, а решта прозора. Збережи як `vessel-<key>-fill.png`.
6. **Доправка згенерованого агентом**: відкрий PNG, виправ пікселі, збережи з тим самим ім'ям.
7. **Експорт**: PNG без масштабування (1×), ім'я за таблицею вище, у теку `backend/internal/pixelart/sprites/`.
8. **Маніфест**: додай або онови запис у `sprites.json`, для топінга вкажи `anchor`, збільш `version`.
9. **Перевірка**: `pixelart sheet --out sheet.png` і перегляд контактного аркуша; тест маніфесту має проходити.
