# Промпт для агента-дизайнера

Промпт, щоб агент згенерував перший набір спрайтів. Автор потім доправляє їх у Pixelorama за [кроками](sprites.md#кроки-в-pixelorama).

## Промпт

```text
Ти — піксель-арт дизайнер. Створи набір спрайтів для генератора обкладинок
рецептів у застосунку Cookly. Стиль — простий, теплий, читабельний на 32×32,
з темним контуром і 1–2 рівнями тіні. Не копіюй стиль чи палітру жодної
наявної гри чи продукту.

1. Палітра. Склади власну палітру рівно з 24 кольорів, орієнтовану на їжу:
   червоні/помаранчеві (буряк, томат, морква), жовті (яйце, сир), зелені
   (зелень, огірок), коричневі (м'ясо, хліб, гречка), білі/кремові (рис,
   сметана), сірі й темні (посуд, контур). Збережи як palette.hex (один
   hex на рядок) і palette.gpl (формат GIMP Palette).

2. Спрайти. Кожен піксель — лише з палітри, фон прозорий (крім фонів).
   Генеруй PNG кодом (наприклад, Python + Pillow з матриць пікселів),
   щоб розміри й кольори були точними. Без згладжування.
   - Посуд 32×32: plate, bowl, glass, board, jar →
     vessel-<key>.png і маска vessel-<key>-fill.png (білий — область,
     куди наливається страва; решта прозора). Область наповнення має
     займати помітну частину посуду.
   - Топінги 8×8 для конкретних інгредієнтів: egg, greens, tomato,
     cucumber, carrot, onion, potato, beet, meat, chicken, fish, cheese,
     mushroom, lemon, berries → topping-<key>.png.
   - Топінги 8×8 для категорій: milk-eggs, meat, seafood, produce,
     grocery, bakery, sweets-snacks, frozen, ready-meals, drinks, dairy,
     eggs, poultry, fish, crustaceans, gluten-grains, gluten-free-grains,
     legumes, tree-nuts, sauces, alcohol → topping-cat-<key>.png.
   - Фони 32×32: bg-1 … bg-4 — спокійні текстури (скатертина, дерево,
     плитка, однотон) з малою кількістю кольорів, щоб не відволікали від
     страви.

3. Маніфест sprites.json:
   {
     "version": 1,
     "vessels": { "<key>": { "file": "...", "fill": "..." } },
     "toppings": { "<key>": { "file": "...", "anchor": [x, y] } },
     "categoryToppings": { "<key>": "..." },
     "backgrounds": ["bg-1.png", "bg-2.png", "bg-3.png", "bg-4.png"]
   }
   anchor — піксель топінга, який ставиться в точку розміщення
   (зазвичай нижній центр).

4. Контактний аркуш. Склади один PNG, де всі спрайти розкладені сіткою
   і збільшені в 8 разів без згладжування, з підписами ключів.

Перевір перед здачею: усі файли існують, розміри точні, усі
непрозорі пікселі — з палітри, маски посуду не порожні.
```

## Що далі

1. Поклади результат у `backend/internal/pixelart/sprites/`.
2. Переглянь контактний аркуш і `pixelart sheet` з реальними рецептами.
3. Доправ спрайти в Pixelorama, збільш `version` у маніфесті.
4. Ключі категорій у маніфесті — це `key` вузлів [дерева категорій](../06-catalog/categories.md#початкове-дерево).
