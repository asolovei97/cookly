# Юзер-сторі — сім'я

Критерії приймання для [плану сім'ї](../index.md). AC перевіряються на рівні API. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Сім'я](household.md) — US-HH-1…5: створення, редагування й місто, права, видимість, вихід і передача ролі.
- [Персони](persons.md) — US-HH-6…10: персони, норма, діти, історія ваги, запрошення.
