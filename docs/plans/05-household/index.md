# B5 · Сім'я

Сім'я, персони, цілі й норми, історія ваги, коди запрошення і права всередині сім'ї. Продуктовий опис — у [сім'ї і персонах](../../accounts/household.md) та [цілях і нормах](../../accounts/goals.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Створення сім'ї на онбордингу разом з персоною акаунта.
- Персони: поля, редагування, архівування.
- Розрахунок норми калорій і БЖВ, межі безпеки, діти, ручне перевизначення.
- Історія ваги.
- Коди запрошення, приєднання до сім'ї.
- Права й видимість, вихід, видалення учасника, передача ролі `owner`.
- Довідник `cities` з початковим списком міст України.

**Не входить**: обладнання й запаси на онбордингу ([B6](../../roadmap.md#бекенд), [B13](../../roadmap.md#бекенд)), бюджет ([B18](../../roadmap.md#бекенд)), графік ваги ([B18](../../roadmap.md#бекенд)), редагування міст з адмінки ([B6](../../roadmap.md#бекенд) / [A3](../../roadmap.md#адмінка)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Місто необов'язкове, питаємо за контекстом | Обов'язкове на онбордингу | Онбординг коротший; місто люди вводять охоче, коли бачать навіщо; без міста працює медіана по Україні |
| Темп цілі в кг на тиждень | Відсоток від витрат | Зрозуміліше людям |
| Дефіцит ≤ 25% витрат і норма ≥ BMR | Без меж | Безпека користувачів дієтичного застосунку |
| Діти: лише «підтримка», норма з таблиці EFSA | Mifflin-St Jeor для всіх; лише ручне введення | Формула розрахована на дорослих; дефіцит дітям не пропонуємо |
| Вага персони з акаунтом приватна | Усе видно всім | Вага — чутливі дані; для планування порцій достатньо норм |
| Учасник виходить — персона лишається | Персона йде разом з акаунтом | Історія меню й готувань сім'ї не ламається |
| М'яке видалення персон | Фізичне видалення | На персону посилаються облік з'їденого й плани |
