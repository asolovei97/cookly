# Персони й норми

Поля персони, історія ваги і розрахунок добової норми калорій та БЖВ.

## Поля персони

| Поле | Значення |
|---|---|
| Ім'я | Для персони акаунта за замовчуванням — `displayName` |
| Стать | `male` \| `female` — потрібна для формули |
| Рік народження | Для персони акаунта — з реєстрації ([B2](../02-app-auth/flows.md#реєстрація)) |
| Зріст | См |
| Рівень активності | Див. таблицю нижче |
| Ціль | `lose` \| `maintain` \| `gain` |
| Темп | Кг на тиждень: схуднення 0,25 / 0,5 / 0,75; набір 0,25 / 0,5 |
| Вага | Останній запис історії ваги |

### Рівні активності

| Рівень | Коефіцієнт |
|---|---|
| Сидячий | 1,2 |
| Легка (1–3 тренування на тиждень) | 1,375 |
| Помірна (3–5) | 1,55 |
| Висока (6–7) | 1,725 |
| Дуже висока (фізична робота + спорт) | 1,9 |

## Історія ваги

- Запис: дата і вага в кг. Поточна вага персони — останній запис.
- Записи вводяться вручну; згодом туди ж писатимуть [інтеграції зі здоров'ям](../../health-integrations.md).
- Графік — у [B18](../../roadmap.md#бекенд).

## Розрахунок норми (від 18 років)

1. **BMR** за Mifflin-St Jeor: `10 × вага + 6,25 × зріст − 5 × вік + 5` (чоловіки) або `− 161` (жінки). Вік — поточний рік мінус рік народження.
2. **Добові витрати (TDEE)** = BMR × коефіцієнт активності.
3. **Поправка на ціль**: `темп × 7700 / 7` ккал на день; для схуднення віднімається, для набору додається.
4. **Межі безпеки** для схуднення: дефіцит не більше **25% TDEE**, і норма не нижча за **BMR**. Якщо обраний темп виходить за межі, норма обрізається, і у відповіді є попередження (`normCapped: true`).

## БЖВ за замовчуванням

| Ціль | Білок | Жири | Вуглеводи |
|---|---|---|---|
| Схуднення | 1,8 г/кг | 25–30% калорій | Решта |
| Підтримка | 1,4 г/кг | 25–30% калорій | Решта |
| Набір | 1,8 г/кг | 25–30% калорій | Решта |

## Діти й підлітки (до 18 років)

- Ціль — **лише `maintain`**; інші цілі відхиляються → `422 household.goal_not_allowed`.
- Норма береться з **довідкової таблиці EFSA** (енергетичні потреби за віком і статтю, ~20 рядків); значення вносяться під час реалізації з першоджерела.
- БЖВ — ті самі правила, що для `maintain`.

## Ручне перевизначення

- Можна задати калорії й БЖВ у грамах вручну (наприклад, за порадою дієтолога).
- Перевизначення **лишається**, доки його не скинуть, навіть якщо змінюється вага.

## Перерахунок

Без ручного перевизначення норма перераховується автоматично, коли змінюються вага (новий запис), активність, ціль, темп, зріст або настає новий рік (вік).
