# Початкові дані

Як база інгредієнтів наповнюється даними USDA.

## Процес

1. **Офлайн-скрипт** `tools/usda-extract` у репозиторії бере набори FDC **Foundation** і **SR Legacy** та список обраних `fdc_id` і формує невеликий файл `catalog/seed/ingredients.json`:
   - назви `uk` / `en`;
   - категорія;
   - базова одиниця, нутрієнти;
   - власні одиниці (`шт` для яйця), густина, колір.
2. **Переклади й вичитка**: чернетку перекладу можна зробити з допомогою LLM, але кожну позицію вичитує людина. Файл проходить рев'ю в PR як код.
3. **`api catalog seed`** запускається під час деплою, як міграції чи `i18n sync`:
   - записи зіставляються за `fdc_id`, тож запуск можна повторювати;
   - нові записи додаються;
   - записи, які **змінив адмін**, не перезаписуються;
   - записи, яких більше немає у файлі, не видаляються.

Обсяг — ~500–1000 найуживаніших позицій.

## Чому не воркер

Вихідні дані FDC — сотні мегабайтів, а потрібно ~700 позицій. Малий файл у репозиторії швидко завантажується, вичитується в PR і не потрапляє в образ як важкий артефакт.
