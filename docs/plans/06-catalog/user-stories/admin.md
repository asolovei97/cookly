# Юзер-сторі — обладнання й адмінка

US-CAT-6…10. Загальні правила — в [індексі юзер-сторі](index.md).

## US-CAT-6 — Обладнання сім'ї
Як користувач, я хочу відмітити, що є на кухні, і зберегти вагу каструль.

**AC-6.1 (Кілька каструль):**
- Given тип `cookware` «Каструля»,
- When учасник додає «велика каструля» з тарою 2100 г і «мала каструля» з тарою 900 г,
- Then обидва записи зберігаються.

**AC-6.2 (Тара для приладу):**
- Given тип `appliance` «Блендер»,
- When учасник задає йому вагу тари,
- Then повертається `422` з кодом `catalog.tare_not_applicable`.

**AC-6.3 (Чуже обладнання):**
- Given обладнання сім'ї A,
- When користувач сім'ї B намагається його змінити,
- Then повертається `404`.

## US-CAT-7 — Довідники в адмінці
Як модератор, я хочу вести довідники каталогу.

**AC-7.1 (Створення інгредієнта):**
- Given `moderator`,
- When він створює інгредієнт з назвами `uk` і `en`, густиною й власними одиницями,
- Then інгредієнт стає публічним, а в аудиті з'являється запис.

**AC-7.2 (Без права):**
- Given адмін лише з роллю `translator`,
- When він змінює мережу чи категорію,
- Then повертається `403` з кодом `admin.forbidden`.

**AC-7.3 (Міста й мережі):**
- Given `moderator`,
- When він додає місто і мережу,
- Then вони з'являються в `GET /v1/cities` і в довіднику мереж.

## US-CAT-8 — Архівування
Як модератор, я хочу прибрати продукт з пошуку, не ламаючи історію.

**AC-8.1 (Архівування):**
- Given публічний товар, на який посилається інший запис,
- When `moderator` видаляє його,
- Then товар архівується: зникає з пошуку, але `GET /v1/catalog/products/{id}` і далі його повертає.

## US-CAT-9 — Початкові дані
Як розробник, я хочу наповнити каталог з USDA, не затираючи правки модераторів.

**AC-9.1 (Перший запуск):**
- Given порожній каталог і файл `catalog/seed/ingredients.json`,
- When запускається `api catalog seed`,
- Then усі позиції файлу з'являються як публічні інгредієнти з `fdc_id`.

**AC-9.2 (Повторний запуск):**
- Given модератор змінив назву одного інгредієнта, а у файлі додано нову позицію,
- When `api catalog seed` запускається знову,
- Then нова позиція додається, змінена назва лишається, і дублікатів немає.

## US-CAT-10 — Унікальність штрихкодів
Як модератор, я хочу, щоб один штрихкод вів на один публічний товар.

**AC-10.1 (Зайнятий штрихкод):**
- Given публічний товар зі штрихкодом X,
- When модератор додає X іншому публічному товару,
- Then повертається `409` з кодом `catalog.barcode_taken`.

**AC-10.2 (Приватні дублікати):**
- Given публічний товар зі штрихкодом X,
- When користувач створює приватний товар з тим самим X,
- Then товар створюється.
