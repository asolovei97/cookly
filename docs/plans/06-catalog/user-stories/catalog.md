# Юзер-сторі — каталог

US-CAT-1…5. Загальні правила — в [індексі юзер-сторі](index.md).

## US-CAT-1 — Пошук продукту
Як користувач, я хочу швидко знайти продукт за назвою чи штрихкодом.

**AC-1.1 (Ранжування):**
- Given приватний товар сім'ї «Молоко домашнє» і публічний інгредієнт «Молоко 2,5%»,
- When користувач шукає «молоко»,
- Then приватний товар іде першим, публічний — після нього.

**AC-1.2 (Фільтр):**
- Given продукти різних категорій,
- When користувач шукає з `category=молочні`,
- Then повертаються лише продукти цієї категорії.

**AC-1.3 (Чужі й архівні записи):**
- Given приватний товар іншої сім'ї і архівний публічний товар з відповідною назвою,
- When користувач шукає,
- Then жоден з них не повертається.

**AC-1.4 (Штрихкод знайдено):**
- Given публічний товар зі штрихкодом `4820000000001`,
- When клієнт викликає `GET /v1/catalog/barcodes/4820000000001`,
- Then повертається цей товар.

**AC-1.5 (Штрихкод не знайдено):**
- Given штрихкоду немає серед публічних і своїх товарів,
- When клієнт його шукає,
- Then повертається `404` з кодом `catalog.barcode_not_found`.

## US-CAT-2 — Свій товар
Як користувач, я хочу додати товар, якого немає в базі, і одразу ним користуватися.

**AC-2.1 (Створення):**
- Given публічний інгредієнт «Молоко 2,5%» з базою `ml`,
- When користувач створює товар з назвою, брендом, `soldBy: package` і розміром упаковки 900,
- Then товар створюється зі `status: private`, власником — сім'єю, базою `ml`, і його бачать усі учасники сім'ї.

**AC-2.2 (Без нутрієнтів):**
- Given товар створено без нутрієнтів,
- When клієнт запитує його картку,
- Then нутрієнти беруться з інгредієнта.

**AC-2.3 (Невідповідність калорій):**
- Given користувач вводить калорії, що відрізняються від `4Б + 9Ж + 4В` більше ніж на 15%,
- When він зберігає товар,
- Then товар зберігається, а відповідь містить `kcalMismatch: true`.

**AC-2.4 (Інша сім'я):**
- Given приватний товар сім'ї A,
- When користувач сім'ї B запитує його картку чи змінює її,
- Then повертається `404`.

**AC-2.5 (Публічний товар):**
- Given публічний товар,
- When користувач намагається його змінити,
- Then повертається `403` з кодом `catalog.forbidden`.

## US-CAT-3 — Свій інгредієнт
Як користувач, я хочу додати екзотичний продукт, для якого немає типового інгредієнта.

**AC-3.1 (Створення):**
- Given користувач у сім'ї,
- When він створює інгредієнт з назвою, категорією, базовою одиницею і нутрієнтами,
- Then інгредієнт створюється зі `status: private` без густини, навіть якщо її передано.

## US-CAT-4 — Одиниці
Як користувач, я хочу вводити кількість у звичних одиницях.

**AC-4.1 (Власні одиниці товару):**
- Given Twix з `шт` = 40 г і AXA з `шт` = 25 г,
- When клієнт запитує картки,
- Then у кожного своя вага `шт`.

**AC-4.2 (Об'ємна одиниця без густини):**
- Given інгредієнт у `g` без густини,
- When до нього застосовують `склянка`,
- Then повертається `422` з кодом `catalog.unit_not_applicable`.

**AC-4.3 (Об'ємна одиниця з густиною):**
- Given борошно з густиною 0,55,
- When застосовують 1 `склянка`,
- Then кількість у базі дорівнює 137,5 г.

## US-CAT-5 — База КБЖВ
Як користувач, я хочу вводити КБЖВ так, як написано на етикетці.

**AC-5.1 (На 100 г для рідини):**
- Given інгредієнт «Олія соняшникова» з базою `ml` і густиною 0,92,
- When користувач створює товар з нутрієнтами «на 100 г»,
- Then нутрієнти зберігаються перерахованими на 100 мл.

**AC-5.2 (Без густини):**
- Given інгредієнт з базою `ml` без густини,
- When користувач створює товар з нутрієнтами «на 100 г»,
- Then повертається `422` з кодом `catalog.unit_not_applicable`.
