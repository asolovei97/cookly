# Довідники

Обладнання, обладнання сім'ї, мережі й міста, а також ендпоінти каталогу. Категорії — в [окремому документі](categories.md).

## Обладнання

- Довідник: назва (`i18n.Text`), тип `appliance` (духовка, блендер, аерогриль) або `cookware` (каструля, сковорода).
- **Рядок довідника** зберігає **типові значення** у звичайних колонках: об'єм, вага тари, діаметр, потужність тощо. JSONB не використовується.
- **Обладнання сім'ї** (`household_equipment`) — посилання на рядок довідника, власна назва («велика каструля») і **ті самі колонки як nullable**: значення = своє, якщо задано, інакше типове. ~~Лише вага тари в г.~~
  - Кілька одиниць одного типу дозволено.
  - Вагу тари можна задати лише для `cookware` → інакше `422 catalog.tare_not_applicable`.
  - Змінювати може будь-який учасник сім'ї.
- **Опис полів**: `GET /v1/equipment/types` віддає для кожного типу `fields[]` — застосовні колонки, одиниця, мітка, межі; значення приходять мапою `values`. Клієнт малює форму за `fields[]`, тож новий атрибут — це міграція й запис в описі полів, без релізу застосунку ([M2](../m02-sign-in-and-onboarding/kitchen-scenes.md#картка)).
- **Поля сцени**: спрайт, `sceneX`, `sceneY` (нормалізовані), шар — з них будується [сцена обладнання](../m02-sign-in-and-onboarding/kitchen-scenes.md#обладнання). Рядок без координат потрапляє в ряд «Інше». Редагує адмін разом із довідником.
- Вимоги рецептів до обладнання — [B9](../../roadmap.md#бекенд).

## Мережі

Назва, країна, `active`. Потрібні [цінам](../../prices/observations.md) ([B8](../../roadmap.md#бекенд)).

## Міста

Довідник `cities` з'явився в [B5](../05-household/household.md#місто); у B6 додається редагування з адмінки.

## Ендпоінти застосунку

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/catalog/search` | Пошук, див. [пошук](search.md) |
| `GET /v1/catalog/barcodes/{code}` | Товар за штрихкодом |
| `GET /v1/catalog/ingredients/{id}`, `GET /v1/catalog/products/{id}` | Картка з одиницями й нутрієнтами |
| `POST /v1/catalog/ingredients`, `POST /v1/catalog/products` | Створити приватний запис сім'ї |
| `PATCH /v1/catalog/ingredients/{id}`, `PATCH /v1/catalog/products/{id}` | Змінити свій приватний запис |
| `GET /v1/catalog/categories`, `GET /v1/catalog/units`, `GET /v1/catalog/equipment` | Довідники |
| `GET`/`POST /v1/household/equipment`, `PATCH`/`DELETE /v1/household/equipment/{id}` | Обладнання сім'ї |

## Адмін-API

- `/admin/v1/catalog/...` — CRUD інгредієнтів, товарів, одиниць, категорій, обладнання, мереж, міст.
- Право «довідники» (`admin`, `moderator`), див. [матрицю](../03-admin-auth/access.md#ролі-й-права); перекладні поля — повна мапа ([B4](../04-i18n/content.md#форма-api)).
- Кожна зміна пишеться в [аудит](../03-admin-auth/audit-and-users.md#аудит).
- Видалення = архівування.
