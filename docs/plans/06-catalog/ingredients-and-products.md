# Інгредієнти й товари

Дві сутності каталогу: типовий **інгредієнт** і конкретний **товар** (SKU), що йому належить. Модель — у [концепції](../../catalog/ingredients-and-products.md).

## Що є в каталозі

Лише продукти, **які купують**: сирі (рис, курка) або вже готові з магазину (ковбаса, хумус). Варене й приготоване — це [рецепти з типовим виходом](../../recipes/recipes.md), а не продукти.

## Нутрієнти

На 100 одиниць бази (`g` або `ml`).

| Нутрієнт | Обов'язковий |
|---|---|
| Калорії (ккал) | Так |
| Білки, жири, вуглеводи (г) | Так |
| Клітковина, цукор, насичені жири (г), сіль (г) | Ні |

- Калорії зберігаються **явно**.
- Якщо калорії продукту від користувача відрізняються від `4Б + 9Ж + 4В` більше ніж на 15%, відповідь містить попередження `kcalMismatch: true`. Зберегти можна.

## Інгредієнт

| Поле | Примітка |
|---|---|
| Назва | `i18n.Text`, [B4](../04-i18n/content.md) |
| Категорія | З [довідника](directories.md#категорії) |
| Базова одиниця | `g` \| `ml` |
| Нутрієнти | Обов'язкові |
| Густина | Г/мл, необов'язкова, задає лише адмін, див. [одиниці](units.md#густина) |
| Власні одиниці | `шт`, `порція`… із середньою вагою, див. [одиниці](units.md) |
| `color`, `sprite_key` | Для [піксельних картинок](../../recipes/pixel-art.md); необов'язкові |
| `fdc_id` | Для записів з USDA |

## Товар

| Поле | Примітка |
|---|---|
| Інгредієнт | Обов'язковий |
| Назва | Обов'язкова |
| Бренд | Необов'язковий |
| Базова одиниця | **Завжди як в інгредієнта** |
| `soldBy` | `package` — упаковка з розміром у базових одиницях і назвою («пачка»); `weight` — на вагу, ціна за кг чи л |
| Нутрієнти | Необов'язкові; без них беруться нутрієнти інгредієнта. База — див. [одиниці](units.md#база-кбжв-товару) |
| Власні одиниці | `шт` = 40 г для Twix тощо |
| Штрихкоди | 0…n, EAN-13 / EAN-8 |

## Штрихкоди

- Окрема таблиця: в одного товару може бути кілька штрихкодів.
- Серед **публічних** товарів штрихкод **унікальний**: `409 catalog.barcode_taken`.
- У приватних товарах різних сімей штрихкоди можуть повторюватися; дублікати розбирає [B7](../../roadmap.md#бекенд).

## Власність і статуси

- `ownerHouseholdId`: `null` — публічний запис; інакше — приватний запис сім'ї.
- `status`: `private` | `pending` | `public` | `rejected`. Переходи між статусами — [B7](../07-moderation/workflow.md).
- Схвалення **не передає власність**, а створює публічну копію; приватний оригінал лишається в сім'ї, див. [публічну копію](../07-moderation/workflow.md#публічна-копія).
- Користувач може створити **товар** на основі наявного інгредієнта і **новий інгредієнт**, якщо типового немає.
- Приватні записи бачить і редагує лише своя сім'я; іншим сім'ям вони недоступні (`404`).
- Публічні записи користувач не редагує.

## Архівування

- Публічний запис не видаляється, а **архівується**: зникає з пошуку, але посилання з рецептів та історії працюють.
- Приватний запис сім'ї теж архівується, якщо на нього вже посилаються; інакше видаляється.
- Перенаправлення архівного запису на інший (об'єднання) — [B7](../07-moderation/merge.md).
