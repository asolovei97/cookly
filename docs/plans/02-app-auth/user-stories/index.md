# Юзер-сторі — авторизація застосунку

Критерії приймання для [плану авторизації](../index.md). AC перевіряються на рівні API. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Вхід і сесії](sign-in.md) — US-AUTH-1…5: вхід, реєстрація, оновлення токенів, пристрої, кілька провайдерів.
- [Акаунт і захист](account.md) — US-AUTH-6…10: видалення, блокування, ліміти, безпечна конфігурація, профіль.
