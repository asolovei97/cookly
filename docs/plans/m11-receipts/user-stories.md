# Юзер-сторі — скан чеків

Критерії приймання для [плану M11](index.md). AC перевіряються Maestro на варіанті `testing` з бекендом і сторінками-фікстурами або RNTL. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MRCPT-1 — Скан
Як покупець, я хочу відсканувати чек за секунду.

**AC-1.1 (QR):**
- Given відкрито сканер,
- When розпізнано QR із URL чека,
- Then вібрація, екран очікування, `receipt.submit@1` у черзі.

**AC-1.2 (Не чек):**
- Given QR з посиланням, не схожим на чек,
- When розпізнано,
- Then пояснення, нічого не надіслано.

**AC-1.3 (Дозвіл):**
- Given дозволу камери немає,
- When відкривається сканер,
- Then пояснення і перехід у налаштування ОС.

## US-MRCPT-2 — Очікування
Як покупець, я не хочу чекати на екрані.

**AC-2.1 (Закрити):**
- Given «Читаємо чек…»,
- When екран закрито і чек розібрано,
- Then чип «Чек готовий» у хедері закупки.

**AC-2.2 (Офлайн):**
- Given немає мережі,
- When QR скановано,
- Then «Чек у черзі», закупка працює; після появи мережі чек розібрано.

## US-MRCPT-3 — Прев'ю
Як покупець, я хочу швидко перевірити, що розпізнано.

**AC-3.1 (Групи):**
- Given рядки різних станів,
- When показується прев'ю,
- Then порядок: Потребують уваги, Розпізнані, Не їжа.

**AC-3.2 (Підтвердження завжди):**
- Given 2 незіставлені рядки,
- When «Підтвердити»,
- Then чек `confirmed`, рядки пропущені: не в запасах і цінах, сума в бюджеті.

**AC-3.3 (Офлайн):**
- Given прев'ю завантажено, немає мережі,
- When «Підтвердити»,
- Then операція в черзі.

## US-MRCPT-4 — Зіставлення
Як покупець, я хочу виправити рядок за кілька тапів.

**AC-4.1 (Кандидат):**
- Given рядок `КурячеКгФіле`,
- When тап і вибір «Куряче філе»,
- Then рядок у «Розпізнаних», аліас запам'ятовується.

**AC-4.2 (Не їжа):**
- Given рядок «Пакет»,
- When «Не їжа»,
- Then рядок у групі «Не їжа»; наступний чек позначить його сам.

**AC-4.3 (Одиниця):**
- Given 3 шт інгредієнта без товару,
- When обрано чип `шт`,
- Then +3 шт після підтвердження.

## US-MRCPT-5 — Закупка
Як покупець, я хочу закрити список одним чеком.

**AC-5.1 (Наслідки):**
- Given чек з хедера активної закупки,
- When показується прев'ю,
- Then «Закриє 8 позицій, додасть 3 нові, оновить ціну 2».

**AC-5.2 (Окрема):**
- Given немає активної закупки,
- When «З чека» і підтвердження,
- Then завершена закупка з чека; запаси, ціни й бюджет оновлені.

**AC-5.3 (Завершена):**
- Given закупку завершено до підтвердження,
- When приходить `shopping.completed`,
- Then пропозиція підтвердити окремо.

## US-MRCPT-6 — Стани й список
Як користувач, я хочу розуміти, що з чеком.

**AC-6.1 (Не підтримується):**
- Given `unsupported`,
- When показується статус,
- Then пояснення і перехід до запису вручну.

**AC-6.2 (Дублікат):**
- Given чек іншої сім'ї,
- When `duplicate`,
- Then «Цей чек уже додано» без переходу; для своєї сім'ї — з переходом.

**AC-6.3 (Повтор):**
- Given `failed`,
- When «Спробувати ще раз»,
- Then імпорт знову `queued`.

**AC-6.4 (Мої чеки):**
- Given незавершене прев'ю і підтверджений чек,
- When відкривається список,
- Then прев'ю нагорі.

**AC-6.5 (Прапорець):**
- Given `receipts` off,
- When відкривається старт закупки й хедер,
- Then шляхів до чека немає.
