# Доступ

Як з'являються адміни, як вони автентифікуються і що їм дозволено.

## Створення адмінів

- **Самостійної реєстрації немає.**
- **Перший адмін** — CLI-команда `api admin create --email … --role admin`. Вона ж рятує, якщо доступ втрачено.
- **Наступних** створює `admin` в адмінці: email і ролі. Система видає **одноразове посилання для налаштування**, яке діє 24 години. Адмін копіює його і передає новому адміну вручну.
- За посиланням новий адмін задає пароль і налаштовує TOTP. Посилання стає недійсним після використання.

## Паролі

- Хеш **argon2id**.
- Мінімум **12 символів**, перевірка за локальним списком найпоширеніших паролів. Порушення → `422 admin.weak_password`.
- Без примусової періодичної зміни.
- Без перевірки через зовнішні сервіси (HIBP).

## TOTP

- **Обов'язковий для всіх** адмінів; налаштовується за посиланням під час створення акаунта.
- Під час налаштування видаються **10 одноразових кодів відновлення**. Кожен спрацьовує лише раз.
- Адмін втратив пристрій → інший `admin` **скидає 2FA**: сесії цього адміна відкликаються, і видається нове посилання для налаштування.

## Ролі й права

- В адміна може бути **кілька ролей**.
- Матриця ролей і прав зберігається **в коді**.

| Право | admin | moderator | translator |
|---|---|---|---|
| Керувати адмінами | ✅ | | |
| Модерація | ✅ | ✅ | |
| Довідники | ✅ | ✅ | |
| Переклади | ✅ | | ✅ |
| Перегляд користувачів застосунку | ✅ | ✅ | |
| Блокування користувачів | ✅ | ✅ | |
| Перегляд аудиту | ✅ | | |

## x-permission

- Кожна операція адмін-контракту має розширення `x-permission` (наприклад `moderation.review`, `users.suspend`).
- Middleware звіряє його з ролями адміна, як `security` у [B1](../01-backend-bootstrap/http-and-errors.md#безпека-за-замовчуванням). Бракує права → `403 admin.forbidden`.
- Операція без `x-permission` відхиляється, а тест перевіряє, що кожна адмін-операція його має.

## Захист від втрати доступу

- Не можна деактивувати чи понизити **останнього активного `admin`** → `409 admin.last_admin`.
- Адмін **не може деактивувати сам себе** чи зняти з себе роль `admin`.
