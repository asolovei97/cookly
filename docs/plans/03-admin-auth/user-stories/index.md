# Юзер-сторі — авторизація адмінки

Критерії приймання для [плану авторизації адмінки](../index.md). AC перевіряються на рівні API (або CLI для US-ADM-1). Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Доступ і сесії](access.md) — US-ADM-1…5: перший адмін, налаштування за посиланням, вхід, сесії, права.
- [Керування](management.md) — US-ADM-6…8: адміни, блокування користувачів застосунку, аудит.
