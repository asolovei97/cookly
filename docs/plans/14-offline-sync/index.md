# B14 · Офлайн-синхронізація

Механізм, на якому закупка й готування працюють без мережі: журнал доменних операцій, ідемпотентне застосування на сервері, стрічка змін для інших пристроїв і правила конфліктів. Технічний контекст — у [технічних рішеннях](../../tech-decisions.md#офлайн).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Реєстр типів операцій, `POST /v1/sync/ops`, `GET /v1/sync/changes`, журнал змін сім'ї.
- Захист від дублікатів, залежні операції, час, межі.
- Правила конфліктів, власник сесії готування.
- Операції, підключені в B14: `pantry.delta`, `catalog.product.create`, `catalog.ingredient.create`.
- Тестовий каркас, яким домени перевіряють свої операції.
- Специфікація клієнта для [M6](../../roadmap.md#мобільний-застосунок) / [M7](../../roadmap.md#мобільний-застосунок).

**Не входить**: операції закупки ([B15](../../roadmap.md#бекенд)) і готування ([B16](../../roadmap.md#бекенд)) — вони реєструються у своїх пунктах; ділення закупки між людьми — правило B15 на механіці B14.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Журнал доменних операцій | Синхронізація рядків (WatermelonDB pull/push) | Бізнес-правила лишаються на сервері; дельти запасів складаються; синхронізуються лише дві сесії, а не вся БД |
| expo-sqlite + Drizzle ORM | WatermelonDB | Не потрібен загальний механізм синхронізації рядків; типізовані запити й міграції локальної схеми |
| UUIDv7 на клієнті | Тимчасові id із заміною | Немає мапінгу id; залежні операції посилаються на id одразу |
| Послідовне застосування в межах сім'ї | Паралельне | Детермінований результат; навантаження сім'ї невелике |
| Поле-рівневий «перемагає останній» для позицій закупки | Запис-рівневий | Дві людини, що змінюють різні поля, не затирають одна одну |
| Сесія готування — одного пристрою | Спільне редагування | Готує одна людина; конфліктів у кроках не буває |
| Ручне виправлення запасів лише онлайн | Офлайн з конфліктами | Абсолютне значення без актуальних даних майже завжди хибне |
| Механізм у B14, операції — у доменах | Усе в B14 | Як модерація й черга перекладів: один механізм, домени підключаються |
