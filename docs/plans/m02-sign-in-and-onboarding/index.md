# M2 · Вхід і онбординг

Вхід через Apple і Google, реєстрація, сім'я й запрошення, короткий онбординг, сцени кухні на Skia для обладнання й запасів з легким режимом, профіль і керування сім'єю. Спирається на [B2](../02-app-auth/index.md), [B5](../05-household/index.md), [B6](../06-catalog/directories.md), [B13](../13-pantry/index.md), [B19](../19-account-deletion/index.md) і [B25](../25-scenes/index.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Вхід, реєстрація, вибір «створити сім'ю чи код», universal link запрошення.
- Токени: `401`, спільний refresh, вихід; екрани відновлення й блокування.
- Онбординг: своя персона, норма, чекліст «Завершіть налаштування», приєднання за кодом.
- Сцени: «Моя кухня» (обладнання) і запаси, картка вводу, легкий режим без Skia.
- Профіль, сесії, провайдери, видалення акаунта.
- Керування сім'єю: персони, коди, ролі, прийоми їжі, таймзона, місто; швидкий запис ваги.

**Не входить**: графік ваги ([M9](../../roadmap.md#мобільний-застосунок)), прапорці на клієнті ([M10](../../roadmap.md#мобільний-застосунок)) — до M10 клієнт використовує значення за замовчуванням, опис сцен і асети ([B25](../25-scenes/index.md)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Apple і Google на обох платформах | На Android лише Google | Користувач лише з Apple не застрягне при переході на Android |
| Обов'язкова лише своя персона | Повний онбординг поспіль | Мінімум до першої цінності; решта — чекліст |
| Skia-сцени для обладнання й запасів | Лише списки | Онбординг запасів і обладнання стає приємним, а не анкетою |
| Опис сцен із сервера | Сцени в коді застосунку | Новий предмет не вимагає релізу |
| Обладнання — одна сцена, запаси — ієрархія з переходом | Дровери | Обладнання вміщується на один екран; холодильник логічно «відчинити» |
| Картка біля предмета | Дровер, окремий екран | Людина лишається в сцені, ввід за кілька тапів |
| Легкий режим — список-еквівалент | Окрема спрощена сцена | Один запасний варіант для старих телефонів, читачів екрана й збою асетів |
| Автовизначення за RAM + вибір користувача | Лише прапорець | Прапорець не таргетує «залізо» |
