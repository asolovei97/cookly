# Налаштування

Профіль акаунта й керування сім'єю. Правила прав — у [B5](../05-household/household.md#права).

## Профіль

- Ім'я, мова, таймзона ([B17](../17-nutrition-log/days.md#таймзони)).
- **Спрощений вигляд** сцен ([сцени](kitchen-scenes.md#легкий-режим)), тема.
- **Провайдери**: прив'язати чи відв'язати Apple і Google; помилки `auth.identity_taken`, `auth.last_identity` ([B2](../02-app-auth/flows.md#привязка-провайдерів)).
- **Сесії**: список пристроїв, вийти на іншому, вийти скрізь.
- **Вихід**.

## Видалення акаунта

- Екран з поясненням: 30 днів на відновлення, що лишиться в сім'ї, що зникне ([B19](../19-account-deletion/anonymization.md)).
- `owner` з іншими учасниками → пояснення і кнопка **передати роль** (`409 household.owner_must_transfer`).
- Незворотна дія — **єдине місце** з підтвердженням ([UX](../../mobile-ux.md#принципи)).
- Окрема дія **«Видалити історію ваги»** ([B19](../19-account-deletion/request.md#видалення-історії-ваги)).

## Сім'я

| Що | Хто |
|---|---|
| Назва, місто, таймзона сім'ї | `owner` |
| Персони: додати, архівувати | `owner` |
| Змінити персону | Сама персона з акаунтом; персону без акаунта — будь-хто |
| Коди запрошення, «Поділитися» посиланням, відкликати | `owner` |
| Передача ролі `owner` | `owner` |
| Вийти із сім'ї | Учасник; `owner` — після передачі ролі |
| Прийоми їжі: додати, перейменувати, порядок, час дня, архів ([B12](../12-meal-plan/model.md#прийоми-їжі-сімї)) | Будь-який учасник |

Дії, яких бракує за правами, не показуються; `403 household.forbidden` — запасний варіант.

## Вага

- **Швидкий запис**: одне поле з поточною вагою, дата — сьогодні, з профілю персони ([B5](../05-household/persons-and-goals.md#історія-ваги)).
- Вага персони з акаунтом видна лише їй ([B5](../05-household/household.md#видимість)).
- Норма перераховується автоматично, новий результат показується одразу.
- Графік — [M9](../../roadmap.md#мобільний-застосунок).
