# Юзер-сторі — вхід

US-MAUTH-1…4. Загальні правила — в [індексі юзер-сторі](index.md).

## US-MAUTH-1 — Вхід і реєстрація
Як новий користувач, я хочу зареєструватися за хвилину.

**AC-1.1 (Новий користувач):**
- Given `fakeidp` повертає нову ідентичність,
- When користувач входить,
- Then один екран реєстрації з підставленим ім'ям і мовою пристрою.

**AC-1.2 (Помилка імені):**
- Given заборонене ім'я,
- When надсилається реєстрація,
- Then помилка під полем імені, введені дані збережено.

**AC-1.3 (Вік):**
- Given рік народження молодший за 16 років,
- When надсилається реєстрація,
- Then екран з поясненням `auth.age_restricted`.

**AC-1.4 (Наявний користувач):**
- Given акаунт із сім'єю,
- When він входить,
- Then головний екран, без онбордингу.

## US-MAUTH-2 — Запрошення посиланням
Як запрошена людина, я хочу приєднатися за посиланням.

**AC-2.1 (До входу):**
- Given відкрито `cookly.app/join/COOK-ABC123` без входу,
- When людина реєструється,
- Then код підставлено, і вона бачить приєднання.

**AC-2.2 (Невалідний код):**
- Given прострочений код,
- When людина приєднується,
- Then пояснення `household.invite_invalid` і поле для іншого коду.

**AC-2.3 (Поділитися):**
- Given власник створює код для персони,
- When натискає «Поділитися»,
- Then системне меню з посиланням `cookly.app/join/…`.

## US-MAUTH-3 — Токени
Як користувач, я не хочу, щоб мене викидало без причини.

**AC-3.1 (Спільний refresh):**
- Given access-токен прострочено і три запити отримали `401`,
- When застосунок оновлює токен,
- Then виконано один refresh, а всі три запити повторено успішно.

**AC-3.2 (Refresh не вдався):**
- Given refresh повертає `401`,
- When застосунок намагається оновити токен,
- Then екран входу.

**AC-3.3 (Черга лишається):**
- Given офлайн-черга з операціями і refresh не вдався,
- When той самий користувач входить знову,
- Then черга відправляється.

## US-MAUTH-4 — Особливі стани
Як користувач, я хочу зрозуміти, що з моїм акаунтом.

**AC-4.1 (Відновлення):**
- Given акаунт `pending_deletion`,
- When він входить і натискає «Відновити»,
- Then акаунт активний, людина на головному екрані.

**AC-4.2 (Блокування):**
- Given заблокований акаунт,
- When він входить,
- Then екран з датою `until` і кнопкою «Видалити акаунт».

**AC-4.3 (Видалення за квитком):**
- Given екран блокування,
- When натиснуто «Видалити акаунт» і підтверджено,
- Then акаунт `pending_deletion`, екран пояснює 30 днів.
