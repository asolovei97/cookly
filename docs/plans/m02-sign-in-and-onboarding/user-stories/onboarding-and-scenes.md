# Юзер-сторі — онбординг і сцени

US-MAUTH-5…9. Загальні правила — в [індексі юзер-сторі](index.md).

## US-MAUTH-5 — Онбординг
Як новий користувач, я хочу швидко побачити свою норму.

**AC-5.1 (До 5 екранів):**
- Given «Створити сім'ю»,
- When користувач заповнює обов'язкове,
- Then екран норми після не більше ніж 5 екранів, сім'я й персона створені.

**AC-5.2 (Продовження):**
- Given онбординг перервано на кроці 3,
- When застосунок відкривають знову,
- Then продовжується з кроку 3.

**AC-5.3 (До 18 років):**
- Given рік народження дає 15 років для персони, яку додає власник,
- When заповнюється ціль,
- Then доступна лише «підтримка», темпу немає.

**AC-5.4 (Чекліст):**
- Given обов'язкове заповнено, решту пропущено,
- When відкривається головний екран,
- Then чекліст «Завершіть налаштування» з трьома кроками, кожен можна закрити.

**AC-5.5 (Приєднання):**
- Given персона, створена власником, і код,
- When людина приєднується,
- Then бачить дані власника для підтвердження і окреме поле ваги.

## US-MAUTH-6 — Сцена обладнання
Як користувач, я хочу показати, що є на моїй кухні.

**AC-6.1 (З довідника):**
- Given у довіднику `equipment` є новий рядок з координатами,
- When відкривається сцена,
- Then предмет на сцені, приглушений, без релізу застосунку.

**AC-6.2 (Без координат):**
- Given рядок без `sceneX`,
- When відкривається сцена,
- Then предмет у ряду «Інше».

**AC-6.3 (Кілька одиниць):**
- Given каструля на сцені,
- When додано «улюблена» 5 л і «запасна» 3 л,
- Then картка показує обидві, предмет яскравий.

**AC-6.4 (Новий атрибут):**
- Given сервер додав у `fields[]` каструлі нове поле,
- When відкривається картка,
- Then поле в формі, значення зберігається.

## US-MAUTH-7 — Сцена запасів
Як користувач, я хочу наповнити холодильник за кілька тапів.

**AC-7.1 (Перехід):**
- Given кухня,
- When тап на холодильник,
- Then анімація наближення і підсцена з полицями; «назад» повертає на кухню.

**AC-7.2 (Перший тап):**
- Given приглушене молоко на полиці,
- When тап,
- Then позиція `unknown` з місцем «холодильник», продукт яскравий, картка відкрита.

**AC-7.3 (Кількість):**
- Given відкрита картка,
- When вибрано `1` і `л`, тап поза карткою,
- Then позиція `quantity` 1000 мл.

**AC-7.4 (Уточнення):**
- Given позиція-інгредієнт «Молоко»,
- When «Уточнити продукт» і вибрано товар,
- Then позиція посилається на товар.

**AC-7.5 (Плюс):**
- Given продукту немає на полиці,
- When «+» і вибір з каталогу,
- Then продукт на полиці зі спрайтом.

**AC-7.7 (Списати):**
- Given у картці молока 900 мл,
- When «Списати» 450 мл із причиною «зіпсувалося»,
- Then у запасах 450 мл, запис у журналі списань; працює офлайн.

**AC-7.8 (Прибрати):**
- Given позицію додано помилково,
- When «Прибрати»,
- Then позиції немає, журнал списань без змін, тост «Скасувати».

**AC-7.9 (Історія):**
- Given закупка, готування й списання молока,
- When відкривається «Історія» в картці,
- Then усі три записи з автором, кількістю й причиною.

**AC-7.6 (Офлайн):**
- Given сцена завантажувалась раніше,
- When відкривається без мережі,
- Then сцена з кешу, зміни йдуть у чергу ([B14](../../14-offline-sync/client.md#черга-операцій)).

## US-MAUTH-8 — Легкий режим
Як власник старого телефона, я хочу, щоб застосунок не гальмував.

**AC-8.1 (Вибір користувача):**
- Given увімкнено «Спрощений вигляд»,
- When відкриваються запаси,
- Then список за місцями, Skia не використовується.

**AC-8.2 (Прапорець):**
- Given `scene.skia` off,
- When відкриваються сцени,
- Then легкий режим.

**AC-8.3 (Читач екрана):**
- Given увімкнено VoiceOver,
- When відкриваються сцени,
- Then легкий режим, усі елементи читаються.

**AC-8.4 (Мало пам'яті):**
- Given RAM менше 3 ГБ під час першого запуску,
- When відкривається застосунок,
- Then легкий режим і підказка; перемикання на сцену зберігається.

**AC-8.5 (Ті самі картки):**
- Given легкий режим,
- When відкривається продукт,
- Then та сама картка з одиницями, «Завжди є», «Уточнити», «Прибрати».

## US-MAUTH-9 — Налаштування
Як користувач, я хочу керувати акаунтом і сім'єю.

**AC-9.1 (Передача ролі):**
- Given `owner` з учасником видаляє акаунт,
- When отримано `409 household.owner_must_transfer`,
- Then пояснення і перехід до передачі ролі.

**AC-9.2 (Швидка вага):**
- Given профіль персони без ручної норми,
- When записано нову вагу,
- Then норма оновилась на екрані.

**AC-9.3 (За правами):**
- Given учасник `member`,
- When відкриває сім'ю,
- Then немає дій додавання персон і кодів, але є прийоми їжі.
