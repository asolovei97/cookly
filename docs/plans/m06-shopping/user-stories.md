# Юзер-сторі — закупка

Критерії приймання для [плану M6](index.md). AC перевіряються Maestro на варіанті `testing` або RNTL, офлайн — з вимкненою мережею емулятора. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MSHOP-1 — Чернетка
Як покупець, я хочу готовий список перед магазином.

**AC-1.1 (З маркера):**
- Given маркер закупки на діапазон сб–пт,
- When тап на маркер,
- Then чернетка на цей діапазон, групи за джерелом із підсумками.

**AC-1.2 (Уже відкрита):**
- Given відкрита закупка,
- When «За списком»,
- Then відкривається вона.

**AC-1.3 (Правки лишаються):**
- Given вручну змінена кількість,
- When «Оновити з плану»,
- Then правка на місці.

**AC-1.4 (Вже є вдома):**
- Given позиція в чернетці,
- When свайп «Вже є вдома»,
- Then позицію прибрано, тост «Скасувати».

## US-MSHOP-2 — Порівняння
Як покупець, я хочу знати, де дешевше.

**AC-2.1 (Перемикання):**
- Given картка «АТБ 1240 · Сільпо 1310»,
- When тап на АТБ,
- Then основна мережа АТБ, товари підібрано за стратегією, суми оновлено.

## US-MSHOP-3 — Позначка
Як покупець, я хочу позначати куплене одним тапом.

**AC-3.1 (Один тап):**
- Given позиція в активній закупці,
- When один тап,
- Then позиція куплена без ціни, поле ціни розгорнуто, запаси поповнено.

**AC-3.2 (Ціна така):**
- Given підказка 45 грн,
- When «Ціна така»,
- Then спостереження ціни 45 грн.

**AC-3.3 (Без дії):**
- Given підказку проігноровано,
- When відкривається підсумок,
- Then спостереження немає, сума `partial`, позиція серед «без ціни».

**AC-3.4 (На вагу):**
- Given товар `weight`,
- When розгортається поле,
- Then режим «сума й вага».

**AC-3.5 (Скасування):**
- Given куплена позиція,
- When «Скасувати» в тості,
- Then позначку знято, запаси повернуто.

## US-MSHOP-4 — Заміна й поза списком
Як покупець, я хочу швидко замінити товар, якого немає на полиці.

**AC-4.1 (Кандидати офлайн):**
- Given немає мережі, кеш завантажено,
- When заміна,
- Then до 5 кандидатів з цінами.

**AC-4.2 (Новий товар офлайн):**
- Given немає мережі,
- When «Створити товар» і позначка,
- Then операції в черзі в правильному порядку.

**AC-4.3 (Поза списком):**
- Given хедер закупки,
- When «+» і вибір продукту,
- Then нова позиція.

## US-MSHOP-5 — Ділення
Як член сім'ї, я хочу купувати окремо від інших.

**AC-5.1 (Фільтр):**
- Given 3 позиції призначено мені,
- When «Мої»,
- Then лише вони.

**AC-5.2 (Зміни інших):**
- Given інший учасник позначив позицію,
- When минає 30 секунд,
- Then позиція куплена на моєму екрані.

**AC-5.3 (Двічі):**
- Given учасник уже купив молоко,
- When я позначаю його офлайн і синхронізую,
- Then банер «Марія вже купила. Додати ще одну?».

## US-MSHOP-6 — Офлайн
Як покупець, я хочу, щоб магазин без мережі нічого не зламав.

**AC-6.1 (Повний сценарій):**
- Given кеш завантажено, мережу вимкнено,
- When куплено 5 позицій і завершено,
- Then усе працює; після появи мережі операції застосовано.

**AC-6.2 (Відхилено):**
- Given операцію відхилено,
- When приходить відповідь,
- Then банер «Не вдалося синхронізувати 1 зміну» з «Повторити» і «Відкинути».

**AC-6.3 (Екран):**
- Given екран закупки відкрито,
- When минає час автоблокування,
- Then екран не гасне.

## US-MSHOP-7 — Завершення й докупити
Як покупець, я хочу закрити закупку й не забути ціни.

**AC-7.1 (Підсумок):**
- Given 2 позиції без ціни, 1 не куплена,
- When «Завершити»,
- Then підсумок із цими даними і полями цін; без другого підтвердження закупка завершується кнопкою на цьому екрані.

**AC-7.2 (Наслідки):**
- Given завершено,
- When читаються бюджет і графік,
- Then сума у факті, маркер «виконано», чипа немає.

**AC-7.3 (Докупити):**
- Given немає відкритої закупки,
- When «Додати в закупку» на картці,
- Then чернетка без діапазону з цією позицією.
