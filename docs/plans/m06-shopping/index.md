# M6 · Закупка офлайн

Чернетка закупки з плану, порівняння мереж і сама закупка в магазині: один тап на позицію, ціни, заміни, ділення між людьми, завершення. Усе працює без мережі. Спирається на [B15](../15-shopping/index.md), [B14](../14-offline-sync/index.md), [B8](../08-prices/index.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Офлайн-сховище й черга операцій за [специфікацією B14](../14-offline-sync/client.md): SQLite + Drizzle, відхилені операції, стрічка змін.
- Чернетка: діапазон, групи, порівняння мереж, правки, старт.
- Екран закупки: позначка, ціна, заміна, поза списком, фільтр «Мої».
- Завершення, докупити.

**Не входить**: скан чека ([M11](../../roadmap.md#мобільний-застосунок)) — тут лише кнопка, маркери закупок на графіку ([M5](../m05-meal-plan/week-grid.md#запланована-закупка)).

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Тап — куплено без ціни, поле ціни розгортається | Приймати показану ціну; завжди клавіатура | 1 тап за UX, а спостереження ціни — лише від людини |
| «Ціна така» підтверджує підказку | Мовчазне прийняття | Не засмічує медіани вигаданими цінами |
| Групи за джерелом, усередині — за категорією | Плаский список | Відповідає руху магазином |
| Завершення через екран підсумку | Діалог підтвердження | Незворотна дія; там же можна дописати ціни |
| Стрічка змін кожні 30 секунд, поки екран відкрито | Постійний сокет | Достатньо для ділення між людьми, просто офлайн |
| Чернетка без діапазону для «докупити» | Вимагати діапазон | Купити одну річ не потребує плану |
