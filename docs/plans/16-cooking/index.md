# B16 · Готування

Сесія покрокового готування з реальними товарами й грамовками і її результат — унікальна страва зі знімком КБЖВ, списанням із запасів і залишком. Продуктовий опис — у [готуванні](../../cooking.md).

Критерії приймання — у [юзер-сторі](user-stories/index.md).

## Обсяг

- Сесія: статуси, старт з плану чи рецепта, товари для рядків, напівфабрикати, зміни.
- Зважування, знімок КБЖВ, завершення, списання із запасів.
- Виправлення протягом 48 годин.
- Готові страви із залишком у запасах.
- Підказка коефіцієнта виходу.
- Фото приготування.
- Операції синхронізації в реєстрі [B14](../14-offline-sync/protocol.md#реєстр-типів).

**Не входить**: запис з'їденого і швидке готування без сесії ([B17](../../roadmap.md#бекенд)), клієнтські екрани й локальні таймери ([M7](../../roadmap.md#мобільний-застосунок)).

## Документи

- [Страва](dish.md) — вага, знімок, завершення, списання, виправлення, готові страви, підказка виходу, фото.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Без зважування вага = сума × коефіцієнт виходу | ~~Сума інгредієнтів~~ | Вода википає; рис з водою важить інакше, ніж суп |
| Списання запасів одним пакетом під час завершення | З кожною зміною рядка | Грамовки змінюються багато разів; запаси не «стрибають» |
| Страва має залишок, напівфабрикат списує його | Напівфабрикат завжди за типовими КБЖВ | Майонез з понеділка — реальна страва з реальними КБЖВ |
| Виправлення протягом 48 годин | Заборонити; дозволити завжди | Помилки помічають одразу, а статистика минулих тижнів не пливе |
| `toTaste` з кількістю враховується | Ніколи не враховувати | Якщо людина вказала 5 г солі, це факт |
| Підказка виходу лише для приватних рецептів | Для всіх | Адмінські й публічні рецепти — еталон, їх змінюють модератори |
