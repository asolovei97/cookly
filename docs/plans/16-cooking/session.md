# Сесія

Як починається, проходить і закінчується готування.

## Статуси

- `in_progress` → `completed` | `abandoned`.
- `abandoned` нічого не списує і страви не створює.
- Старт можливий **офлайн**, якщо рецепт є в кеші ([B14](../14-offline-sync/client.md#кеш-для-офлайну)).
- **Кілька сесій** одночасно дозволено (борщ і салат).
- Сесія належить **пристрою**, що її почав; інші бачать її лише для читання; передача — онлайн ([B14](../14-offline-sync/conflicts.md#власник-сесії-готування)).

## Старт

- **З запланованого готування** ([B12](../12-meal-plan/model.md#заплановане-готування)): порції, вибрані `optional`-рядки і зв'язок з планом підтягуються.
- **З будь-якого рецепта**: без зв'язку з планом. Після завершення страву можна прив'язати до запланованого готування («це те, що планували на завтра»).
- Склад масштабується під порції ([B9](../09-recipes/structure.md#масштабування)).

## Товар для рядка

Для кожного рядка-інгредієнта на старті підставляється:

1. товар цього інгредієнта в [запасах](../13-pantry/model.md) з найбільшим залишком;
2. інакше — товар з останньої [закупки](../15-shopping/index.md);
3. інакше — сам інгредієнт з типовими КБЖВ.

## Напівфабрикат

- Рядок-напівфабрикат пропонує обрати **наявну страву** цього рецепта із залишком ([страва](dish.md#готові-страви)): списується її залишок, КБЖВ беруться з її знімка на 100 г.
- Якщо страви немає — типові [`recipe_nutrition`](../09-recipes/composition.md#recipe_nutrition), а клієнт підказує «спершу приготуйте майонез».

## Зміни під час готування

На будь-якому кроці:

- **замінити** товар чи інгредієнт;
- **змінити кількість** (в будь-якій застосовній [одиниці](../06-catalog/units.md#застосовність));
- **додати** чи **прибрати** рядок;
- **увімкнути чи вимкнути** `optional`-рядок;
- задати **фактичну кількість** `toTaste`-рядку («сіль, 5 г»): тоді він враховується в КБЖВ і списанні; без кількості — ні;
- позначити **крок виконаним**.

## Операції синхронізації

| Тип | Що робить |
|---|---|
| `cooking.start@1` | Почати сесію з рецепта чи запланованого готування |
| `cooking.line.set@1` | Товар чи інгредієнт, кількість, додати чи прибрати рядок, `optional`, страва-напівфабрикат |
| `cooking.step.done@1` | Крок виконано |
| `cooking.weigh@1` | Зважування: посудини, брутто, тара |
| `cooking.complete@1` | Завершити, див. [страву](dish.md#завершення) |
| `cooking.abandon@1` | Покинути |
| `cooking.photo.attach@1` | Прив'язати фото |
| `cooking.edit@1` | Виправлення після завершення, див. [страву](dish.md#виправлення) |

Операції з завершеною чи покинутою сесією (крім `edit` і `photo.attach`) → `rejected` з `cooking.closed`.

## Ендпоінти (онлайн)

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/cooking?status=in_progress` | Активні сесії сім'ї |
| `GET /v1/cooking/{id}` | Сесія з поточним складом і кроками |
| `POST /v1/cooking/{id}/transfer` | Продовжити на цьому пристрої |
| `POST /v1/dishes/{id}/link-plan` | Прив'язати страву до запланованого готування |
| `GET /v1/dishes?status=available` | Готові страви із залишком |
| `POST /v1/dishes/{id}/discard` | «Доїли» чи «викинули» |
