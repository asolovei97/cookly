# Юзер-сторі — готування

Критерії приймання для [плану готування](../index.md). AC перевіряються на рівні API, зокрема через `POST /v1/sync/ops`. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

- [Сесія](session.md) — US-COOK-1…5: старт, товари, напівфабрикати, зміни, власник.
- [Страва](dish.md) — US-COOK-6…10: вага, знімок і списання, виправлення, готові страви, підказка виходу й фото.
