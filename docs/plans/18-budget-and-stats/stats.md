# Статистика

Як персона рухається до цілі: спожите проти норми і підтримки, вага, головний екран.

## Дефіцит

Для кожного дня з записами ([B17](../17-nutrition-log/days.md#підсумки-днів)):

| Число | Формула | Що показує |
|---|---|---|
| **Фактичний дефіцит** (головне) | TDEE − спожите | Дефіцит від підтримки, який і дає схуднення |
| **Відхилення від норми** | спожите − норма | Наскільки персона тримається плану; норма вже містить дефіцит під ціль |

- **TDEE** = BMR × коефіцієнт активності ([B5](../05-household/persons-and-goals.md#розрахунок-норми-від-18-років)). Рахується за формулою **навіть для ручної норми**.
- Персони до 18 років — TDEE з тієї самої таблиці EFSA, що й норма.
- Значення TDEE і норми — ті, що діяли **в той день** (вага й параметри на дату).

## Тиждень і періоди

- **Середнє** — лише за днями, де є хоча б один запис; поруч `daysWithData` («дані за 5 з 7 днів»).
- Дні без записів не рахуються як 0 ккал. Позначки «день заповнено» в MVP немає.
- Періоди графіків: `week`, `month`, `3months`; точки — по днях, для `3months` — по тижнях.

## Вага

- Точки з [історії ваги](../05-household/persons-and-goals.md#історія-ваги).
- **Ковзне середнє за 7 днів**.
- **Очікувана траєкторія**: від першої ваги періоду з темпом цілі (кг на тиждень); для «підтримки» — горизонтальна.
- Видимість — за [B5](../05-household/household.md#видимість): вагу персони з акаунтом бачить лише вона сама; іншим учасникам блок ваги повертається як `null`.

## Видимість

- Статистику харчування **кожної персони** бачить будь-який учасник сім'ї, крім ваги персон з акаунтом.
- Персона іншої сім'ї → `404`.

## Головний екран

`GET /v1/dashboard?personId=` — усе для екрана одним запитом:

| Блок | Вміст |
|---|---|
| `today` | Спожиті ккал і БЖВ проти норми, за прийомами їжі |
| `week` | Середній фактичний дефіцит, середнє відхилення від норми, `daysWithData` |
| `weight` | Остання вага, зміна за 7 днів, тренд (або `null`, якщо не видно) |
| `budget` | Бюджет, факт, прогноз, `unpricedCount` ([бюджет](budget.md)) |
| `waste` | Списано за поточний період бюджету, за причинами ([списання](waste.md)) |

«Сьогодні» — у таймзоні акаунта, для персони без акаунта — у таймзоні сім'ї.

## Ендпоінти

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/dashboard?personId=` | Головний екран |
| `GET /v1/stats/nutrition?personId=&period=` | Ряди спожитого, норми, TDEE, дефіциту для графіків |
| `GET /v1/stats/weight?personId=&period=` | Точки ваги, ковзне середнє, траєкторія |

## Розрахунок

- Усе рахується **на льоту** з записів з'їденого, історії ваги й параметрів персони, з індексами за персоною й датою.
- Таблиця денних агрегатів — коли головний екран почне гальмувати.
