# Статистика й бюджет

Екрани, куди ведуть кнопка «Статистика» й кільце бюджету.

## Статистика

- Перемикач **тиждень / місяць / 3 місяці** ([B18](../18-budget-and-stats/stats.md#тиждень-і-періоди)).
- **Фактичний дефіцит** проти TDEE — головне число ([B18](../18-budget-and-stats/stats.md#дефіцит)).
- **Відхилення від норми** — друге число.
- **«Дані за N з 7 днів»**: дні без записів не рахуються.
- Пусто → пояснення і «Записати їжу».

## Графіки

На **SVG** (`react-native-svg`), однаково на всіх телефонах.

| Графік | Дані |
|---|---|
| **Спожите проти норми** | `GET /v1/stats/nutrition` |
| **Вага** | `GET /v1/stats/weight`: точки, ковзне середнє за 7 днів, траєкторія цілі |

- Чужа вага персони з акаунтом — блок **прихований** ([B18](../18-budget-and-stats/stats.md#вага)).
- Для читачів екрана — текстовий підсумок під графіком.

## Бюджет

`GET /v1/budget?period=` ([B18](../18-budget-and-stats/budget.md#ендпоінти)):

- **бюджет, факт, прогноз**, **повна вартість плану** окремо;
- **«Без ціни»**: лічильник і список, де можна дописати ціну;
- **історія** періодів;
- `owner` задає **суму й період** (`PUT /v1/budget`); для інших дії немає;
- Офлайн — кеш лише для читання.

## Списання

Блок на екрані бюджету ([B18](../18-budget-and-stats/waste.md#статистика)):

- **«Списано за період: N грн»** за причинами;
- **топ продуктів**, що найчастіше псуються;
- журнал; **скасування запису** — одразу, зі «Скасувати» (`DELETE /v1/waste/{id}`);
- рахується на сім'ю, не на персону.

Самі дії списання — у [картці запасів](../m02-sign-in-and-onboarding/kitchen-scenes.md#картка) і [готових стравах](../m07-cooking/dish.md#готові-страви).
