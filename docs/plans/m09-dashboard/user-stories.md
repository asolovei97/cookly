# Юзер-сторі — дешборд

Критерії приймання для [плану M9](index.md). AC перевіряються Maestro на варіанті `testing` або RNTL. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MDASH-1 — Кільця КБЖВ
Як користувач, я хочу одним поглядом бачити свій день.

**AC-1.1 (Легенда):**
- Given норма 2000 ккал, спожито 1450,
- When відкривається дешборд,
- Then концентричні кільця ккал, Б, Ж, В і легенда «Ккал 1450 / 2000».

**AC-1.2 (Перевищення):**
- Given спожито 2300 при нормі 2000,
- When показуються кільця,
- Then другий оберт бурштиновим, «+300», червоного немає.

**AC-1.3 (Перехід):**
- Given кільця,
- When тап,
- Then щоденник дня.

**AC-1.4 (Доступність):**
- Given увімкнено читач екрана,
- When фокус на кільцях,
- Then зачитуються значення з легенди.

**AC-1.5 (Одразу):**
- Given записано їжу,
- When повернення на дешборд,
- Then кільця оновлені анімацією без очікування сервера.

## US-MDASH-2 — Кільце бюджету
Як член сім'ї, я хочу бачити, чи вкладаємося.

**AC-2.1 (Значення):**
- Given бюджет 3000, факт 1800, прогноз 2900, 2 без ціни,
- When показується блок,
- Then кільце 60%, легенда з цими значеннями.

**AC-2.2 (Немає бюджету):**
- Given бюджет не задано,
- When дешборд відкриває `owner`,
- Then «Задати бюджет»; учасник `member` блока не бачить.

## US-MDASH-3 — Останні позиції
Як користувач, я хочу швидко повторити звичну їжу.

**AC-3.1 (Ще раз):**
- Given останній запис «Йогурт 1 шт»,
- When «Ще раз»,
- Then новий запис за 1 тап, тост «Скасувати», кільця оновлені.

**AC-3.2 (Тап):**
- Given рядок,
- When тап,
- Then картка кількості цього запису.

## US-MDASH-4 — Статистика
Як персона на дефіциті, я хочу бачити реальний прогрес.

**AC-4.1 (Дефіцит):**
- Given записи в 5 днях із 7,
- When відкривається статистика за тиждень,
- Then середній фактичний дефіцит, відхилення від норми, «дані за 5 з 7».

**AC-4.2 (Вага):**
- Given записи ваги й темп цілі,
- When обрано місяць,
- Then точки, ковзне середнє, траєкторія.

**AC-4.3 (Чужа вага):**
- Given обрано іншу персону з акаунтом,
- When відкривається статистика,
- Then графіка ваги немає.

**AC-4.4 (Пусто):**
- Given немає записів,
- When відкривається статистика,
- Then пояснення і «Записати їжу».

## US-MDASH-5 — Бюджет і списання
Як власник сім'ї, я хочу керувати бюджетом і бачити, скільки викидаємо.

**AC-5.1 (Задати):**
- Given `owner`,
- When задано 3000 на тиждень,
- Then кільце оновлено; `member` дії не бачить.

**AC-5.2 (Без ціни):**
- Given позиція без ціни,
- When дописано ціну,
- Then лічильник зменшився, факт зріс.

**AC-5.3 (Списання):**
- Given 3 `spoiled` і 1 `given_away`,
- When показується блок,
- Then суми за причинами, топ продуктів.

**AC-5.4 (Скасування):**
- Given запис списання,
- When скасовано,
- Then запаси повернуто.

## US-MDASH-6 — Персона й офлайн
Як член сім'ї, я хочу дивитися статистику інших і працювати без мережі.

**AC-6.1 (Чужа персона):**
- Given обрано тата,
- When показується дешборд,
- Then його КБЖВ, спільний бюджет, блоку ваги немає.

**AC-6.2 (Скидання):**
- Given обрано тата, застосунок закрито,
- When відкривається знову,
- Then обрано «я».

**AC-6.3 (Офлайн):**
- Given немає мережі,
- When записано їжу,
- Then кільця оновлені локально, позначка «офлайн».

**AC-6.4 (Вага):**
- Given остання вага 8 днів тому,
- When показується дешборд,
- Then «Записати вагу» помітніша, діалогу немає.
