# Страва

Кінець готування і життя готової страви в запасах. Правила — у [B16](../16-cooking/dish.md).

## Зважування

Екран наприкінці, **необов'язковий**:

- вибір **посудини** з обладнання сім'ї, **тара підставляється** ([B6](../06-catalog/directories.md#обладнання));
- поле **брутто**;
- **«+ ще посудина»**;
- велика кнопка **«Пропустити»** → вага за коефіцієнтом виходу ([B16](../16-cooking/dish.md#вага)).

Тари немає → поле вводу; значення пропонується **зберегти в обладнанні**.

## Результат

Після `cooking.complete@1`, без діалогу підтвердження, бо є [48 годин на виправлення](#виправлення):

- вага; **КБЖВ** загалом, на 100 г, на порцію;
- **вартість** страви, `partial` з позначкою ([B16](../16-cooking/dish.md#знімок-кбжв));
- **підказки** про розбіжність запасів ([B16](../16-cooking/dish.md#завершення));
- **фото** — необов'язкове, у черзі, якщо офлайн ([B16](../16-cooking/dish.md#фото));
- **«Підтвердити обід»**, якщо прийом їжі прив'язаний ([M8](../../roadmap.md#мобільний-застосунок)).

Запаси списуються одним пакетом під час завершення; заплановане готування отримує фактичну дату.

## Готові страви

Розділ у вкладці **«Запаси»** і блок на дешборді ([M9](../../roadmap.md#мобільний-застосунок)):

- страви із **залишком**, **строком**, позначкою **«строк минув»** ([B16](../16-cooking/dish.md#готові-страви));
- сортування: спершу те, що скоро зіпсується.

Дії:

| Дія | Що робить |
|---|---|
| **«Доїли»** | Залишок 0 |
| **«Викинути»** | Грами (за замовчуванням увесь залишок) і причина `spoiled` / `given_away` / `other` ([B18](../18-budget-and-stats/waste.md)) |
| **«Записати як з'їдене»** | [M8](../../roadmap.md#мобільний-застосунок) |

## Виправлення

- Протягом **48 годин** на картці страви — **«Виправити»**: той самий редактор складу, вага ([B16](../16-cooking/dish.md#виправлення)).
- `cooking.edit@1`, працює офлайн.
- Вікно закрито → дії немає; `rejected` з `cooking.edit_window_closed` при запізнілій синхронізації — банер.

## Страва без рецепта

**«Додати страву»** в розділі «Готові страви» ([B16](../16-cooking/dish.md#страва-без-рецепта)):

- назва, вага;
- КБЖВ: **з аналога** через [пікер](../m03-catalog-and-search/picker-and-search.md#catalogpicker) або вручну;
- джерело: подарунок / домашнє за замовчуванням;
- строк — необов'язковий.
