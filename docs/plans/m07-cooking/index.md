# M7 · Готування офлайн

Покрокове готування на кухні без мережі: старт, кроки, таймери, зміни складу, зважування, результат, а також готові страви в запасах. Спирається на [B16](../16-cooking/index.md), [B14](../14-offline-sync/index.md), [B18](../18-budget-and-stats/waste.md).

Критерії приймання — у [юзер-сторі](user-stories.md).

## Обсяг

- Старт з панелі «+», рецепта чи графіка; екран «Перед початком».
- Покроковий режим, локальні таймери, зміни рядків.
- Зважування, результат, фото.
- Кілька сесій, власник, переривання.
- Готові страви: залишок, викидання, виправлення 48 годин, страва без рецепта.

**Не входить**: підтвердження прийому їжі ([M8](../../roadmap.md#мобільний-застосунок)) — тут лише кнопка, голосові команди ([майбутнє](../../future.md)).

## Документи

- [Сесія](session.md) — старт, «Перед початком», кроки, таймери, зміни, кілька сесій.
- [Страва](dish.md) — зважування, результат, готові страви, викидання, виправлення, страва без рецепта.
- [Юзер-сторі](user-stories.md) — US-MCOOK-1…7.

## Ключові рішення

| Рішення | Відкинуто | Чому |
|---|---|---|
| Екран «Перед початком» | Одразу перший крок | Видно, чого бракує і які товари підставлено |
| Один крок на екран, «Далі» 1 тап | Список кроків | Читається здалеку, брудними руками |
| Таймери локальні, кілька одночасно | Один таймер; серверні | Борщ і салат паралельно; працює без мережі |
| «Пропустити» зважування велика | Дрібне посилання | Зважування необов'язкове і не блокує |
| Завершення без діалогу | Підтвердження | Є 48 годин на виправлення |
| «Покинути» зі «Скасувати» | Діалог | Нічого не списує |
