# Формат

Як описується сцена, щоб клієнт міг намалювати її без знання конкретних предметів.

## Опис

```json
{
  "key": "kitchen_pantry",
  "version": 7,
  "formatVersion": 1,
  "canvas": { "width": 360, "height": 640 },
  "background": "<asset>",
  "objects": [
    {
      "id": "fridge",
      "sprite": "<asset>",
      "x": 0.08, "y": 0.22, "w": 0.34, "h": 0.5,
      "layer": 2,
      "binding": { "type": "storage_location", "location": "fridge" },
      "opens": "pantry_fridge",
      "transition": "zoom_open"
    }
  ],
  "shelves": []
}
```

## Полотно

- `canvas` задає **базові пропорції**.
- Координати об'єктів **нормалізовані** (0–1) відносно полотна.
- На екрані з іншими пропорціями сцена **вписується по ширині**, без спотворень; зайве місце заповнює фон.

## formatVersion

- Ціле число, зростає, коли з'являється те, чого старий рушій не вміє (новий тип переходу, нове поле з обов'язковою поведінкою).
- Клієнт знає максимальну версію, яку підтримує; опис новішої версії він **не малює**, а вмикає [легкий режим](../m02-sign-in-and-onboarding/kitchen-scenes.md#легкий-режим).

## Об'єкти

| Поле | Примітка |
|---|---|
| `id` | Унікальний у сцені |
| `sprite` | Асет або набір за станами |
| `x`, `y`, `w`, `h` | Нормалізовані |
| `layer` | Порядок шарів |
| `binding` | `storage_location` або відсутнє (декорація) |
| `opens` | Ключ підсцени |
| `transition` | Тип переходу: у формату 1 — `zoom_open` |
| `states` | Необов'язкові спрайти станів: `present`, `absent` |
| `label` | Ключ `ui_strings` для читачів екрана |

## Слоти полиць

Підсцена (`pantry_fridge`) описує `shelves[]`:

- полиця — прямокутник і `slots[]` у нормалізованих координатах;
- клієнт **сам розставляє продукти**: спершу наявні в сім'ї, потім [запропоновані](locations.md#запропоновані-продукти);
- слотів забракло → полиця гортається або з'являється «ще»;
- точні позиції продуктів ніхто вручну не задає.

## Сцени MVP

| Ключ | Що |
|---|---|
| `kitchen_pantry` | Кухня: холодильник, морозилка, шафка, полиця зі спеціями, кошик |
| `pantry_fridge`, `pantry_freezer`, `pantry_cupboard`, `pantry_spices`, `pantry_basket` | Підсцени з полицями |
| `kitchen_equipment` | Сцена обладнання |

## Сцена обладнання

- У репозиторії лежить лише фон і прямокутник ряду **«Інше»**.
- `GET /v1/scenes/kitchen_equipment` збирає `objects[]` з таблиці [`equipment`](../06-catalog/directories.md#обладнання): спрайт, `sceneX`, `sceneY`, шар.
- Рядок без координат — у ряду «Інше».
- Зміна довідника **збільшує версію** цієї сцени.
- Наявне в сім'ї — яскраве, відсутнє — приглушене; це вирішує клієнт за обладнанням сім'ї.
