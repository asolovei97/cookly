# Юзер-сторі — сцени

Критерії приймання для [плану сцен](index.md). AC перевіряються на рівні API, команд деплою і адмін-ендпоінтів. Кожен AC покривається тестом з назвою `TestAC_<US>_<N>_...`.

## US-SCENE-1 — Синхронізація
Як розробник, я хочу змінити сцену без релізу застосунку.

**AC-1.1 (Нова версія):**
- Given у `scenes/` змінено опис `pantry_fridge`,
- When виконується `api scenes sync`,
- Then `version` сцени зросла, а незмінені сцени не змінилися.

**AC-1.2 (Асети з хешем):**
- Given новий PNG,
- When виконується синхронізація,
- Then асет у Garage під іменем з хешем вмісту, опис посилається на нього.

**AC-1.3 (Невалідний опис):**
- Given об'єкт з `x = 1.4` або посилання на неіснуючу підсцену,
- When виконується синхронізація,
- Then команда падає, сцени в БД не змінилися.

**AC-1.4 (Бюджет):**
- Given асети сумарно понад 5 МБ,
- When запускається CI,
- Then перевірка падає.

## US-SCENE-2 — Маніфест і опис
Як клієнт, я хочу завантажувати лише те, що змінилося.

**AC-2.1 (ETag):**
- Given клієнт має `ETag` маніфесту, і сцени не змінились,
- When `GET /v1/scenes` з `If-None-Match`,
- Then `304`.

**AC-2.2 (Опис):**
- Given сцена `kitchen_pantry`,
- When `GET /v1/scenes/kitchen_pantry`,
- Then опис з `formatVersion`, об'єктами й абсолютними URL асетів.

**AC-2.3 (Без токена):**
- Given запит без токена,
- When `GET /v1/scenes`,
- Then `401 auth.unauthorized`.

**AC-2.4 (Прапорець не впливає):**
- Given `scene.skia` off,
- When `GET /v1/pantry/locations`,
- Then `200` з місцями.

## US-SCENE-3 — Сцена обладнання
Як адмін, я хочу, щоб новий рядок довідника одразу з'явився на сцені.

**AC-3.1 (З таблиці):**
- Given новий рядок `equipment` зі спрайтом і координатами,
- When `GET /v1/scenes/kitchen_equipment`,
- Then об'єкт у відповіді, `version` зросла.

**AC-3.2 (Без координат):**
- Given рядок без `sceneX`,
- When читається сцена,
- Then об'єкт без позиції, з позначкою ряду «Інше».

## US-SCENE-4 — Запропоновані продукти
Як модератор, я хочу міняти, що пропонувати в холодильнику, без деплою.

**AC-4.1 (Порядок):**
- Given для `fridge` задано молоко, яйця, сир у цьому порядку,
- When `GET /v1/pantry/locations`,
- Then вони в цьому порядку з перекладеними назвами.

**AC-4.2 (Архів):**
- Given інгредієнт зі списку архівовано,
- When читаються місця,
- Then його немає.

**AC-4.3 (Права):**
- Given адмін лише з роллю `translator`,
- When змінює список,
- Then `403 admin.forbidden`.

## US-SCENE-5 — Місце за замовчуванням
Як користувач, я хочу, щоб молоко саме потрапляло в холодильник.

**AC-5.1 (Успадкування):**
- Given мапінг `Молочні` → `fridge`,
- When додається позиція «Кефір» без місця,
- Then `storageLocation = fridge`.

**AC-5.2 (Конкретніший вузол):**
- Given `Молочні` → `fridge` і `Сухе молоко` → `cupboard`,
- When додається сухе молоко,
- Then `cupboard`.

**AC-5.3 (Без збігу):**
- Given категорії немає в мапінгу,
- When додається позиція,
- Then `cupboard`.

**AC-5.4 (Вибір користувача):**
- Given користувач перемістив позицію в морозилку,
- When мапінг змінюється,
- Then позиція лишається в морозилці.

## US-SCENE-6 — Спрайти
Як користувач, я хочу бачити будь-який продукт на полиці.

**AC-6.1 (Ланцюжок):**
- Given інгредієнт без спрайта в категорії зі спрайтом,
- When читається продукт,
- Then спрайт категорії; без нього — «пакунок».
