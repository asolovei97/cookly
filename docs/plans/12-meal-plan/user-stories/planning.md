# Юзер-сторі — планування

US-PLAN-1…5. Загальні правила — в [індексі юзер-сторі](index.md).

## US-PLAN-1 — Прийоми їжі
Як сім'я, я хочу свої прийоми їжі.

**AC-1.1 (Стандартні):**
- Given щойно створена сім'я,
- When клієнт запитує прийоми їжі,
- Then повертаються сніданок, обід, вечеря й перекус.

**AC-1.2 (Власний):**
- Given учасник сім'ї,
- When він додає «Другий сніданок» між сніданком і обідом,
- Then прийом їжі зберігається в цьому порядку.

**AC-1.3 (Архівування):**
- Given прийом їжі із записами в плані,
- When учасник його видаляє,
- Then він зникає з доступних для нових записів, а старі записи лишаються.

## US-PLAN-2 — Готування й позиції
Як укладач меню, я хочу розкласти страви по днях.

**AC-2.1 (Одне готування — кілька прийомів):**
- Given заплановане готування борщу на 8 порцій у понеділок,
- When учасник додає по 3 порції в обід понеділка й вівторка,
- Then обидва прийоми посилаються на те саме готування, а нерозподілених лишається 2 порції.

**AC-2.2 (Перекус-продукт):**
- Given товар «Яблуко» з `шт` = 150 г,
- When учасник додає 1 `шт` у перекус,
- Then позиція зберігається з кількістю 150 г.

**AC-2.3 (Базовий рецепт):**
- Given базовий рецепт «Вівсянка»,
- When учасник додає його в сніданок з кількістю порцій без окремого готування,
- Then позиція зберігається з посиланням на рецепт.

## US-PLAN-3 — Хто їсть і частки
Як укладач меню, я хочу, щоб порції ділилися справедливо.

**AC-3.1 (За замовчуванням):**
- Given сім'я з нормами 2600, 1800 і 1600 ккал,
- When учасник додає позицію в прийом їжі,
- Then усі три персони серед тих, хто їсть, з частками 43, 30 і 27%.

**AC-3.2 (Без персони):**
- Given донька в школі,
- When учасник прибирає її з обіду,
- Then частки решти перераховуються за їхніми нормами.

**AC-3.3 (Неправильна сума):**
- Given ручні частки 50 і 40%,
- When учасник зберігає їх,
- Then повертається `422` з кодом `plan.invalid_shares`.

## US-PLAN-4 — Залишки й строки
Як укладач меню, я хочу бачити, якщо щось не сходиться.

**AC-4.1 (Перерозподіл):**
- Given готування на 6 порцій,
- When у прийоми їжі розподілено 8 порцій,
- Then план показує `over_allocated`.

**AC-4.2 (Строк зберігання):**
- Given рецепт зберігається 2 дні, готування в понеділок,
- When прийом їжі з ним стоїть у четвер,
- Then план показує `storage_expired`.

**AC-4.3 (До готування):**
- Given готування в середу,
- When прийом їжі з ним стоїть у вівторок,
- Then план показує `before_cooking`.

**AC-4.4 (Фактична дата):**
- Given заплановане готування в понеділок і прийом у четвер при строку 3 дні,
- When фактичне готування прив'язують з датою вівторок,
- Then `storage_expired` для четверга зникає.

## US-PLAN-5 — КБЖВ
Як персона, я хочу бачити, чи вкладаюся в норму.

**AC-5.1 (На день):**
- Given персона з нормою 2000 ккал і запланованими позиціями на 2300 ккал з її частками,
- When клієнт запитує план дня,
- Then для персони повертається 2300 ккал і відхилення +300 ккал (+15%).

**AC-5.2 (Тиждень):**
- Given план на 7 днів,
- When клієнт запитує тиждень,
- Then для кожної персони повертається середнє КБЖВ на день.
