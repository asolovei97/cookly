- [Планування](planning.md) — US-PLAN-1…5: прийоми їжі, позиції, хто їсть і частки, залишки й строки, КБЖВ.
- [Перевірки](checks.md) — US-PLAN-6…10: вартість, шаблони, вподобання, алергії, конфлікти й межі.
