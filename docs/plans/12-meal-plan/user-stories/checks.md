# Юзер-сторі — перевірки

US-PLAN-6…10. Загальні правила — в [індексі юзер-сторі](index.md).

## US-PLAN-6 — Вартість
Як сім'я, я хочу знати, скільки коштує тиждень харчування.

**AC-6.1 (Джерела ціни):**
- Given сім'я раніше купувала товар для інгредієнта A, а для інгредієнта B — ні,
- When клієнт запитує вартість готування,
- Then A рахується за ціною того товару, а B — за орієнтовною ціною інгредієнта.

**AC-6.2 (Неповна вартість):**
- Given для одного інгредієнта ціна невідома,
- When клієнт запитує вартість,
- Then вона повертається з `partial: true`.

**AC-6.3 (Без запасів):**
- Given у запасах є все для готування,
- When клієнт запитує вартість плану,
- Then вартість дорівнює повній вартості інгредієнтів.

## US-PLAN-7 — Шаблони й копіювання
Як укладач меню, я не хочу щотижня планувати з нуля.

**AC-7.1 (Додати):**
- Given тиждень з одним готуванням і шаблон з п'ятьма,
- When учасник застосовує шаблон у режимі `add`,
- Then на тижні шість готувань.

**AC-7.2 (Замінити):**
- Given той самий тиждень і шаблон,
- When учасник застосовує шаблон у режимі `replace`,
- Then на тижні лише п'ять готувань із шаблону.

**AC-7.3 (Копіювати тиждень):**
- Given заповнений минулий тиждень,
- When учасник копіює його на наступний,
- Then наступний тиждень має ті самі готування й прийоми їжі за днями тижня.

## US-PLAN-8 — Вподобання
Як персона, я не хочу бачити в своєму меню те, що не люблю.

**AC-8.1 (Неулюблене):**
- Given донька не любить гриби,
- When у вечерю, де вона серед тих, хто їсть, ставлять страву з грибами,
- Then позиція зберігається, а план показує `disliked`.

**AC-8.2 (Через напівфабрикат):**
- Given донька не любить цибулю, а страва містить напівфабрикат з цибулею,
- When страву ставлять доньці,
- Then план показує `disliked`.

**AC-8.3 (Улюблене):**
- Given тато любить гречку,
- When учасник шукає рецепти з фільтром улюбленого тата,
- Then повертаються рецепти з гречкою.

**AC-8.4 (Права):**
- Given персона з акаунтом A,
- When інший учасник змінює її вподобання,
- Then повертається `403` з кодом `household.forbidden`.

## US-PLAN-9 — Алергії
Як батько, я хочу, щоб алерген не потрапив до дитини випадково.

**AC-9.1 (Підтвердження):**
- Given у сина алергія на горіхи,
- When учасник ставить йому страву з волоськими горіхами,
- Then повертається `409` з кодом `plan.allergen_confirmation_required` і переліком збігів.

**AC-9.2 (Явне підтвердження):**
- Given той самий випадок,
- When учасник повторює запит з `confirmAllergen: true`,
- Then позиція зберігається, а план показує `allergen`.

**AC-9.3 (Категорія):**
- Given у мами алергія на категорію «молочні»,
- When їй ставлять страву з сиром категорії «сири» і з вершками категорії «молочні»,
- Then збіг знаходиться лише для вершків.

## US-PLAN-10 — Конфлікти й межі
Як учасник, я не хочу перезаписати чужі зміни.

**AC-10.1 (Одночасна зміна):**
- Given двоє учасників відкрили той самий прийом їжі,
- When другий зберігає зміни зі старою версією,
- Then повертається `409` з кодом `plan.stale`.

**AC-10.2 (Діапазон):**
- Given запит плану на 90 днів,
- When клієнт його надсилає,
- Then повертається `422` з `errors[]` для діапазону.

**AC-10.3 (Далеко вперед):**
- Given дата через 400 днів,
- When учасник планує на неї готування,
- Then повертається `422`.

**AC-10.4 (Минуле):**
- Given учора,
- When учасник змінює вчорашній прийом їжі,
- Then зміни зберігаються.

**AC-10.5 (Інша сім'я):**
- Given прийом їжі сім'ї A,
- When користувач сім'ї B його запитує,
- Then повертається `404`.
