# Модель

Сутності плану, права й межі.

## Прийоми їжі сім'ї

- Назва — звичайний рядок мовою користувача (як контент сім'ї, [B4](../04-i18n/content.md#форма-api)), порядок, необов'язковий час дня (знадобиться для нагадувань).
- Під час створення сім'ї з'являються **4 стандартні**: сніданок, обід, вечеря, перекус ([B5](../05-household/household.md#онбординг)).
- Прийом їжі, в якому вже є записи, **архівується**: його немає серед нових, але старі записи лишаються.

## Заплановане готування

| Поле | Примітка |
|---|---|
| Рецепт | Свій, адмінський чи публічний ([B9](../09-recipes/index.md), [B11](../11-recipe-publishing/index.md)) |
| Порції | Скільки порцій готуємо |
| Дата | Запланований день |
| Вибрані `optional`-рядки | Враховуються в КБЖВ, вартості й закупці |
| Фактичне готування | Посилання з [B16](../../roadmap.md#бекенд), коли приготували |

## Прийом їжі в плані

- Дата + прийом їжі сім'ї.
- **Хто їсть** — список персон, за замовчуванням уся сім'я. Наприклад, в обід донька в школі.
- **Позиції**:
  - **порції запланованого готування** (X порцій);
  - **товар чи інгредієнт** з кількістю й одиницею: перекус «яблуко 150 г», «йогурт 1 шт»;
  - **базовий рецепт** без окремого готування («вівсянка») — у [B17](../../roadmap.md#бекенд) стає [швидким готуванням](../../nutrition-log.md#швидке-готування).

## Частки

- Позиція ділиться між персонами, які їдять, **частками у %**.
- **За замовчуванням** частки пропорційні калорійним нормам цих персон: норми 2600 / 1800 / 1600 → 43 / 30 / 27%.
- Частки можна змінити вручну; сума має бути 100% → інакше `422 plan.invalid_shares`.
- Зміна складу тих, хто їсть, перераховує частки за замовчуванням, якщо їх не змінювали вручну.
- Підтвердження чи зміна часток, коли їдять, — [B17](../../roadmap.md#бекенд).

## Шаблони тижня

- **Шаблон** — збережений набір готувань і прийомів їжі за днями тижня, з порціями, складом тих, хто їсть, і частками.
- **Застосування** до тижня: режим `add` (за замовчуванням) додає позиції; режим `replace` спершу очищає тиждень.
- **«Копіювати тиждень»** — застосування іншого тижня як шаблону, з тими самими режимами.

## Права й конфлікти

- План редагує **будь-який учасник** сім'ї.
- Кожна сутність має версію; одночасна зміна з двох пристроїв → `409 plan.stale`.
- План працює **лише онлайн**.
- План іншої сім'ї → `404`.

## Межі

- Один запит — не більше **62 днів** → інакше `422`.
- Планувати можна до **року вперед** → інакше `422`.
- Минулі дні можна редагувати.

## Ендпоінти

| Метод і шлях | Що робить |
|---|---|
| `GET /v1/plan?from=&to=` | План за діапазоном з розрахунками й попередженнями |
| `POST`/`PATCH`/`DELETE /v1/plan/cookings/{id}` | Заплановані готування |
| `POST`/`PATCH`/`DELETE /v1/plan/meals/{id}` | Прийоми їжі в плані, позиції, хто їсть, частки |
| `GET`/`POST`/`PATCH`/`DELETE /v1/household/meal-slots` | Прийоми їжі сім'ї |
| `GET`/`POST`/`DELETE /v1/plan/templates` | Шаблони тижня |
| `POST /v1/plan/templates/{id}/apply` | Застосувати шаблон (`weekStart`, `mode`) |
| `POST /v1/plan/copy-week` | Копіювати тиждень (`from`, `to`, `mode`) |
| `GET`/`PUT /v1/household/persons/{id}/preferences` | [Вподобання](preferences.md) |
