# Юзер-сторі — облік з'їденого

Критерії приймання для [плану M8](index.md). AC перевіряються Maestro на варіанті `testing` або RNTL, офлайн — з вимкненою мережею емулятора. Кожен AC покривається тестом з назвою `AC_<US>_<N>_...`.

## US-MNUTR-1 — Три тапи
Як користувач, я хочу записати звичну їжу майже без зусиль.

**AC-1.1 (Нещодавня позиція):**
- Given вчора записано йогурт 1 шт,
- When «+», «Записати їжу», тап на йогурт,
- Then запис 1 шт створено, тост «Записано · Змінити · Скасувати».

**AC-1.2 (Скасувати):**
- Given тост,
- When «Скасувати»,
- Then запису немає, запаси повернуто.

**AC-1.3 (Прийом за часом):**
- Given 13:00 і час обіду 13:00,
- When відкривається екран,
- Then чип «Обід».

**AC-1.4 (Без часу):**
- Given жоден прийом їжі не має часу,
- When відкривається екран,
- Then чип «Перекус».

## US-MNUTR-2 — Картка кількості
Як користувач, я хочу вказати кількість зручним способом.

**AC-2.1 (Із запасів):**
- Given продукт є в запасах,
- When відкривається картка,
- Then «із запасів» увімкнено, поля ціни немає.

**AC-2.2 (Не із запасів):**
- Given продукту немає в запасах,
- When відкривається картка,
- Then перемикач вимкнено, є поле ціни.

**AC-2.3 (Наживо):**
- Given 100 г, 250 ккал,
- When задано 200 г,
- Then показано 500 ккал без запиту до сервера.

**AC-2.4 (Страва):**
- Given страва,
- When обрано порції,
- Then грами перераховані.

## US-MNUTR-3 — Заклади
Як користувач, я хочу записати бургер з місця, де я зараз.

**AC-3.1 (Поруч):**
- Given дозвіл надано, точка за 300 м,
- When відкривається вкладка,
- Then точка перша, тап відкриває меню за розділами.

**AC-3.2 (Без дозволу):**
- Given дозвіл відхилено,
- When відкривається вкладка,
- Then нещодавні заклади й пошук.

**AC-3.3 (Запаси):**
- Given записано «Біг Мак» з ціною,
- When читаються запаси й бюджет,
- Then запаси без змін, у бюджеті ціна.

## US-MNUTR-4 — Ручний запис і швидке готування
Як користувач, я хочу записати те, чого немає в базі, і те, що зварив без режиму готування.

**AC-4.1 (Лише ккал):**
- Given «Ручний запис»,
- When введено 350 ккал,
- Then запис створено.

**AC-4.2 (Швидке готування):**
- Given вівсянка, змінено склад, з'їдено 150 г зі 180 г,
- When записано,
- Then запис 150 г, страва із залишком 30 г у «Готових стравах».

## US-MNUTR-5 — Підтвердження
Як член сім'ї, я хочу одним тапом записати обід усіх.

**AC-5.1 (Один тап):**
- Given приготований обід на трьох,
- When «Підтвердити»,
- Then три записи, тост «Скасувати», картка зникла.

**AC-5.2 (Зміна):**
- Given картка,
- When «Змінити» і тата прибрано,
- Then записи лише для двох.

**AC-5.3 (Не приготовано):**
- Given страву не приготовано,
- When показується картка,
- Then «Швидке готування» і «Готувати».

**AC-5.4 (Більше за залишок):**
- Given залишок менший за суму,
- When «Підтвердити»,
- Then записи створено, тост-підказка.

## US-MNUTR-6 — Щоденник
Як користувач, я хочу бачити й виправляти записи дня.

**AC-6.1 (Групи):**
- Given записи сніданку й обіду,
- When відкривається щоденник,
- Then групи за прийомами їжі, підсумки проти норми.

**AC-6.2 (Свайп):**
- Given запис «із запасів»,
- When свайп і «Скасувати»,
- Then запис на місці, запаси незмінні.

**AC-6.3 (Повторити):**
- Given вчорашній сніданок: йогурт і страва без залишку,
- When «Повторити»,
- Then йогурт сьогодні, страва пропущена з поясненням.

**AC-6.4 (Чужий запис):**
- Given запис тата, зроблений ним самим,
- When мама відкриває щоденник тата,
- Then запис видно, дій змінити й видалити немає.

## US-MNUTR-7 — Офлайн
Як користувач, я хочу записувати їжу без мережі.

**AC-7.1 (Запис і підсумок):**
- Given немає мережі,
- When записано 3 позиції,
- Then підсумок дня оновився локально; після появи мережі операції застосовано.

**AC-7.2 (Пошук):**
- Given немає мережі, йогурт є в нещодавніх,
- When шукають «йогурт»,
- Then він у результатах із позначкою «немає мережі».
