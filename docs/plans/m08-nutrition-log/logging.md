# Запис

Як за кілька тапів записати будь-яку їжу. Правила — у [B17](../17-nutrition-log/entries.md).

## Екран запису

**«+» → «Записати їжу»** ([M3](../m03-catalog-and-search/navigation.md#панель-)):

- чип **персони**: за замовчуванням я;
- чип **прийому їжі**: автопідстановка за часом дня ([B17](../17-nutrition-log/days.md#прийоми-їжі));
- картка **«Підтвердити обід»**, якщо є ([підтвердження](confirm-and-diary.md#підтвердження));
- **пошук** [`food-search`](../21-establishments/search.md#єдиний-пошук-їжі) із вкладками **Нещодавнє · Часте · Готові страви · Заклади** ([B17](../17-nutrition-log/days.md#нещодавні));
- **сканер** ([M3](../m03-catalog-and-search/picker-and-search.md#сканер-штрихкоду)) і **«Ручний запис»** поруч із пошуком.

## Три тапи

**«+» → «Записати їжу» → нещодавня позиція**:

- записується **одразу з останньою кількістю**, `nutrition.entry.add@1`;
- тост **«Записано · Змінити · Скасувати»**;
- кроку підтвердження немає.

## Картка кількості

Новий продукт або **«Змінити»**:

- **число** і чипи застосовних [одиниць](../06-catalog/units.md#застосовність);
- для **страви** — грами або порції;
- перемикач **«із запасів»**: увімкнений, якщо продукт є в запасах ([B17](../17-nutrition-log/from-plan.md#запаси));
- поле **ціна** — лише коли «із запасів» вимкнено ([B17](../17-nutrition-log/from-plan.md#бюджет));
- **ккал рахуються наживо**.

## Заклади

У вкладці **«Заклади»** ([B21](../21-establishments/search.md)):

- **найближчі точки** (`/v1/establishments/nearby`), якщо є дозвіл;
- нещодавні заклади;
- пошук; меню за **розділами**.

Дозвіл на геолокацію просимо **при першому відкритті вкладки**; без нього — звичайний пошук.

Картка позиції: порції, ціна, точка. Запаси не змінюються ([B17](../17-nutrition-log/entries.md#види)).

Свого закладу немає → створити приватний ([B21](../21-establishments/publishing-and-prices.md#приватне-для-сімї)).

## Ручний запис

- **Одне поле ккал**.
- Згорнуто: назва, БЖВ, ціна.
- Для кафе без даних ([B17](../17-nutrition-log/entries.md#види)).

## Швидке готування

Обрано рецепт ([B17](../17-nutrition-log/from-plan.md#швидке-готування)) → екран:

- **склад** — змінюється без обмежень;
- **скільки з'їдено**;
- **«із запасів»**: вимкнути — «їв у гостях».

Запис створює страву; **залишок** одразу з'являється в «Готових стравах» ([M7](../m07-cooking/dish.md#готові-страви)).
