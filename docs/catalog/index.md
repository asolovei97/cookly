# Каталог

Довідники, на яких тримається вся система: інгредієнти й товари з КБЖВ, одиниці виміру, обладнання, а також модерація того, що додають користувачі.

- [Інгредієнти й товари](ingredients-and-products.md) — дворівнева модель продукту і джерела КБЖВ.
- [Одиниці виміру](units.md) — базові й альтернативні одиниці, густина, перерахунки.
- [Обладнання](equipment.md) — довідник обладнання, вимоги рецептів, вага тари.
- [Модерація](moderation.md) — як продукти й контент від користувачів потрапляють у загальну базу.
